# 第 3 週今日 Python 練習題：購物車結帳計算機

## 題目說明

你正在為一間小型網路商店開發後端計算邏輯。今天的任務是用**函數**來拆解購物車的結帳流程：計算小計、套用折扣、計算稅金，最後印出收據明細。

## 技術要求
- 概念：`def`、`return`、位置參數、預設參數（default values）、多個回傳值
- 需要的模組：無（純 Python）

## 具體任務

1. **定義 `calculate_subtotal(items)` 函數**
   - 接收一個 list，每個元素為 `(商品名稱, 單價, 數量)` 的 tuple
   - 回傳所有商品的小計金額（單價 × 數量 的總和）

2. **定義 `apply_discount(subtotal, discount_rate=0.0)` 函數**
   - 接收小計與折扣率（預設為 `0.0`，即無折扣）
   - 折扣率範圍：`0.0`（無折扣）到 `1.0`（全免）
   - 回傳折扣後金額

3. **定義 `calculate_tax(amount, tax_rate=0.05)` 函數**
   - 接收金額與稅率（預設 5%）
   - 回傳 `(稅額, 含稅總計)` 兩個值

4. **定義 `print_receipt(items, discount_rate=0.0, tax_rate=0.05)` 函數**
   - 整合以上三個函數
   - 印出格式化收據（見範例輸出）

## 範例

```python
# 商品清單：(名稱, 單價, 數量)
cart = [
    ("蘋果", 30, 3),
    ("牛奶", 65, 2),
    ("麵包", 45, 1),
]

print_receipt(cart, discount_rate=0.1, tax_rate=0.05)
```

**預期輸出：**
```
========== 購物收據 ==========
蘋果        x3    $90
牛奶        x2    $130
麵包        x1    $45
------------------------------
小計：              $265
折扣（10%）：       -$26.5
折扣後金額：        $238.5
稅金（5%）：        $11.93
------------------------------
總計：              $250.43
==============================
```

## 提示
- 可以用 f-string 的 `:.2f` 格式化小數點，例如 `f"{value:.2f}"`
- `calculate_tax` 要同時回傳兩個值：`return tax, total`，呼叫端用 `tax, total = calculate_tax(...)` 接收
- 先讓每個函數獨立運作正確，最後再組合到 `print_receipt`
- 測試 `apply_discount` 時，試試不傳 `discount_rate`，確認預設值有作用

## 學習重點

函數是爬蟲與 ML 流程的核心骨架：
- **爬蟲**：你會將「取得頁面」、「解析內容」、「儲存資料」各自包成函數，讓程式結構清晰可重用
- **ML**：前處理（normalization、encoding）、訓練、評估各階段都是獨立函數，方便調整與測試
- **預設參數**：在 ML 中常見於超參數設定，例如 `train_model(data, epochs=10, lr=0.001)`
