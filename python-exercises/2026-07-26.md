# 第 3 週今日 Python 練習題：智慧型購物清單計算器

## 題目說明

你要幫一個小型網路商店設計一套「購物清單計算器」。這個計算器需要用多個**函數**組合而成，讓程式碼更有結構、更容易維護。透過這個練習，你將學會如何定義函數、傳遞參數、設定預設值，以及讓函數回傳計算結果。

---

## 技術要求
- **概念**：`def`、`return`、位置參數、關鍵字參數、預設參數值、函數組合呼叫
- **需要的模組**：無（純 Python）

---

## 具體任務

1. **定義 `calculate_item_total(price, quantity, discount=0)` 函數**
   - 計算單品小計：`price × quantity × (1 - discount)`
   - `discount` 預設為 `0`（無折扣），範圍為 0.0 ～ 1.0（例如 0.1 代表九折）
   - 回傳小計金額（浮點數，四捨五入到小數點第 2 位）

2. **定義 `apply_shipping(subtotal, threshold=500, fee=60)` 函數**
   - 若 `subtotal` 達到 `threshold`（預設 500 元），免運費，回傳 `0`
   - 否則回傳 `fee`（預設運費 60 元）

3. **定義 `calculate_order(items)` 函數**
   - 參數 `items` 為一個 list，每個元素是字典：`{"name": 商品名, "price": 單價, "quantity": 數量, "discount": 折扣（可選）}`
   - 對每個商品呼叫 `calculate_item_total()`，加總得到小計
   - 呼叫 `apply_shipping()` 得到運費
   - 回傳一個字典：
     ```python
     {
         "items_breakdown": [...],  # 每項商品的名稱與小計
         "subtotal": 小計總金額,
         "shipping": 運費,
         "total": 小計 + 運費
     }
     ```

4. **主程式**：建立一個購物清單並印出結帳明細（格式見下方範例）。

---

## 範例

```python
# 輸入
cart = [
    {"name": "Python 入門書", "price": 350, "quantity": 2},
    {"name": "機械鍵盤", "price": 1200, "quantity": 1, "discount": 0.1},
    {"name": "滑鼠墊", "price": 80, "quantity": 3},
]

result = calculate_order(cart)

# 預期輸出
# ========== 購物明細 ==========
# Python 入門書      x2   NT$ 700.00
# 機械鍵盤           x1   NT$ 1080.00
# 滑鼠墊             x3   NT$ 240.00
# --------------------------------
# 小計：             NT$ 2020.00
# 運費：             NT$ 0.00   (滿 500 元免運)
# ================================
# 總計：             NT$ 2020.00
```

---

## 提示

- 使用 `round(value, 2)` 將浮點數四捨五入到小數點第 2 位。
- 字典的 `discount` 欄位是可選的，讀取時可用 `item.get("discount", 0)` 設定預設值。
- 印出格式化字串時，`f"{value:.2f}"` 可以固定顯示兩位小數。
- 先確認每個函數單獨測試正確，再組合呼叫 `calculate_order()`。

## 學習重點

| 概念 | 在本題的應用 | 爬蟲 / ML 的關聯 |
|------|-------------|-----------------|
| `def` + `return` | 每個計算步驟獨立封裝成函數 | 爬蟲中將「解析一頁資料」封裝成函數，重複呼叫 |
| 預設參數 | `discount=0`、`fee=60` 讓函數更彈性 | ML 中模型超參數常有預設值（如 `n_estimators=100`） |
| 函數組合 | `calculate_order()` 內部呼叫另外兩個函數 | 資料前處理 pipeline：清洗 → 轉換 → 特徵工程，每步一個函數 |
| 字典操作 | 用 `.get()` 安全讀取可選欄位 | 爬蟲解析 JSON API 回傳結果時常用 |
