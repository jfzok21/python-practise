# 第 3 週今日 Python 練習題：購物車計算機

## 題目說明

你要幫一家網路商店建立一個「購物車計算機」，使用函數來計算商品總價、折扣後金額，以及格式化購物清單。這道題將讓你熟悉 `def`、`return`、參數傳遞與預設值的應用。

---

## 技術要求

- **概念：** `def` 定義函數、`return` 回傳值、位置參數、預設參數（default parameter）、關鍵字引數（keyword argument）
- **需要的模組：** 無（純 Python）

---

## 具體任務

1. **定義 `calculate_total(items)` 函數**
   - 接受一個 `list`，每個元素是 `(商品名稱, 單價, 數量)` 的 tuple
   - 回傳所有商品的總金額（浮點數）

2. **定義 `apply_discount(total, discount_rate=0.0)` 函數**
   - 接受總金額與折扣率（預設 `0.0` 表示不打折）
   - `discount_rate` 為 0 到 1 之間的小數，例如 `0.1` 代表九折（打 10% 折扣）
   - 回傳折扣後的金額，四捨五入至小數點後兩位

3. **定義 `print_receipt(items, discount_rate=0.0, currency="TWD")` 函數**
   - 呼叫前兩個函數並印出格式化收據（見範例）
   - `currency` 預設為 `"TWD"`，可改為 `"USD"` 等字串
   - 函數不需要 `return`（直接 `print` 即可）

4. **在主程式呼叫 `print_receipt`，示範：**
   - 不打折的情況
   - 打九折（`discount_rate=0.1`）的情況
   - 使用 `currency="USD"` 的情況

---

## 範例

```python
# 商品清單
cart = [
    ("蘋果", 30, 3),
    ("牛奶", 55, 2),
    ("麵包", 45, 1),
]

print_receipt(cart)
# 預期輸出：
# ==============================
# 購物清單
# ==============================
# 蘋果        x3   90 TWD
# 牛奶        x2  110 TWD
# 麵包        x1   45 TWD
# ------------------------------
# 小計：              245 TWD
# 折扣：              0%
# 應付金額：          245.00 TWD
# ==============================

print_receipt(cart, discount_rate=0.1)
# 應付金額：          220.50 TWD

print_receipt(cart, discount_rate=0.2, currency="USD")
# 應付金額：          196.00 USD
```

---

## 提示

- `def` 函數可以在另一個函數內部被呼叫，把計算邏輯拆開放在不同函數中，主函數負責「組合」。
- 預設參數要放在非預設參數之後，例如 `def foo(a, b=0)` 合法，`def foo(a=0, b)` 不合法。
- 格式化輸出可用 f-string：`f"{name:<10} x{qty}  {subtotal:>5} {currency}"`
- `round(number, 2)` 可以四捨五入到小數點後兩位。
