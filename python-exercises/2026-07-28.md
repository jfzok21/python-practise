# 第 4 週今日 Python 練習題：學生成績管理系統

## 題目說明

你要為一個小型補習班建立一個成績管理系統。透過這個練習，你將學會使用 `list`、`dict`、`tuple` 和 `set` 來組織與操作資料，這些都是 Python 最核心的資料結構。

---

## 技術要求

- **概念**：list、dict、tuple、set 的建立與操作、迴圈遍歷、條件判斷、list comprehension
- **需要的模組**：無（純 Python 內建）

---

## 具體任務

1. **建立學生資料**
   - 使用 `dict` 儲存每位學生的資訊（姓名、各科成績）
   - 將所有學生的 `dict` 放入一個 `list` 中
   - 用 `tuple` 儲存科目名稱（科目清單不可更改）

2. **計算統計數據**
   - 計算每位學生的平均分
   - 找出每科的最高分、最低分
   - 找出全班平均分高於 75 分的學生

3. **使用 set 去重與比較**
   - 找出「數學」或「英文」任一科不及格（低於 60 分）的學生集合
   - 找出「數學」且「英文」都不及格的學生集合
   - 利用 set 差集找出只有「數學」不及格（英文及格）的學生

4. **輸出報告**
   - 印出每位學生的成績單（含平均分）
   - 印出需要輔導的學生名單

---

## 範例

```python
# 科目（tuple，不可修改）
SUBJECTS = ("數學", "英文", "自然", "社會")

# 學生資料（list of dict）
students = [
    {"姓名": "小明", "數學": 85, "英文": 72, "自然": 90, "社會": 68},
    {"姓名": "小華", "數學": 55, "英文": 48, "自然": 70, "社會": 80},
    {"姓名": "小美", "數學": 92, "英文": 88, "自然": 76, "社會": 95},
    {"姓名": "大雄", "數學": 40, "英文": 65, "自然": 58, "社會": 72},
    {"姓名": "靜香", "數學": 78, "英文": 91, "自然": 85, "社會": 89},
]

# 預期輸出範例：
# ========== 成績報告 ==========
# 小明：數學=85, 英文=72, 自然=90, 社會=68 | 平均=78.75
# 小華：數學=55, 英文=48, 自然=70, 社會=80 | 平均=63.25
# ...
#
# 平均分高於 75 分的學生：['小明', '小美', '靜香']
#
# 需要輔導（任一科不及格）：{'小華', '大雄'}
# 數學且英文都不及格：{'小華'}
# 只有數學不及格（英文及格）：{'大雄'}
```

---

## 提示

- 計算平均分：`avg = sum(student[s] for s in SUBJECTS) / len(SUBJECTS)`
- 找不及格學生可以用 set comprehension：`{s["姓名"] for s in students if s["數學"] < 60}`
- set 聯集用 `|`，交集用 `&`，差集用 `-`
- `f-string` 可以格式化小數：`f"{avg:.2f}"`

---

## 學習重點

| 資料結構 | 特性 | 爬蟲／ML 中的應用 |
|----------|------|------------------|
| `list` | 有序、可修改 | 存放爬到的多筆資料列 |
| `dict` | 鍵值對 | 解析 JSON API 回應、特徵欄位映射 |
| `tuple` | 有序、不可修改 | 固定設定（欄位名稱、座標）|
| `set` | 無序、不重複 | 去除重複 URL、快速成員查詢 |

---

## 進階挑戰（選做）

1. **排名**：依平均分由高到低排序學生（使用 `sorted()` 加上 `key` 參數）
2. **科目分析**：用 `dict` 建立每科的成績分佈（及格人數 vs 不及格人數）
3. **dict comprehension**：一行程式碼建立 `{學生姓名: 平均分}` 的字典
4. **巢狀結構**：改用 `{學生姓名: {科目: 成績}}` 的巢狀 dict 重新儲存資料，並完成同樣的統計
