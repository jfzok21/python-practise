# 第 4 週今日 Python 練習題：學生成績管理系統

## 題目說明

你是學校的行政人員，需要建立一個簡單的學生成績管理系統。  
透過這個練習，你將學習如何靈活運用 Python 的四種主要資料結構：`list`、`dict`、`tuple`、`set`，並理解它們各自的特性與適用場景。

---

## 技術要求

- **概念**：list（有序可變）、dict（鍵值對）、tuple（有序不可變）、set（無序不重複）
- **需要的模組**：無（純 Python 內建）

---

## 具體任務

1. **建立學生資料（dict + list）**  
   建立一個 `dict`，鍵為學生姓名，值為一個包含三科成績的 `list`（國文、英文、數學）。  
   至少包含 5 位學生。

2. **計算每位學生的平均分（dict + tuple）**  
   遍歷學生資料，計算每位學生的平均分（取到小數點後一位），  
   並用 `tuple` 儲存每位學生的 `(姓名, 平均分)` 作為不可變記錄。

3. **找出不重複的分數（set）**  
   將所有學生的所有成績收集到一個 `set` 中，  
   印出「出現過的不重複分數有幾種」。

4. **找出高材生（list 過濾）**  
   找出平均分 >= 80 分的學生，將他們的姓名存入一個新的 `list`，並印出。

5. **排行榜（list 排序）**  
   將所有學生依平均分由高到低排序，印出排行榜（名次、姓名、平均分）。

---

## 範例

```python
# 輸入（你自己建立的資料）
students = {
    "小明": [85, 72, 90],
    "小華": [60, 55, 70],
    "小美": [95, 88, 92],
    "小強": [78, 80, 75],
    "小玲": [50, 62, 58],
}

# 預期輸出範例
# === 學生平均分 ===
# 小明：82.3 分
# 小華：61.7 分
# 小美：91.7 分
# 小強：77.7 分
# 小玲：56.7 分

# === 不重複分數種類 ===
# 共出現 15 種不同分數

# === 高材生名單（平均 >= 80）===
# ['小明', '小美']

# === 排行榜 ===
# 第 1 名：小美 - 91.7 分
# 第 2 名：小明 - 82.3 分
# 第 3 名：小強 - 77.7 分
# 第 4 名：小華 - 61.7 分
# 第 5 名：小玲 - 56.7 分
```

---

## 提示

- 計算平均分：`sum(scores) / len(scores)`，配合 `round()` 取到小數點後一位
- `set` 直接用 `len()` 可得不重複元素數量
- 排序可用 `sorted(list, key=lambda x: x[1], reverse=True)`
- `tuple` 不可修改，適合儲存「不應被更動」的最終結果
- 遍歷 `dict` 時，用 `.items()` 同時取得 key 和 value
