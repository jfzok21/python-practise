# 第 4 週今日 Python 練習題：學生成績管理系統

## 題目說明

你將建立一個簡單的學生成績管理系統，練習使用 Python 的四種核心資料結構：`list`、`dict`、`tuple`、`set`。透過這個實際應用場景，了解各種資料結構的特性與適用時機。

## 技術要求
- 概念：list、dict、tuple、set 的建立與操作
- 需要的模組：無（純 Python 標準語法）

## 具體任務

1. **建立學生資料（dict + tuple）**
   - 建立一個 `dict`，鍵為學生姓名，值為 `tuple`（數學成績, 英文成績, 科學成績）
   - 至少包含 5 位學生的資料

2. **計算平均分（list 操作）**
   - 對每位學生，計算其三科的平均分
   - 將 `(姓名, 平均分)` 存入一個 `list`，並依平均分由高到低排序

3. **找出不重複的高分科目（set 應用）**
   - 找出所有學生中，單科達到 90 分（含）以上的「科目名稱」
   - 用 `set` 存放，確保不重複

4. **篩選與輸出**
   - 印出平均分前三名的學生姓名與分數
   - 印出有哪些科目出現過 90 分以上的高分

## 範例

```python
# 學生資料格式
students = {
    "小明": (85, 92, 78),
    "小華": (91, 88, 95),
    "小美": (76, 83, 90),
    "大雄": (60, 72, 68),
    "靜香": (95, 97, 89),
}

# 科目名稱（用於對應 tuple 的索引）
subjects = ["數學", "英文", "科學"]

# 期望輸出範例：
# === 平均分前三名 ===
# 1. 靜香：93.67 分
# 2. 小華：91.33 分
# 3. 小明：85.00 分
#
# === 出現 90 分以上的科目 ===
# {'數學', '英文', '科學'}
```

## 提示
- `tuple` 可以用索引取值：`scores[0]` 是第一科成績
- `dict.items()` 可以同時取得鍵與值：`for name, scores in students.items()`
- `list` 的 `sort()` 或 `sorted()` 可以用 `key=` 參數指定排序依據
- `set` 用 `add()` 新增元素，自動去除重複
- 平均分格式化：`f"{avg:.2f}"` 可顯示到小數點後兩位

## 學習重點

| 資料結構 | 特性 | 本題用途 |
|----------|------|----------|
| `dict`   | 鍵值對，快速查找 | 以姓名對應成績 |
| `tuple`  | 不可變，有序 | 儲存固定的三科成績 |
| `list`   | 可變，有序，可排序 | 排名結果清單 |
| `set`    | 不重複，無序 | 去除重複的高分科目 |

**與爬蟲／ML 的關聯：**
- 爬蟲抓回的資料通常先存入 `list`，再轉換為 `dict` 整理
- ML 資料前處理時，`dict` 用來存欄位映射，`set` 用來找唯一類別（如分類標籤）
- `tuple` 常用於 ML 中的座標、超參數組合等不可變配置
