# 第 4 週今日 Python 練習題：學生成績管理系統

## 題目說明

你要建立一個簡單的學生成績管理系統，練習使用 Python 的四種核心資料結構：`list`、`dict`、`tuple`、`set`。透過這個練習，你將學會如何選擇合適的資料結構來儲存和操作不同類型的資料。

## 技術要求
- 概念：list（有序可變）、dict（鍵值對）、tuple（有序不可變）、set（無序不重複）
- 需要的模組：無（只使用 Python 內建功能）

## 具體任務

1. **建立資料**
   - 用 `dict` 儲存每位學生的姓名與各科成績（國文、數學、英文）
   - 用 `tuple` 儲存每位學生的基本資料（學號、姓名），確保資料不被意外修改
   - 用 `list` 儲存所有學生的姓名清單

2. **計算統計**
   - 計算每位學生的平均分數
   - 找出全班每一科的最高分與最低分
   - 列出所有不重複的成績（使用 `set` 去除重複值）

3. **進行篩選與排序**
   - 找出平均分數 >= 80 的優秀學生名單（使用 list comprehension）
   - 依照平均分數由高到低排序所有學生
   - 印出每位學生的成績單（格式化輸出）

## 範例

```python
# 建立學生資料
students = {
    "小明": {"國文": 85, "數學": 92, "英文": 78},
    "小華": {"國文": 70, "數學": 65, "英文": 88},
    "小美": {"國文": 95, "數學": 80, "英文": 90},
    "小強": {"國文": 60, "數學": 75, "英文": 72},
}

# 學生基本資料（用 tuple 確保不可修改）
student_ids = [
    ("S001", "小明"),
    ("S002", "小華"),
    ("S003", "小美"),
    ("S004", "小強"),
]

# 計算平均分數
def calculate_average(scores: dict) -> float:
    return sum(scores.values()) / len(scores)

# 預期輸出：
# ===== 成績單 =====
# 小明：國文 85 | 數學 92 | 英文 78 | 平均 85.0
# 小華：國文 70 | 數學 65 | 英文 88 | 平均 74.3
# 小美：國文 95 | 數學 80 | 英文 90 | 平均 88.3
# 小強：國文 60 | 數學 75 | 英文 72 | 平均 69.0
#
# ===== 優秀學生（平均 >= 80）=====
# 小明（85.0）、小美（88.3）
#
# ===== 不重複成績清單 =====
# {60, 65, 70, 72, 75, 78, 80, 85, 88, 90, 92, 95}
```

## 提示

- `dict.values()` 可以取出所有值，搭配 `sum()` 和 `len()` 計算平均
- `sorted(students.items(), key=lambda x: ..., reverse=True)` 可以對 dict 排序
- List comprehension 格式：`[x for x in iterable if 條件]`
- 用 `set()` 將 list 轉換成集合可自動去除重複值
- `f"{數字:.1f}"` 可以格式化小數點到一位

## 學習重點

這個練習的概念直接對應到爬蟲和資料分析的實際需求：

- **dict** → 爬蟲抓下來的每一筆資料（如商品名稱、價格、連結）通常儲存為 dict
- **list of dicts** → 多筆爬蟲結果 → 之後會存成 CSV 或 Pandas DataFrame
- **set** → 爬蟲去除重複 URL，避免重複爬取相同頁面
- **tuple** → 固定格式的資料（如座標、RGB 值）在 NumPy/Pandas 中很常見
