# 第 4 週今日 Python 練習題：書籍管理清單

## 題目說明

你要為一間二手書店建立一個簡單的書籍管理系統。這個系統需要使用 Python 的資料結構（list、dict、tuple、set）來儲存書籍資訊，並提供新增、查詢、刪除等基本功能。

## 技術要求
- 概念：list、dict、tuple、set 的操作與應用
- 需要的模組：無（僅使用 Python 內建功能）

## 具體任務

1. **建立書籍資料庫**
   - 使用 `list` 存放所有書籍，每本書用一個 `dict` 表示
   - 每本書包含以下欄位：
     - `title`（字串）：書名
     - `author`（字串）：作者
     - `price`（浮點數）：售價
     - `tags`（set）：標籤，例如 `{"Python", "程式設計"}`

2. **新增書籍**
   - 撰寫函數 `add_book(library, title, author, price, tags)` 將新書加入 `library` 清單

3. **查詢書籍**
   - 撰寫函數 `search_by_tag(library, tag)` 回傳所有含有指定標籤的書籍清單
   - 撰寫函數 `search_by_author(library, author)` 回傳指定作者的所有書籍

4. **統計資訊**
   - 撰寫函數 `get_stats(library)` 回傳一個 `tuple`，包含：
     - 書籍總數
     - 平均售價（四捨五入至小數點第二位）
     - 所有不重複標籤的集合（`set`）

5. **刪除書籍**
   - 撰寫函數 `remove_book(library, title)` 依書名刪除書籍（若不存在則印出提示）

## 範例

```python
# 初始化書庫
library = []

# 新增書籍
add_book(library, "Python 入門", "王小明", 350.0, {"Python", "程式設計", "入門"})
add_book(library, "資料分析實戰", "李大華", 480.0, {"Python", "資料分析", "Pandas"})
add_book(library, "網頁爬蟲技術", "陳美玲", 420.0, {"Python", "爬蟲", "requests"})
add_book(library, "JavaScript 進階", "林志偉", 380.0, {"JavaScript", "前端", "進階"})

# 查詢含有 "Python" 標籤的書
python_books = search_by_tag(library, "Python")
print(f"含 Python 標籤的書籍：{[b['title'] for b in python_books]}")
# 輸出：含 Python 標籤的書籍：['Python 入門', '資料分析實戰', '網頁爬蟲技術']

# 統計資訊
total, avg_price, all_tags = get_stats(library)
print(f"總書數：{total}，平均售價：{avg_price}，所有標籤：{all_tags}")
# 輸出：總書數：4，平均售價：407.5，所有標籤：{'Python', '程式設計', '入門', '資料分析', 'Pandas', '爬蟲', 'requests', 'JavaScript', '前端', '進階'}

# 刪除書籍
remove_book(library, "Python 入門")
print(f"刪除後書數：{len(library)}")
# 輸出：刪除後書數：3
```

## 提示

- `dict` 的值可以是任意型別，包括 `set`
- 使用 `list comprehension` 讓查詢函數更簡潔，例如：`[b for b in library if tag in b['tags']]`
- `tuple` 很適合用來回傳多個統計值，搭配解包語法：`total, avg, tags = get_stats(library)`
- 刪除 list 中的元素可以用 `library.remove(item)` 或 `del library[index]`
- `set` 的聯集可用 `set1 | set2` 或 `set1.union(set2)`；要取得所有書的標籤聯集可以用迴圈累加

## 學習重點

這題是資料結構的綜合練習，與爬蟲／ML 的關聯如下：

- **爬蟲（第 6–8 週）**：爬下來的資料通常以 `list of dict` 的形式儲存，例如每篇文章是一個 dict，整個頁面的文章放在 list 裡。掌握 dict 操作是解析爬蟲資料的基礎。
- **資料分析（第 10 週 Pandas）**：Pandas 的 DataFrame 可以直接從 `list of dict` 建立（`pd.DataFrame(library)`），所以熟悉這種結構，往後學 Pandas 時會非常順手。
- **ML 特徵工程（第 12 週）**：標籤（tag）的概念與 ML 的類別特徵（categorical feature）相似；`set` 的操作也對應到集合運算在特徵選取上的應用。
