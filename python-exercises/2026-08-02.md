# 第 4 週今日 Python 練習題：學生成績管理系統

## 題目說明

建立一個簡單的學生成績管理系統，練習使用 Python 的核心資料結構：`list`、`dict`、`tuple`、`set`。你將透過這個系統學習如何組織、查詢與分析資料——這些技能在之後的爬蟲資料儲存與 Pandas 資料分析中都會大量應用。

## 技術要求
- 概念：list 操作、dict 存取、tuple 不可變性、set 去重
- 需要的模組：無（純 Python 標準語法）

## 具體任務

1. **建立資料結構**：用 `dict` 儲存 5 位學生的成績，鍵為姓名，值為包含三科成績的 `list`（國文、數學、英文）。

2. **計算統計數據**：
   - 計算每位學生的平均成績
   - 找出全班最高分與最低分的學生
   - 計算每一科目的全班平均

3. **使用 tuple 儲存不可變資料**：將科目名稱以 `tuple` 形式定義（因為科目名稱不應被修改）。

4. **使用 set 找出特殊學生**：
   - 找出三科都及格（≥60）的學生集合
   - 找出至少一科不及格的學生集合
   - 驗證兩個集合的聯集是否等於全體學生

5. **排名輸出**：依平均成績由高到低排序，印出排名表。

## 範例

```python
# 資料結構定義
subjects = ("國文", "數學", "英文")  # tuple：不可變

students = {
    "小明": [85, 92, 78],
    "小華": [70, 55, 88],
    "小美": [95, 88, 91],
    "小強": [60, 45, 58],
    "小玲": [78, 83, 72],
}

# 預期輸出
# === 學生成績排名 ===
# 第1名 小美：平均 91.3 分
# 第2名 小明：平均 85.0 分
# 第3名 小玲：平均 77.7 分
# 第4名 小華：平均 71.0 分
# 第5名 小強：平均 54.3 分
#
# === 三科全部及格的學生 ===
# {'小美', '小玲', '小明'}
#
# === 至少一科不及格的學生 ===
# {'小強', '小華'}
#
# === 科目平均 ===
# 國文：77.6 分
# 數學：72.6 分
# 英文：77.4 分
```

## 提示
- 計算平均可用 `sum(scores) / len(scores)`
- `dict.items()` 可同時取得鍵與值：`for name, scores in students.items()`
- `sorted()` 搭配 `key` 參數可排序：`sorted(students.items(), key=lambda x: ..., reverse=True)`
- set comprehension 語法：`{name for name, scores in students.items() if 條件}`
- `round(數字, 1)` 可四捨五入到小數點後一位

## 學習重點

這題直接對應爬蟲與 ML 的核心操作：

- **爬蟲（第 6–8 週）**：爬下來的資料通常是 `list` of `dict`，每筆資料是一個字典。你會用 `dict` 存商品名稱、價格、評分等欄位。
- **Pandas（第 10 週）**：`DataFrame` 本質上就是把 `list` of `dict` 轉換成表格。今天練習的 `dict` 操作，就是 Pandas 的基礎直覺。
- **資料清洗**：`set` 的去重特性，在處理爬蟲重複資料或 ML 特徵類別時非常實用。
