# 第 4 週今日 Python 練習題：書單管理系統

## 題目說明

你是一個書蟲，想用 Python 建立一個簡單的書單管理系統。
這個系統需要記錄書名、作者、閱讀狀態，並能依照不同條件查詢。
透過本題，你將全面練習 list、dict、tuple、set 四種資料結構的使用時機與操作方式。

## 技術要求
- 概念：list（有序集合）、dict（鍵值對）、tuple（不可變序列）、set（去重集合）
- 需要的模組：無（純 Python 內建）

## 具體任務

1. **建立書單**
   建立一個 `list`，裡面存放至少 5 本書的資料。
   每本書用一個 `dict` 表示，包含以下欄位：
   ```python
   {
       "title": "書名",
       "author": "作者",
       "year": 出版年份（int）,
       "read": True 或 False
   }
   ```

2. **統計不重複作者**
   將所有書的作者姓名收集到一個 `set`，印出不重複的作者總數。

3. **篩選已讀書籍**
   用 list comprehension 篩選出 `"read": True` 的書單，
   印出這些書的標題。

4. **建立年份索引**
   建立一個 `dict`，鍵為出版年份，值為該年所有書名的 `list`。
   印出每個年份及對應的書名。

5. **不可變的推薦書**
   挑選 2 本你最想推薦的書，用 `tuple` 儲存其 `(書名, 作者)` 組合，
   並嘗試修改 tuple 看看會發生什麼錯誤（用 try/except 捕捉並印出錯誤訊息）。

## 範例

```python
# 書單範例
books = [
    {"title": "Python 入門", "author": "Guido", "year": 2020, "read": True},
    {"title": "資料科學導論", "author": "Alice", "year": 2021, "read": False},
    {"title": "機器學習實戰", "author": "Guido", "year": 2022, "read": True},
    {"title": "網頁爬蟲技術", "author": "Bob", "year": 2021, "read": False},
    {"title": "Pandas 資料分析", "author": "Alice", "year": 2023, "read": True},
]

# 任務 2 輸出範例
不重複作者數量：3 位
{'Guido', 'Alice', 'Bob'}

# 任務 3 輸出範例
已讀書籍：
- Python 入門
- 機器學習實戰
- Pandas 資料分析

# 任務 4 輸出範例
2020 年出版：['Python 入門']

2022 年出版：['機器學習實戰']
2023 年出版：['Pandas 資料分析']

# 任務 5 輸出範例
推薦書單（tuple）：('Python 入門', 'Guido')
嘗試修改 tuple 發生錯誤：'tuple' object does not support item assignment
```

## 提示
- `set()` 可直接從 list 去除重複：`set([1, 1, 2])` → `{1, 2}`
- dict 可用 `dict.get(key, 預設值)` 避免 KeyError
- list comprehension 格式：`[x for x in 清單 if 條件]`
- 建立年份索引時，可先檢查 key 是否存在再 append：
  ```python
  if year not in index:
      index[year] = []
  index[year].append(title)
  ```
- tuple 一旦建立就無法修改，這是它與 list 最大的差異

## 學習重點

| 結構 | 特色 | 爬蟲 / ML 應用 |
|------|------|----------------|
| `list` | 有序、可修改 | 儲存爬取的多筆資料列 |
| `dict` | 鍵值對應 | 對應欄位名稱與值（JSON 解析） |
| `tuple` | 不可變 | 資料庫欄位定義、固定的設定值 |
| `set` | 去重 | 去除重複 URL、統計不重複類別 |

爬蟲時你會大量使用 `dict` 來代表一筆資料，用 `list` 收集多筆結果，
用 `set` 追蹤已拜訪的頁面；ML 中 Pandas 的 DataFrame 底層也是以 dict 為基礎。
