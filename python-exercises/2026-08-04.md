# 第 5 週今日 Python 練習題：學生成績管理系統

## 題目說明

你需要建立一個簡單的學生成績管理系統，能夠讀取、新增、查詢並儲存學生的成績資料。所有資料以 CSV 檔案格式儲存，並使用字串處理技巧來格式化輸出結果。

## 技術要求
- 概念：字串操作（split、strip、join、format）、檔案讀寫（open、read、write）、CSV 格式處理
- 需要的模組：`csv`、`os`

## 具體任務

1. **建立 CSV 檔案**：建立一個 `students.csv`，包含欄位：`姓名,科目,成績`，並手動輸入至少 5 筆資料。
2. **讀取並顯示資料**：讀取 CSV 檔案，以格式化的方式在終端機顯示所有學生成績（使用 `f-string` 或 `str.format()` 對齊欄位）。
3. **查詢功能**：讓使用者輸入學生姓名，顯示該學生所有科目的成績，並計算平均分。
4. **新增資料**：讓使用者輸入新的學生成績，追加（append）寫入 CSV 檔案。
5. **成績統計**：讀取全部成績，找出最高分、最低分，以及全班平均分。

## 範例

```python
# students.csv 內容範例
姓名,科目,成績
王小明,數學,85
王小明,英文,72
李小花,數學,91
李小花,英文,88
陳大雄,數學,63
陳大雄,英文,77

# 執行後的輸出範例
=== 學生成績一覽 ===
姓名      科目      成績
---------------------
王小明    數學      85
王小明    英文      72
李小花    數學      91
李小花    英文      88
陳大雄    數學      63
陳大雄    英文      77

請輸入學生姓名查詢：王小明
王小明 的成績：
  數學：85 分
  英文：72 分
  平均：78.50 分

=== 全班統計 ===
最高分：91（李小花 / 數學）
最低分：63（陳大雄 / 數學）
全班平均：79.33 分
```

## 提示

- 使用 `open('students.csv', 'r', encoding='utf-8')` 讀取檔案，用 `open('students.csv', 'a', encoding='utf-8', newline='')` 追加寫入。
- 用 `csv.reader()` 和 `csv.writer()` 來處理 CSV 格式，避免手動處理逗號。
- 字串對齊可使用 `f"{name:<8}"` 靠左對齊、`f"{score:>6}"` 靠右對齊。
- 計算平均分時記得將字串轉為數字：`int(row[2])` 或 `float(row[2])`。
- 用 `os.path.exists()` 檢查檔案是否存在，決定是否要先寫入標題列。

## 學習重點

字串處理與 CSV 是爬蟲資料儲存的基礎——當你用 `requests` + `BeautifulSoup` 抓取網頁資料後，最常見的儲存格式就是 CSV。學會 `open()` 的各種模式（`r`/`w`/`a`）和 `csv` 模組，之後爬蟲練習會直接用到這些技巧。資料科學中，`pandas` 的 `read_csv()` 也是建立在相同概念上。

## 進階挑戰（選做）

1. 加入**科目篩選**：讓使用者選擇只顯示特定科目的成績，並排序（由高到低）。
2. 加入**成績等第**：用字串處理將分數轉換為等第（90+ → A、80–89 → B、70–79 → C、60–69 → D、60 以下 → F），寫入新的欄位並存回 CSV。
3. 將所有功能包成**函數**，並用 `while` 迴圈建立一個互動式選單（輸入 1 查詢、2 新增、3 統計、0 離開）。
