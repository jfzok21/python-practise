# 第 5 週今日 Python 練習題：學生成績單 CSV 分析器

## 題目說明

你是學校的助理，需要讀取一份學生成績的 CSV 檔案，分析每位學生的平均分數，並將結果輸出到新的 CSV 檔案。過程中你也需要練習字串處理，例如格式化輸出、去除空白、轉換大小寫等操作。

---

## 技術要求
- **概念**：字串方法（str methods）、檔案讀寫（open、read、write）、CSV 處理
- **需要的模組**：`csv`（標準庫，無需安裝）

---

## 具體任務

1. **建立輸入 CSV 檔案** `students.csv`，內容如下（直接用程式碼寫入）：
   ```
   姓名,數學,英文,自然,社會
   王小明,85,90,78,88
   陳美麗,92,88,95,91
   林大偉,70,75,68,72
   張淑芬,88,82,90,85
   李建國,60,65,58,70
   ```

2. **讀取 CSV 並計算**每位學生的：
   - 平均分數（四捨五入到小數點第一位）
   - 最高分科目
   - 等第（A: 90+, B: 80-89, C: 70-79, D: 60-69, F: 60以下）

3. **字串處理練習**：
   - 將姓名用 `str.ljust(6)` 對齊排版
   - 將等第輸出為完整說明（例如 `A` → `優秀`, `B` → `良好`）

4. **將結果寫入** `results.csv`，欄位為：`姓名,平均分,最高分科目,等第`

5. **在終端機印出排版整齊的成績報告**

---

## 範例

輸入（students.csv）：
```
姓名,數學,英文,自然,社會
王小明,85,90,78,88
陳美麗,92,88,95,91
```

輸出（終端機）：
```
===== 學生成績報告 =====
姓名      平均分  最高分科目  等第
王小明    85.3    英文        B（良好）
陳美麗    91.5    自然        A（優秀）
========================
班級平均：88.4
```

輸出（results.csv）：
```
姓名,平均分,最高分科目,等第
王小明,85.3,英文,B
陳美麗,91.5,自然,A
```

---

## 提示

- 用 `open('students.csv', 'w', encoding='utf-8', newline='')` 寫入 CSV（`newline=''` 避免多餘換行）
- 用 `csv.DictReader(f)` 讀取，可以直接用欄位名稱取值（如 `row['數學']`）
- 計算平均：`round(sum(scores) / len(scores), 1)`
- 找最高分科目：`max(subject_scores, key=subject_scores.get)`
- 字串格式化：`f"{name:<6} {avg:>6.1f}"`（`<` 左對齊，`>` 右對齊）
