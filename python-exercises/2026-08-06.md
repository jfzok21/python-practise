# 第 5 週今日 Python 練習題：學生成績報告產生器

## 題目說明

你是一位學校的系統工程師，需要撰寫一個 Python 程式，從原始的成績字串中解析出學生資料，並將整理後的結果存入 CSV 檔案，最後讀取 CSV 並輸出統計摘要。

這道題目涵蓋字串處理、檔案讀寫、CSV 操作，是爬蟲與資料分析的基礎能力訓練。

---

## 技術要求

- **概念**：str 方法（split、strip、replace、upper/lower）、open（讀寫模式）、CSV 格式讀寫
- **需要的模組**：`csv`（Python 內建）

---

## 具體任務

1. **解析原始資料字串**
   將以下多行字串逐行解析，提取「姓名」、「科目」、「分數」：

   ```
   原始資料（每行格式：姓名 | 科目 | 分數）：
   "  王小明 | 數學 | 88 "
   "  陳雅婷|英文|72"
   "  李建宏 | 數學 | 95 "
   "  王小明 | 英文 | 61 "
   "  陳雅婷 | 數學 | 84 "
   "  李建宏|英文| 78"
   ```

   **要求**：使用 `strip()` 去除多餘空白，使用 `split('|')` 分割欄位。

2. **寫入 CSV 檔案**
   將解析出的資料寫入 `scores.csv`，欄位為：`姓名,科目,分數`

3. **讀取 CSV 並計算統計值**
   重新讀取 `scores.csv`，計算並輸出：
   - 每位學生的平均分數
   - 全班最高分與最低分
   - 數學科與英文科的平均分數

4. **格式化輸出報告**
   使用字串格式化（`f-string` 或 `.format()`）輸出整齊的報告。

## 提示

- 使用 `open('scores.csv', 'w', newline='', encoding='utf-8')` 寫入 CSV（Windows 需要 `newline=''` 避免多餘空行）
- 使用 `csv.writer` 和 `csv.reader` 讀寫 CSV
- 分數從 CSV 讀出時是字串，記得用 `int()` 或 `float()` 轉換
- 可用 `dict` 來累積每位學生的分數清單，例如 `{"王小明": [88, 61]}`
- 計算平均值：`sum(scores) / len(scores)`

## 參考骨架

```python
import csv

raw_data = """  王小明 | 數學 | 88 
  陳雅婷|英文|72
  李建宏 | 數學 | 95 
  王小明 | 英文 | 61 
  陳雅婷 | 數學 | 84 
  李建宏|英文| 78"""

# Step 1：解析字串
records = []
for line in raw_data.strip().split('\n'):
    parts = line.split('|')
    name = parts[0].strip()
    subject = parts[1].strip()
    score = int(parts[2].strip())
    records.append([name, subject, score])

# Step 2：寫入 CSV
with open('scores.csv', 'w', newline='', encoding='utf-8') as f:
    writer = csv.writer(f)
    writer.writerow(['姓名', '科目', '分數'])
    writer.writerows(records)
```
