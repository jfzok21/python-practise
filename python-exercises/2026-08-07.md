# 第 5 週今日 Python 練習題：學生成績報表產生器

## 題目說明

你需要撰寫一個程式，從 CSV 檔案讀取學生成績資料，進行字串處理與統計分析後，將整理好的報表寫入另一個 CSV 檔案。這個練習模擬了真實資料處理的工作流程，也是未來爬蟲儲存資料時的核心技能。

## 技術要求
- 概念：字串方法（strip、split、upper、lower、format）、檔案讀寫（open/close、with 語句）、CSV 讀寫（csv 模組）
- 需要的模組：`csv`、`os`（標準函式庫，無需安裝）

## 具體任務

1. **建立輸入 CSV 檔案**（`students.csv`），內容如下（請直接用程式寫入）：
   ```
   姓名,國文,數學,英文,自然
   王小明 ,85,92,78,88
   陳美玲,76,65, 90,72
   李大華,91,88,85,95
   張小花 , 55,70,62,58
   林志偉,100,98,97,99
   ```

2. **讀取 CSV 並進行字串清理**：
   - 去除每個欄位的多餘空白（使用 `strip()`）
   - 將姓名欄位格式化（確認無空白）

3. **計算每位學生的平均分數**，並依以下標準判斷等級：
   - 90 分以上：`優等`
   - 80-89 分：`甲等`
   - 70-79 分：`乙等`
   - 60-69 分：`丙等`
   - 60 分以下：`丁等`

4. **將結果寫入新的 CSV 檔案**（`report.csv`），格式如下：
   ```
   姓名,國文,數學,英文,自然,平均,等級
   ```

5. **讀取 `report.csv` 並印出排名**（依平均分數由高到低排序）。

## 範例

```python
# 執行後終端機輸出：
=== 學生成績排名 ===
第1名：林志偉  平均：98.50分  等級：優等
第2名：李大華  平均：89.75分  等級：甲等
第3名：王小明  平均：85.75分  等級：甲等
第4名：陳美玲  平均：75.75分  等級：乙等
第5名：張小花  平均：61.25分  等級：丙等

全班平均：82.20 分
最高分：林志偉（98.50）
最低分：張小花（61.25）
```

## 提示

- 使用 `with open('檔名', 'w', newline='', encoding='utf-8-sig') as f:` 寫入 CSV，`utf-8-sig` 可避免 Excel 開啟時出現亂碼
- `csv.DictReader` 可以用欄位名稱取值，比 `csv.reader` 更方便
- 計算平均時記得將字串轉為 `float()`
- 排序可用 `sorted(資料列表, key=lambda x: x['平均'], reverse=True)`
- 字串格式化範例：`f"第{i+1}名：{row['姓名']:<4} 平均：{avg:.2f}分"`

## 進階挑戰（選做）

1. **加入錯誤處理**：如果某個成績欄位不是數字（例如缺考寫成「缺」），程式要能優雅地跳過該學生並印出警告，不能直接崩潰。

2. **產生文字報表**：除了 CSV，額外用 `open()` 寫入一個 `report.txt`，內容是可以直接列印的格式化報表（包含標題、分隔線、排名）。

3. **統計各科班平均**：計算並顯示每一科目的全班平均分數。

4. **互動模式**：讓使用者輸入一個學生姓名，程式查詢並顯示該生的完整成績。
