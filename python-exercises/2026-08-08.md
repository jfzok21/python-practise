# 第 5 週今日 Python 練習題：學生成績管理系統

## 題目說明

你是學校的資訊組長，需要開發一個簡單的學生成績管理程式。程式能從 CSV 檔案讀取學生成績、進行統計分析，並將結果輸出成新的 CSV 報告。透過這個練習，你將熟悉字串處理與檔案讀寫——這兩項技能在之後的爬蟲（儲存抓取資料）與資料分析（讀取資料集）中都非常重要。

## 技術要求
- 概念：字串方法（strip、split、upper、format）、檔案讀寫（open/with）、CSV 格式處理
- 需要的模組：`csv`（標準函式庫，不需安裝）

## 具體任務

1. **建立成績 CSV 檔案**：用 Python 的 `csv` 模組寫入一個 `students.csv`，內容包含至少 5 位學生的姓名、國語、數學、英語成績。

2. **讀取並計算平均**：讀取 `students.csv`，對每位學生計算三科平均分（四捨五入到小數點第一位），並依平均分決定等第：
   - 90 分以上：A
   - 80–89 分：B
   - 70–79 分：C
   - 60–69 分：D
   - 59 分以下：F

3. **字串格式化輸出**：將每位學生的資訊用格式化字串印出，欄位對齊（使用 `f-string` 或 `str.format()`）。

4. **儲存報告**：將包含平均分與等第的結果寫入 `report.csv`。

5. **統計摘要**：在程式結尾印出全班的最高平均、最低平均、以及全班平均。

## 範例

```python
# students.csv 內容（你自己建立）
姓名,國語,數學,英語
王小明,85,92,78
李美麗,70,65,88
張志豪,95,98,91
陳雅婷,60,55,72
林建宏,80,75,83

# 程式執行輸出（格式化對齊）
姓名       國語  數學  英語  平均    等第
王小明      85    92    78   85.0    B
李美麗      70    65    88   74.3    C
張志豪      95    98    91   94.7    A
陳雅婷      60    55    72   62.3    D
林建宏      80    75    83   79.3    C

📊 全班統計
最高平均：94.7（張志豪）
最低平均：62.3（陳雅婷）
全班平均：79.1

# report.csv 內容
姓名,國語,數學,英語,平均,等第
王小明,85,92,78,85.0,B
...
```

## 提示

- 用 `with open('students.csv', 'w', newline='', encoding='utf-8') as f:` 開啟檔案，避免多餘換行
- `csv.DictWriter` 可以用欄位名稱（key）來寫入，比較直觀
- `csv.DictReader` 讀取時每一列會是一個 dict，例如 `row['姓名']`
- 讀進來的數字是字串，記得用 `int()` 轉換後才能做運算
- `round(num, 1)` 可以四捨五入到小數點第一位
- 字串對齊可以用 `f"{name:<8}"` 讓文字靠左補空白，`f"{score:>4}"` 讓數字靠右
