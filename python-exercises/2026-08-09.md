# 第 5 週今日 Python 練習題：學生成績管理系統

## 題目說明

你需要建立一個簡單的「學生成績管理系統」，練習字串處理、檔案讀寫與 CSV 格式操作。程式能從 CSV 檔案讀取學生成績、進行統計分析，並將結果寫回新的 CSV 檔案。

---

## 技術要求

- **概念**：字串方法（split、strip、join、format、upper/lower）、檔案讀寫（open、read、write、with）、CSV 格式處理
- **需要的模組**：`csv`（Python 內建，無需安裝）

---

## 具體任務

1. **建立 CSV 資料檔**：手動（或用程式）建立一個 `students.csv`，包含以下欄位：
   - `name`（姓名）、`math`（數學）、`english`（英文）、`science`（自然）

2. **讀取並解析 CSV**：
   - 使用 `csv.DictReader` 讀取每位學生的資料
   - 將分數從字串轉為整數

3. **進行字串與數值處理**：
   - 計算每位學生的**平均分數**
   - 依平均分數判斷等第：
     - 90 以上 → `"A"`
     - 80–89 → `"B"`
     - 70–79 → `"C"`
     - 60–69 → `"D"`
     - 60 以下 → `"F"`
   - 將姓名轉為全大寫（`.upper()`）

4. **格式化輸出**：
   - 在終端機用對齊格式（`f-string` 或 `str.format()`）印出結果表格

5. **寫入結果 CSV**：
   - 將含有 `name`、`math`、`english`、`science`、`average`、`grade` 的結果寫入 `results.csv`

---

## 範例

```python
# students.csv 內容範例
name,math,english,science
Alice,88,92,78
Bob,65,70,60
Carol,95,89,97

# 終端機輸出範例
姓名        數學  英文  自然  平均    等第
ALICE        88    92    78   86.0    B
BOB          65    70    60   65.0    D
CAROL        95    89    97   93.7    A

# results.csv 輸出範例
name,math,english,science,average,grade
ALICE,88,92,78,86.0,B
BOB,65,70,60,65.0,D
CAROL,95,89,97,93.7,A
```

---

## 提示

- 用 `with open('students.csv', 'r', encoding='utf-8') as f:` 開啟檔案，避免忘記關閉
- `csv.DictReader(f)` 可以直接將每行轉成字典，用欄位名稱存取值很方便
- 計算平均時記得用 `round(avg, 1)` 保留一位小數
- 寫入 CSV 用 `csv.DictWriter`，記得先呼叫 `writer.writeheader()`
- 字串對齊可使用 `f"{name:<10}"` 靠左對齊、`f"{score:>4}"` 靠右對齊

## 學習重點

字串與 CSV 操作是資料分析的基礎：

- **爬蟲關聯**：爬蟲抓回來的資料通常是「字串」，必須先用 `strip()`、`split()`、`replace()` 清理，再轉型成數值才能計算。
- **Pandas 關聯**：下週學的 Pandas `read_csv()` 底層邏輯與今天手動用 `csv` 模組讀取完全相同，理解原理後操作 DataFrame 會更直覺。
- **ML 關聯**：Machine Learning 的訓練資料幾乎都以 CSV 格式存放，今天的讀寫技巧在整個學習旅程都會反覆用到。

## 進階挑戰（選做）

1. **排序**：將學生依平均分數**由高到低**排序後輸出
2. **例外處理**：若分數欄位不是數字（如空白或文字），用 `try/except` 處理錯誤並跳過該筆資料
3. **命令列參數**：用 `sys.argv` 讓使用者在執行時指定輸入檔案名稱，例如 `python grades.py students.csv`
