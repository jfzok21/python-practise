# 第 5 週今日 Python 練習題：學生成績管理系統

## 題目說明

建立一個簡單的學生成績管理系統，練習字串處理、檔案讀寫與 CSV 格式操作。你將從 CSV 檔案讀取學生資料、進行字串處理後分析成績，並將結果寫回新的 CSV 檔案。

## 技術要求
- 概念：str 方法、open()、with 語句、csv 模組、字串格式化
- 需要的模組：`csv`、`os`（皆為標準函式庫，無需安裝）

## 具體任務

1. **建立 CSV 資料檔**：手動建立 `students.csv`，內容包含欄位 `姓名,國文,數學,英文`，至少輸入 5 筆學生資料。

2. **讀取並解析 CSV**：使用 `csv.DictReader` 讀取檔案，將每位學生的分數轉換為整數，計算平均分數（四捨五入至小數第一位）。

3. **字串處理**：
   - 去除姓名中多餘的空白（使用 `.strip()`）
   - 判斷每位學生的等第：90+ → `A`、80+ → `B`、70+ → `C`、60+ → `D`、60以下 → `F`
   - 將姓名轉為全大寫（若有英文名）或直接處理中文姓名

4. **輸出結果**：將處理後的資料（包含原始欄位 + 平均分數 + 等第）寫入 `result.csv`。

5. **印出摘要**：讀取 `result.csv` 並在終端機印出格式化的成績摘要表，包含班級平均。

## 範例

```python
# students.csv 範例內容：
# 姓名,國文,數學,英文
# 王小明,85,90,78
# 李美麗,72,68,80
# 陳大偉,95,92,88

# 預期終端機輸出：
# ==============================
# 學生成績摘要
# ==============================
# 姓名      國文  數學  英文  平均    等第
# 王小明     85   90   78   84.3   B
# 李美麗     72   68   80   73.3   C
# 陳大偉     95   92   88   91.7   A
# ==============================
# 班級平均：83.1
```

## 提示

- 讀取 CSV 時，所有欄位預設為字串，記得用 `int()` 轉換分數
- 使用 `round(value, 1)` 計算小數第一位平均
- `with open('file.csv', 'w', newline='', encoding='utf-8') as f:` 寫入時記得加 `newline=''` 避免多餘空行
- 格式化輸出可用 f-string：`f"{name:<8} {score:>4}"`（左對齊、右對齊）
- `csv.DictWriter` 的 `fieldnames` 參數需指定欄位順序

## 學習重點

### 與爬蟲的關聯
爬蟲抓回來的資料幾乎都是「字串」形式，需要大量的 `.strip()`、`.replace()`、`int()`、`float()` 轉換。將爬蟲結果存成 CSV 是最常見的做法，本週學的 `csv.writer` / `csv.DictWriter` 正是下一步爬蟲實戰的基礎。

### 與 ML 的關聯
資料科學的第一步往往是「讀取 CSV → 清洗字串 → 數值轉換」，這和 Pandas 的底層邏輯完全相同。熟悉手動 CSV 操作後，你會更理解 `pd.read_csv()` 在做什麼。

## 進階挑戰（選做）

1. **錯誤處理**：若 CSV 中某科分數不是數字（空白或文字），改以 0 分計算並印出警告訊息。
2. **排序輸出**：依平均分數由高到低排序後再寫入 `result.csv`。
3. **統計分析**：額外計算並輸出各科最高分、最低分與標準差（不使用 numpy，手動計算）。
4. **互動模式**：讓使用者輸入新學生資料（姓名與三科成績），自動附加到 `students.csv` 並重新產生 `result.csv`。
