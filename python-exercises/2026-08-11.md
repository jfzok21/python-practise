# 第 6 週今日 Python 練習題：用 requests 抓取網頁資料

## 題目說明

你將學習如何使用 `requests` 函式庫向網路伺服器發送 HTTP 請求，並處理回應的狀態碼與內容。這是進入網頁爬蟲世界的第一步！

---

## 技術要求

- **概念**：HTTP GET 請求、回應狀態碼、回應標頭（headers）、回應內文（text / JSON）、例外處理
- **需要的模組**：`requests`（若尚未安裝，請執行 `pip install requests`）

---

## 具體任務

1. **基本請求**：使用 `requests.get()` 向 `https://httpbin.org/get` 發送 GET 請求，並印出：
   - 狀態碼（`status_code`）
   - 回應標頭中的 `Content-Type`
   - 回應的 JSON 內容（`.json()` 方法）

2. **帶參數的請求**：向 `https://httpbin.org/get` 發送請求，同時附上查詢參數 `name=你的名字` 與 `week=6`，確認回應的 `args` 欄位包含你傳入的參數。

3. **自訂標頭**：加入自訂的 `User-Agent` 標頭（例如 `MyPythonBot/1.0`），再次發送請求，確認回應的 `headers` 欄位中出現你設定的 User-Agent。

4. **例外處理**：嘗試向一個不存在的網址（例如 `https://httpbin.org/status/404`）發送請求，利用 `response.raise_for_status()` 捕捉 `requests.exceptions.HTTPError`，並印出友善的錯誤訊息。

5. **超時設定**：向 `https://httpbin.org/delay/5` 發送請求，設定 `timeout=2`，捕捉 `requests.exceptions.Timeout` 例外並印出提示。

---

## 範例

```python
import requests

# 任務 1：基本請求
url = "https://httpbin.org/get"
response = requests.get(url)

print(f"狀態碼：{response.status_code}")
print(f"Content-Type：{response.headers['Content-Type']}")
data = response.json()
print(f"回應 JSON：{data}")

# 任務 2：帶查詢參數
params = {"name": "小明", "week": 6}
response = requests.get(url, params=params)
print(f"傳入的參數：{response.json()['args']}")
# 輸出範例：傳入的參數：{'name': '小明', 'week': '6'}

# 任務 3：自訂 User-Agent
headers = {"User-Agent": "MyPythonBot/1.0"}
response = requests.get(url, headers=headers)
print(f"User-Agent：{response.json()['headers']['User-Agent']}")
# 輸出範例：User-Agent：MyPythonBot/1.0

# 任務 4：例外處理（404）
try:
    r = requests.get("https://httpbin.org/status/404")
    r.raise_for_status()
except requests.exceptions.HTTPError as e:
    print(f"HTTP 錯誤：{e}")

# 任務 5：超時
try:
    r = requests.get("https://httpbin.org/delay/5", timeout=2)
except requests.exceptions.Timeout:
    print("請求超時！伺服器沒有在 2 秒內回應。")
```

---

## 提示

- `requests.get(url, params=dict)` 會自動將字典轉成 URL 查詢字串（`?key=value&...`）。
- `response.json()` 會將回應內文解析為 Python 字典，前提是回應的 Content-Type 是 `application/json`。
- `response.raise_for_status()` 在狀態碼 4xx / 5xx 時會自動拋出例外，是爬蟲中常用的防禦寫法。
- `timeout` 參數可以是單一數字（連線與讀取共用），或 `(connect_timeout, read_timeout)` 元組。
- 測試時可先用 [https://httpbin.org](https://httpbin.org)，它是專門設計用來測試 HTTP 請求的服務。

## 學習重點（跟爬蟲的關聯）

| 本週概念 | 爬蟲中的實際應用 |
|---|---|
| `requests.get()` | 下載網頁 HTML 或 API 回應 |

## 進階挑戰（選做）

1. **Session 物件**：使用 `requests.Session()` 發送多次請求，觀察 Session 物件如何自動保留 cookies 和 headers。

2. **POST 請求**：向 `https://httpbin.org/post` 發送 POST 請求，附上表單資料（`data={"key": "value"}`）或 JSON 資料（`json={"key": "value"}`），比較兩種方式在回應中的差異。

3. **批次請求 + 計時**：用迴圈向 `https://httpbin.org/get?id={i}` 發送 5 次請求（i = 1~5），記錄每次請求的耗時（使用 `time.time()`），最後印出平均耗時。

4. **儲存回應內容**：向某個圖片網址（例如 `https://httpbin.org/image/png`）發送請求，使用 `response.content`（bytes）將圖片儲存到本地檔案。
