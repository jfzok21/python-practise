# 第 6 週今日 Python 練習題：用 requests 抓取網頁資料

## 題目說明

學習使用 `requests` 套件發送 HTTP 請求，取得網頁內容，並從回應中擷取有用的資訊。本週是爬蟲學習的起點，重點在理解 HTTP 請求與回應的基本結構。

## 技術要求
- 概念：HTTP GET 請求、回應狀態碼、回應標頭、回應本文
- 需要的模組：`requests`（需安裝：`pip install requests`）

## 具體任務

1. 使用 `requests.get()` 向公開 API 發送 GET 請求（使用 `https://httpbin.org/get`）
2. 檢查回應的狀態碼（`response.status_code`），若不是 200 則印出錯誤訊息
3. 印出回應的標頭資訊（`response.headers`）中的 `Content-Type`
4. 將回應的 JSON 內容解析（`response.json()`）並印出其中的 `origin`（你的 IP 位址）
5. 使用 `requests.get()` 帶入自訂查詢參數（`params`），向 `https://httpbin.org/get` 傳送 `name=你的名字&city=台灣`，印出回應 JSON 中的 `args` 欄位

## 範例

```python
import requests

# 任務 1-4：基本 GET 請求
url = "https://httpbin.org/get"
response = requests.get(url)

if response.status_code == 200:
    print(f"狀態碼：{response.status_code}")
    print(f"Content-Type：{response.headers['Content-Type']}")
    data = response.json()
    print(f"你的 IP：{data['origin']}")
else:
    print(f"請求失敗，狀態碼：{response.status_code}")

# 任務 5：帶查詢參數
params = {"name": "小明", "city": "台灣"}
response2 = requests.get(url, params=params)
data2 = response2.json()
print(f"傳送的參數：{data2['args']}")
```

```
# 預期輸出（IP 會依實際網路而異）：
狀態碼：200
Content-Type：application/json
你的 IP：203.XX.XX.XX
傳送的參數：{'city': '台灣', 'name': '小明'}
```

## 提示

- `requests` 不是內建套件，需先執行 `pip install requests` 安裝
- `response.status_code` 回傳整數（例如 200、404、500）
- `response.text` 回傳純文字內容；`response.json()` 回傳已解析的 Python 字典
- `params` 參數接受字典，`requests` 會自動將其轉換為 URL 查詢字串（`?name=小明&city=台灣`）
- `https://httpbin.org` 是一個測試 HTTP 請求的公開服務，非常適合練習

## 學習重點（跟爬蟲／ML 的關聯）

- **爬蟲基礎**：所有網頁爬蟲都從 HTTP 請求開始。`requests` 是 Python 爬蟲最常用的工具，下週的 BeautifulSoup 會結合 `requests` 解析網頁 HTML。
- **API 串接**：許多資料科學任務需要從 REST API 取得資料（天氣、股票、社群媒體），這就是 `requests` 的核心用途。
- **狀態碼判斷**：爬蟲程式必須處理各種回應狀態（200 成功、404 找不到、429 請求過多、503 服務不可用），是健壯爬蟲的必要能力。

## 進階挑戰（選做）

1. **加入標頭偽裝**：部分網站會檢查 `User-Agent`，試試加入 `headers={"User-Agent": "Mozilla/5.0 ..."}`，觀察 `https://httpbin.org/headers` 回傳的變化。

2. **錯誤處理**：使用 `try/except` 捕捉 `requests.exceptions.ConnectionError` 與 `requests.exceptions.Timeout`，並加入 `timeout=5` 參數。

3. **多個 URL 批次請求**：建立一個函式 `fetch_urls(urls: list) -> list`，接收多個 URL，回傳每個 URL 的狀態碼與標題（從 JSON 回應中擷取），並用迴圈印出結果。
