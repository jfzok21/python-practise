# 第 6 週今日 Python 練習題：網頁資料抓取入門

## 題目說明

網際網路上有大量公開資訊，學會用 Python 自動抓取這些資料，是進入資料分析與爬蟲世界的第一步。本練習帶你用 `requests` 模組發送 HTTP 請求、取得網頁回應，並從中擷取有用的資訊。

---

## 技術要求

- **概念**：HTTP 請求（GET）、狀態碼、Response 物件、JSON 解析、標頭（headers）
- **需要的模組**：`requests`（若尚未安裝，請執行 `pip install requests`）

---

## 具體任務

1. **基本 GET 請求**
   向 `https://httpbin.org/get` 發送 GET 請求，印出回應狀態碼與回應本文（文字格式）。

2. **解析 JSON 回應**
   `https://httpbin.org/get` 會回傳 JSON 格式資料。將回應解析為 Python 字典，並印出以下欄位：
   - `origin`（你的 IP 位址）
   - `headers`（請求標頭）
   - `url`（請求 URL）

3. **帶參數的請求**
   向 `https://httpbin.org/get` 發送帶有查詢參數的請求：
   - `name`：你的名字（任意字串）
   - `topic`：`python_scraping`
   
   印出回應中 `args` 欄位的內容，確認參數有正確傳送。

4. **自訂標頭（Headers）**
   模擬瀏覽器發送請求，加入 `User-Agent` 標頭，值設為：
   ```
   Mozilla/5.0 (Python Learner) AppleWebKit/537.36
   ```
   向相同網址發送請求，印出回應中的 `headers` 欄位，確認 `User-Agent` 有被記錄。

5. **錯誤處理**
   向一個不存在的網址（例如 `https://httpbin.org/status/404`）發送請求，
   判斷狀態碼是否為 200，若不是則印出：「請求失敗，狀態碼：[狀態碼]」。

---

## 範例

```python
import requests

# 任務 1：基本 GET 請求
response = requests.get("https://httpbin.org/get")
print("狀態碼：", response.status_code)
print("回應內容（前 200 字）：", response.text[:200])

# 任務 2：解析 JSON
data = response.json()
print("來源 IP：", data["origin"])

# 任務 3：帶參數的請求
params = {"name": "小明", "topic": "python_scraping"}
response2 = requests.get("https://httpbin.org/get", params=params)
print("傳入的參數：", response2.json()["args"])

# 任務 4：自訂 User-Agent
headers = {"User-Agent": "Mozilla/5.0 (Python Learner) AppleWebKit/537.36"}
response3 = requests.get("https://httpbin.org/get", headers=headers)
print("User-Agent：", response3.json()["headers"]["User-Agent"])

# 任務 5：錯誤處理
response4 = requests.get("https://httpbin.org/status/404")
if response4.status_code != 200:
    print(f"請求失敗，狀態碼：{response4.status_code}")
```

**預期輸出（範例）：**
```
狀態碼： 200
回應內容（前 200 字）： {
  "args": {}, ...
來源 IP： 1.2.3.4
傳入的參數： {'name': '小明', 'topic': 'python_scraping'}
User-Agent： Mozilla/5.0 (Python Learner) AppleWebKit/537.36
請求失敗，狀態碼：404
```

---

## 提示

- `requests.get(url)` 回傳一個 `Response` 物件。
- `response.status_code` 取得 HTTP 狀態碼（200 = 成功，404 = 找不到頁面）。
- `response.text` 取得回應的純文字內容。
- `response.json()` 將 JSON 格式回應自動解析為 Python 字典，非常方便。
- 傳遞查詢參數用 `params=` 關鍵字引數（`requests` 會自動拼接 URL）。
- 自訂標頭用 `headers=` 關鍵字引數，傳入字典。
- 網路請求有可能失敗，養成檢查狀態碼的好習慣。
