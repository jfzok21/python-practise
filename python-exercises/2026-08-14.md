# 第 6 週今日 Python 練習題：用 requests 抓取網頁資料

## 題目說明

學會使用 `requests` 模組送出 HTTP 請求、取得回應內容，並從中擷取出有用的資訊。這是所有網頁爬蟲的核心基礎：先能「拿到網頁」，下週才能「解析網頁」。

## 技術要求

- 概念：HTTP GET 請求、回應狀態碼、回應文字/JSON 內容、錯誤處理
- 需要的模組：`requests`（安裝：`pip install requests`）

## 具體任務

1. 安裝並匯入 `requests` 模組。
2. 對公開 API `https://httpbin.org/get` 送出 GET 請求，印出：
   - 回應狀態碼（`status_code`）
   - 回應的 JSON 內容中的 `origin`（你的 IP）與 `url` 欄位。
3. 自訂請求標頭（Headers），加入 `User-Agent: MyPythonBot/1.0`，再次發送並印出 headers 回傳值確認設定成功。
4. 加入**錯誤處理**：若狀態碼不是 200，或發生網路連線錯誤（`requests.exceptions.RequestException`），印出友善的錯誤訊息而非讓程式崩潰。
5. 試著對 `https://httpbin.org/status/404` 送請求，確認你的錯誤處理可以正常攔截非 200 回應。

## 範例

```python
# 預期輸出（數值會依實際情況不同）
狀態碼：200
我的 IP：203.XXX.XXX.XXX
請求網址：https://httpbin.org/get
Headers 中的 User-Agent：MyPythonBot/1.0
---
發送請求到 https://httpbin.org/status/404
錯誤：收到非預期的狀態碼 404
```

## 提示

- `response = requests.get(url)` 送出請求；`response.status_code` 取得狀態碼。
- `response.json()` 將 JSON 回應自動轉成 Python dict。
- `response.text` 取得純文字內容（非 JSON 時使用）。
- 自訂 headers 的寫法：`requests.get(url, headers={"User-Agent": "MyPythonBot/1.0"})`。
- 用 `try/except requests.exceptions.RequestException` 捕捉所有網路相關錯誤。
- 檢查狀態碼可以用 `response.raise_for_status()`，它會在非 2xx 時自動拋出例外。

## 學習重點（跟爬蟲／ML 的關聯）

| 概念 | 爬蟲應用 |
|------|----------|
| `requests.get()` | 抓取任何網頁或 API |
| 狀態碼判斷 | 避免爬到錯誤頁面就存入垃圾資料 |
| 自訂 Headers | 模擬瀏覽器行為、避免被網站封鎖 |
| 錯誤處理 | 大量爬取時不因單一失敗而中斷整個程式 |
