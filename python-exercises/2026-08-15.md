# 第 6 週今日 Python 練習題：用 requests 抓取網頁資料

## 題目說明

學習使用 Python 的 `requests` 函式庫發送 HTTP 請求，取得網頁回應並解析其中的純文字或 JSON 資料。這是網頁爬蟲的第一步，也是資料蒐集的核心技能。

## 技術要求

- 概念：HTTP GET 請求、狀態碼、回應內容、JSON 解析、例外處理
- 需要的模組：`requests`（`pip install requests`）

## 具體任務

1. 使用 `requests.get()` 對公開 API `https://httpbin.org/get` 發送請求，印出回應狀態碼。
2. 將回應內容以 JSON 格式解析，印出 `headers` 欄位中的 `User-Agent`。
3. 對 `https://httpbin.org/status/404` 發送請求，判斷狀態碼並印出對應訊息（成功 / 找不到頁面 / 其他錯誤）。
4. 使用 `try/except` 包住請求，捕捉 `requests.exceptions.ConnectionError`，在無法連線時印出友善的錯誤訊息而非程式崩潰。
5. 加入自訂 `headers`（將 `User-Agent` 設為 `MyPythonScraper/1.0`），重新發送步驟 1 的請求，確認 JSON 回應中的 `User-Agent` 已更新。

## 範例

```python
import requests

# 步驟 1 & 2
url = "https://httpbin.org/get"
response = requests.get(url)
print(f"狀態碼：{response.status_code}")

data = response.json()
print(f"User-Agent：{data['headers']['User-Agent']}")

# 步驟 3
r = requests.get("https://httpbin.org/status/404")
if r.status_code == 200:
    print("成功取得頁面")
elif r.status_code == 404:
    print("找不到頁面（404）")
else:
    print(f"其他錯誤：{r.status_code}")

# 步驟 4
try:
    r2 = requests.get("https://這個網址不存在.xyz", timeout=5)
except requests.exceptions.ConnectionError:
    print("無法連線，請確認網址或網路狀態")

# 步驟 5
custom_headers = {"User-Agent": "MyPythonScraper/1.0"}
r3 = requests.get(url, headers=custom_headers)
print(f"自訂 User-Agent：{r3.json()['headers']['User-Agent']}")
```

預期輸出（部分）：
```
狀態碼：200
User-Agent：python-requests/2.x.x
找不到頁面（404）
無法連線，請確認網址或網路狀態
自訂 User-Agent：MyPythonScraper/1.0
```

## 提示

- `response.json()` 會將 JSON 字串自動轉成 Python dict，比手動 `json.loads(response.text)` 更方便。
- 加上 `timeout=10` 參數避免請求無限等待：`requests.get(url, timeout=10)`。
- 真實爬蟲時，許多網站會封鎖預設的 `python-requests` User-Agent，自訂 headers 是繞過的基本技巧。
- `response.raise_for_status()` 可以在狀態碼為 4xx / 5xx 時自動拋出例外，比手動判斷更簡潔。
