# 第 6 週今日 Python 練習題：用 requests 探索網路上的天氣資料

## 題目說明

網頁爬蟲的第一步，就是學會如何用程式發送 HTTP 請求並取得回應。
本題將帶你用 `requests` 模組連接一個公開的 JSON API，取得天氣資訊，並整理成易讀的格式輸出。

我們使用的是 **Open-Meteo**（完全免費、不需要 API Key）的氣象 API。

---

## 技術要求

- **概念**：HTTP GET 請求、JSON 解析、requests.get()、回應狀態碼、例外處理
- **需要的模組**：`requests`（安裝指令：`pip install requests`）

---

## 具體任務

1. 用 `requests.get()` 向 Open-Meteo API 發送請求，取得台北市今日的天氣資料。
   - URL（已包含參數）：
     ```
     https://api.open-meteo.com/v1/forecast?latitude=25.05&longitude=121.53&current_weather=true&timezone=Asia%2FTaipei
     ```

2. 檢查 HTTP 回應狀態碼（`response.status_code`），若不是 `200` 則印出錯誤訊息並結束程式。

3. 用 `response.json()` 將回應內容解析為 Python 字典（dict）。

4. 從 JSON 資料中取出以下欄位並格式化輸出：
   - 時間（`time`）
   - 氣溫（`temperature`，單位：°C）
   - 風速（`windspeed`，單位：km/h）
   - 天氣代碼（`weathercode`）

5. 根據 `weathercode` 對應到文字說明（只需對應下列幾種即可）：

   | weathercode | 說明 |
   |---|---|
   | 0 | ☀️ 晴天 |
   | 1, 2, 3 | ⛅ 部分多雲 |
   | 45, 48 | 🌫️ 有霧 |
   | 51, 53, 55 | 🌦️ 毛毛雨 |
   | 61, 63, 65 | 🌧️ 下雨 |
   | 80, 81, 82 | 🌩️ 陣雨 |
   | 其他 | ❓ 未知天氣 |

## 提示

- `response.json()` 回傳的是一個巢狀字典，天氣資料在 `data["current_weather"]` 裡面。
- 用 `weather_desc.get(code, "❓ 未知天氣")` 可以安全地取得對應說明，找不到時返回預設值。
- 建議用 `try / except requests.exceptions.ConnectionError` 捕捉網路連線錯誤。
- 可以先 `print(response.json())` 看看完整的 JSON 結構，再決定要取哪些欄位。

## 學習重點（跟爬蟲／ML 的關聯）

- **爬蟲基礎**：幾乎所有爬蟲都從 `requests.get()` 開始——這是取得網頁原始碼或 API 資料的核心動作。
- **JSON 是 API 的共同語言**：下週學 BeautifulSoup 時處理的是 HTML；很多現代網站和 API 則直接回傳 JSON，兩者都要會。
- **狀態碼判斷**：在 ML 資料收集中，往往需要大量請求外部 API，對錯誤狀態碼（4xx、5xx）做妥善處理，才能寫出穩健的資料管線。
