# 第 6 週今日 Python 練習題：天氣資料爬蟲入門

## 題目說明

使用 Python 的 `requests` 模組，學習如何對網路 API 發送 HTTP 請求、取得 JSON 格式的回應資料，並進行基本的資料解析與顯示。本題使用免費的公開天氣 API（Open-Meteo）作為練習對象，不需要任何 API 金鑰。

---

## 技術要求

- **概念**：HTTP GET 請求、URL 參數、JSON 解析、錯誤處理（status code）
- **需要的模組**：`requests`（需安裝：`pip install requests`）

---

## 具體任務

1. 使用 `requests.get()` 向 Open-Meteo API 發送請求，取得台北市今日天氣資料。
   - API 端點：`https://api.open-meteo.com/v1/forecast`
   - 參數：`latitude=25.0375`, `longitude=121.5637`, `current_weather=true`

2. 檢查 HTTP 回應狀態碼，若不是 `200` 則顯示錯誤訊息並結束程式。

3. 使用 `.json()` 方法解析回應，取出 `current_weather` 中的以下欄位：
   - `temperature`：目前氣溫（°C）
   - `windspeed`：風速（km/h）
   - `weathercode`：天氣代碼（整數）

4. 根據 `weathercode` 判斷天氣描述：
   - `0`：晴天 ☀️
   - `1`、`2`、`3`：多雲 ⛅
   - `45`、`48`：霧 🌫️
   - `51`–`67`：雨天 🌧️
   - 其他：未知天氣 ❓

5. 將結果格式化輸出。

---

## 範例

```python
# 預期輸出（實際數值依當時天氣而定）
=== 台北市目前天氣 ===
氣溫：27.3 °C
風速：14.2 km/h
天氣狀況：晴天 ☀️
```

## 提示

- 發送請求時記得傳入 `params` 字典，`requests` 會自動組成正確的 URL：
  ```python
  params = {
      "latitude": 25.0375,
      "longitude": 121.5637,
      "current_weather": True
  }
  response = requests.get(url, params=params)
  ```
- 使用 `response.status_code` 檢查是否成功（200 = OK）。
- 使用 `response.json()` 取得字典格式的資料。
- 可用 `try/except requests.exceptions.ConnectionError` 處理網路斷線的情況。

## 學習重點

**跟爬蟲的關聯**：
- `requests` 是 Python 爬蟲最核心的工具，幾乎所有爬蟲專案都會用到它。
- 現代網站常透過 API 回傳 JSON 資料（而非直接回傳 HTML），這種資料更容易解析，下週的 BeautifulSoup 則是針對 HTML 頁面的解析工具。
- 學會看 HTTP 狀態碼（200/404/403/429 等）是除錯爬蟲時必備的技能。
