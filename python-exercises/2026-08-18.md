# 第 7 週今日 Python 練習題：用 BeautifulSoup 解析維基百科頁面

## 題目說明

你已經學會用 `requests` 抓取網頁原始 HTML，現在要進一步學習如何用 **BeautifulSoup** 解析 HTML 結構，擷取你真正需要的資料。本次練習將解析一個真實的維基百科頁面，提取文章標題、段落摘要與所有外部連結。

## 技術要求

- **概念**：HTML 樹狀結構、CSS 選擇器、標籤屬性、find / find_all
- **需要的模組**：`requests`、`bs4`（BeautifulSoup4）

安裝方式：
```bash
pip install requests beautifulsoup4
```

## 具體任務

1. 用 `requests.get()` 抓取以下維基百科頁面的 HTML：
   `https://zh.wikipedia.org/wiki/Python_(%E7%A8%8B%E5%BC%8F%E8%AA%9E%E8%A8%80)`

2. 建立 `BeautifulSoup` 物件（使用 `html.parser`），並擷取：
   - 頁面的 `<h1>` 標題文字
   - 正文第一個 `<p>` 段落（非空白、非括號開頭）的純文字內容（去除 `<sup>` 引用標記）
   - 所有 `href` 以 `http` 開頭的外部連結（去除重複），存成 `list`

3. 將結果印出，格式如下：
   ```
   【標題】Python（程式語言）
   【摘要】Python 是一種廣泛使用的高階程式語言……
   【外部連結數量】42
   【前 5 個外部連結】
   1. https://www.python.org/
   2. ...
   ```

4. 將結果寫入 `output_wiki.txt`，每個區塊之間以空行分隔。

## 範例

```python
import requests
from bs4 import BeautifulSoup

URL = "https://zh.wikipedia.org/wiki/Python_(%E7%A8%8B%E5%BC%8F%E8%AA%9E%E8%A8%80)"

# 抓取 HTML
headers = {"User-Agent": "Mozilla/5.0"}
response = requests.get(URL, headers=headers)
response.encoding = "utf-8"

# 建立 soup 物件
soup = BeautifulSoup(response.text, "html.parser")

# 擷取標題
title = soup.find("h1").get_text()
print(f"【標題】{title}")

# 擷取第一段非空白段落（去除 <sup>）
for p in soup.select("#mw-content-text p"):
    for sup in p.find_all("sup"):
        sup.decompose()       # 移除引用標記
    text = p.get_text().strip()
    if text and not text.startswith("（"):
        print(f"【摘要】{text}")
        break

# 擷取外部連結
links = list({
    a["href"]
    for a in soup.find_all("a", href=True)
    if a["href"].startswith("http")
})
print(f"【外部連結數量】{len(links)}")
```

## 提示

- 用 `soup.select("CSS選擇器")` 可以精準定位元素，例如 `soup.select("#mw-content-text p")`。
- `tag.get_text()` 會把標籤內所有文字合併成字串；`tag.decompose()` 可以從樹中移除該標籤。
- 維基百科有些 `<p>` 是空的或只有空白，記得用 `.strip()` 後判斷 `if text`。
- 使用 `set` 去除重複連結，最後再轉回 `list`。
- 傳送請求時記得加 `User-Agent` header，避免被伺服器拒絕。

## 學習重點

| 技巧 | 爬蟲 / ML 的實際應用 |
|------|----------------------|
| `find` / `find_all` | 定位特定標籤，抓取商品名稱、價格、評論 |
| `select`（CSS 選擇器） | 精準對應動態生成的 HTML 結構 |
| `decompose` | 清理 noise 標籤，為 NLP 模型準備乾淨文本 |
| `get_text` | 取純文字，去除 HTML 標記干擾 |
| 外部連結蒐集 | 建立爬蟲種子 URL 列表，進行多頁爬取 |
