# 第 7 週今日 Python 練習題：用 BeautifulSoup 解析新聞標題

## 題目說明

上週你學會了用 `requests` 抓取網頁的 HTML 原始碼，這週要進一步學習如何用 **BeautifulSoup** 把這段 HTML「讀懂」，找出我們真正想要的資料（例如新聞標題、連結、日期）。

本題目將模擬解析一段 HTML 字串（不需要真的連線），練習用 BeautifulSoup 抓取結構化資料。

---

## 技術要求

- **概念**：HTML 結構、CSS 選擇器、標籤搜尋、屬性提取
- **需要的模組**：
  - `bs4`（BeautifulSoup4）：`pip install beautifulsoup4`

---

## 具體任務

給定以下 HTML 字串（模擬新聞列表頁面）：

```python
html = """
<html>
<body>
  <div class="news-list">
    <article class="news-item">
      <h2 class="title"><a href="/news/1">台灣科技業創新高，AI 需求帶動股市上漲</a></h2>
      <span class="date">2026-08-19</span>
      <p class="summary">受惠於人工智慧需求爆發，台灣科技股今日全面上漲...</p>
    </article>
    <article class="news-item">
      <h2 class="title"><a href="/news/2">暑假尾聲，各地旅遊景點人潮爆滿</a></h2>
      <span class="date">2026-08-19</span>
      <p class="summary">暑假最後一個週末，全台知名景點湧現大批遊客...</p>
    </article>
    <article class="news-item">
      <h2 class="title"><a href="/news/3">氣象局發布颱風警報，民眾應提早準備</a></h2>
      <span class="date">2026-08-18</span>
      <p class="summary">中央氣象局表示，今年第十號颱風正在逼近...</p>
    </article>
    <article class="news-item">
      <h2 class="title"><a href="/news/4">教育部宣布新課綱調整，強化程式設計教育</a></h2>
      <span class="date">2026-08-17</span>
      <p class="summary">教育部今日公布最新課綱修訂內容，將在國高中強化...</p>
    </article>
  </div>
</body>
</html>
"""
```

請完成以下任務：

1. **基本解析**：用 BeautifulSoup 解析上方 HTML，找出所有 `<article class="news-item">` 元素，印出共有幾則新聞。

2. **提取標題與連結**：對每則新聞，取出：
   - 標題文字（`<h2>` 內的 `<a>` 標籤文字）
   - 連結網址（`<a>` 標籤的 `href` 屬性）

3. **提取日期**：取出每則新聞的日期（`<span class="date">` 的文字）。

4. **整合輸出**：將所有資料整理成一個 list of dict，格式如下，並漂亮地印出：
   ```python
   [
     {"title": "...", "url": "/news/1", "date": "2026-08-19"},
     ...
   ]
   ```

5. **篩選今日新聞**：過濾出日期為 `2026-08-19` 的新聞，只印出這些標題。

## 提示

- 用 `BeautifulSoup(html, "html.parser")` 建立解析器物件
- `soup.find_all("article", class_="news-item")` 可以找所有符合條件的標籤
- 在某個標籤物件 `item` 上再次呼叫 `.find()` 可以在其「內部」繼續搜尋
- 取標籤文字用 `.get_text(strip=True)` 或 `.text`
- 取屬性值用 `tag["href"]` 或 `tag.get("href")`
- 日期比較可直接用字串比較（`"2026-08-19" == date_str`）
