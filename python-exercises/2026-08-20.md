# 第 7 週今日 Python 練習題：用 BeautifulSoup 解析書籍清單

## 題目說明

你會從一個模擬的 HTML 書籍目錄頁面中，使用 BeautifulSoup 提取書名、作者、價格與評分，並將結果整理成結構化資料輸出。

## 技術要求

- 概念：HTML 結構、CSS 選擇器、BeautifulSoup 標籤解析、資料清理
- 需要的模組：`bs4`（BeautifulSoup）、`requests`（可選）

## 具體任務

1. 建立一段模擬的 HTML 字串（書籍目錄），包含至少 5 本書，每本書有：書名、作者、價格、星級評分
2. 使用 `BeautifulSoup` 解析這段 HTML
3. 找出所有書籍的資訊，並存入一個 list of dict
4. 印出所有書籍，格式為：`《書名》 | 作者 | 售價 | ⭐ 評分`
5. 找出價格最低與評分最高的書，分別印出

## 範例

```python
# 模擬 HTML 結構（你可以設計自己的格式）
html = """
<div class="book-list">
  <div class="book">
    <h2 class="title">Python 程式設計入門</h2>
    <p class="author">作者：王小明</p>
    <span class="price">NT$ 450</span>
    <span class="rating">4.5</span>
  </div>
  <div class="book">
    <h2 class="title">資料科學實戰</h2>
    <p class="author">作者：李大華</p>
    <span class="price">NT$ 680</span>
    <span class="rating">4.8</span>
  </div>
  <!-- 更多書籍 ... -->
</div>
"""

from bs4 import BeautifulSoup

soup = BeautifulSoup(html, 'html.parser')
books = soup.find_all('div', class_='book')

book_list = []
for book in books:
    title = book.find('h2', class_='title').text
    author = book.find('p', class_='author').text.replace('作者：', '')
    price = int(book.find('span', class_='price').text.replace('NT$ ', ''))
    rating = float(book.find('span', class_='rating').text)
    book_list.append({'title': title, 'author': author, 'price': price, 'rating': rating})

# 預期輸出範例：
# 《Python 程式設計入門》 | 王小明 | NT$ 450 | ⭐ 4.5
# 《資料科學實戰》 | 李大華 | NT$ 680 | ⭐ 4.8
```

## 提示

- `soup.find()` 找第一個符合的標籤；`soup.find_all()` 找所有符合的標籤
- 用 `tag.text` 或 `tag.get_text()` 取得標籤內的文字
- 用 `tag['class']` 或 `tag.get('href')` 取得屬性值
- 字串中的數字要用 `int()` 或 `float()` 轉型後才能排序比較
- `str.replace()` 可以幫你清掉不需要的前綴字元
