# 第 7 週今日 Python 練習題：BeautifulSoup 解析職缺列表

## 題目說明

你已經學會用 `requests` 抓取網頁原始碼。這週的目標是用 **BeautifulSoup** 把原始 HTML 解析成結構化資料——就像從雜亂的書頁中，精準地找到你要的段落。

本題模擬一個靜態的「假職缺頁面」（你自己建立），再用 BeautifulSoup 從中提取職缺名稱、公司、地點等資訊，最後整齊地印出來。

## 技術要求

- **概念**：HTML 結構、CSS 選擇器、BeautifulSoup `find()` / `find_all()` / `.text` / `.get()`
- **需要的模組**：
  ```
  pip install beautifulsoup4 requests
  ```

## 具體任務

1. **建立假職缺頁面**：在同目錄建立 `jobs.html`，內容包含至少 3 筆職缺（使用 `<div class="job-card">` 包裝每一筆）。
2. **解析 HTML**：用 `open()` 讀取 `jobs.html`，並傳入 `BeautifulSoup`。
3. **提取資料**：從每個 `.job-card` 中取出：
   - 職缺名稱（`<h2 class="job-title">`）
   - 公司名稱（`<span class="company">`）
   - 工作地點（`<span class="location">`）
   - 薪資（`<span class="salary">`，若無則顯示「未標示」）
4. **格式化輸出**：每筆職缺以分隔線區隔，清楚印出四個欄位。

## 解題架構（`parse_jobs.py`）

```python
from bs4 import BeautifulSoup

# 1. 讀取 HTML 檔
with open("jobs.html", encoding="utf-8") as f:
    html = f.read()

# 2. 建立 BeautifulSoup 物件
soup = BeautifulSoup(html, "html.parser")

# 3. 找出所有職缺卡片
cards = soup.find_all("div", class_="job-card")

# 4. 逐一解析並輸出
for card in cards:
    title    = card.find("h2",   class_="job-title").text.strip()
    company  = card.find("span", class_="company").text.strip()
    location = card.find("span", class_="location").text.strip()
    salary_tag = card.find("span", class_="salary")
    salary   = salary_tag.text.strip() if salary_tag else "未標示"

    print("=" * 50)
    print(f"職缺名稱：{title}")
    print(f"公　　司：{company}")
    print(f"地　　點：{location}")
    print(f"薪　　資：{salary}")

print("=" * 50)
print(f"共找到 {len(cards)} 筆職缺。")
```

---

## 提示

- `soup.find("tag", class_="className")` 找第一個符合條件的元素。
- `soup.find_all(...)` 回傳一個 list，每個元素都是一個 Tag 物件。
- `.text` 取元素的純文字；`.strip()` 去掉頭尾空白/換行。
- 如果某個 `find()` 找不到就回傳 `None`——這就是為什麼薪資要先判斷 `if salary_tag`，避免 `AttributeError`。
- 解析器選 `"html.parser"`（Python 內建），不需額外安裝；速度快、夠用。

## 學習重點（與爬蟲／ML 的關聯）

| 今天學的 | 之後的用途 |
|---------|-----------|
| `find_all("div", class_="...")` | 批次抓取商品、新聞、股價 |
| `None` 防呆判斷 | 實際網頁資料不完整，是常態 |
| `.text.strip()` | 清理文字是 NLP / ML 前處理的第一步 |
| 結構化輸出 | 下週存成 CSV，送入 Pandas 分析 |
