# 第 7 週今日 Python 練習題：用 BeautifulSoup 解析電影列表頁面

## 題目說明

你將建立一個 Python 腳本，讀取一段模擬的 HTML 電影列表，並使用 BeautifulSoup 解析出每部電影的名稱、評分和類型，最後整齊地輸出到終端機。

## 技術要求
- 概念：HTML 結構、標籤選取、屬性存取、迴圈
- 需要的模組：`bs4`（BeautifulSoup4）、`re`（可選）

## 具體任務

1. 建立一個包含下列 HTML 字串的變數（不需要真實發送網路請求）
2. 使用 `BeautifulSoup` 解析這段 HTML
3. 找出所有電影區塊（每個 `<div class="movie">`）
4. 從每個區塊中取出：
   - 電影名稱（`<h2 class="title">`）
   - 評分（`<span class="rating">`），轉換成 `float`
   - 類型標籤（所有 `<span class="genre">`），收集成 list
5. 只印出評分 **大於 7.5** 的電影
6. 輸出格式範例如下

## 範例

```python
# 使用的 HTML 字串（複製貼入你的程式）
html_content = """
<html>
<body>
  <div id="movie-list">
    <div class="movie">
      <h2 class="title">千與千尋</h2>
      <span class="rating">8.6</span>
      <div class="genres">
        <span class="genre">動畫</span>
        <span class="genre">奇幻</span>
      </div>
    </div>
    <div class="movie">
      <h2 class="title">復仇者聯盟</h2>
      <span class="rating">8.0</span>
      <div class="genres">
        <span class="genre">動作</span>
        <span class="genre">科幻</span>
      </div>
    </div>
    <div class="movie">
      <h2 class="title">愛情公寓</h2>
      <span class="rating">6.2</span>
      <div class="genres">
        <span class="genre">喜劇</span>
        <span class="genre">愛情</span>
      </div>
    </div>
    <div class="movie">
      <h2 class="title">星際效應</h2>
      <span class="rating">9.1</span>
      <div class="genres">
        <span class="genre">科幻</span>
        <span class="genre">劇情</span>
      </div>
    </div>
  </div>
</body>
</html>
"""

# 預期輸出（評分 > 7.5）
# 🎬 千與千尋
#    評分：8.6
#    類型：動畫、奇幻
#
# 🎬 復仇者聯盟
#    評分：8.0
#    類型：動作、科幻
#
# 🎬 星際效應
#    評分：9.1
#    類型：科幻、劇情
```

## 提示

- 安裝：`pip install beautifulsoup4`
- 用 `BeautifulSoup(html_content, "html.parser")` 建立解析器
- `soup.find_all("div", class_="movie")` 可以取得所有電影區塊
- 對單一標籤用 `.text.strip()` 取得純文字
- 多個相同標籤（genres）用 `find_all()` 取回 list，再用 list comprehension 取文字
- `float(rating_text)` 轉換評分為數字再比較

## 學習重點

| 概念 | 爬蟲應用 |
|------|----------|
| `find()` | 找單一目標標籤，如標題、價格 |
| `find_all()` | 找多筆資料，如商品列表、留言 |
| `tag["屬性名稱"]` | 取連結 `href`、圖片 `src` |
| `.text` vs `.get_text()` | 取純文字，後者可指定分隔符 |

真實爬蟲流程：`requests.get(url)` → 取 `response.text` → 丟入 `BeautifulSoup` → 選取你要的標籤。今天先練習最重要的「選取」部分。

## 進階挑戰（選做）

1. **排序輸出**：依評分由高到低排列所有電影（不過濾）
2. **統計類型**：計算所有類型出現的次數，印出最熱門的類型 Top 3
3. **加上屬性**：修改 HTML，在 `<div class="movie">` 加上 `data-year="2023"` 屬性，並在輸出時一併顯示上映年份（用 `tag["data-year"]` 取得）
