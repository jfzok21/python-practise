# 第 7 週今日 Python 練習題：BeautifulSoup 解析靜態網頁

## 題目說明

你需要解析一段 HTML 字串，使用 BeautifulSoup 從中擷取結構化資料，並將結果整理成 Python 字典列表。這是爬蟲流程中最核心的一步：拿到 HTML 後如何「看懂」它、取出你要的資料。

---

## 技術要求

- 概念：HTML 樹狀結構、CSS 選擇器、tag / attribute / text 擷取
- 需要的模組：`bs4`（`pip install beautifulsoup4`）

---

## 具體任務

假設你拿到以下一段書籍清單的 HTML：

```html
<div class="book-list">
  <div class="book" data-id="1">
    <h2 class="title">Python 自動化的樂趣</h2>
    <span class="author">Al Sweigart</span>
    <span class="price">NT$ 580</span>
    <a class="link" href="/book/1">詳細頁面</a>
  </div>
  <div class="book" data-id="2">
    <h2 class="title">流暢的 Python</h2>
    <span class="author">Luciano Ramalho</span>
    <span class="price">NT$ 1080</span>
    <a class="link" href="/book/2">詳細頁面</a>
  </div>
  <div class="book" data-id="3">
    <h2 class="title">Python Cookbook</h2>
    <span class="author">David Beazley</span>
    <span class="price">NT$ 750</span>
    <a class="link" href="/book/3">詳細頁面</a>
  </div>
</div>
```

請完成以下三項任務：

1. **解析基本資料**：用 BeautifulSoup 解析上方 HTML，找出所有 `.book` 區塊，擷取每本書的：
   - `data-id`（屬性值）
   - 書名（`.title` 標籤文字）
   - 作者（`.author` 標籤文字）
   - 價格（`.price` 標籤文字，只保留數字，轉為 `int`）
   - 連結網址（`<a>` 標籤的 `href` 屬性）

2. **整理成結構化資料**：將每本書的資料存入字典，再把所有字典放進一個 list，最後 `print` 出來。

3. **過濾與排序**：找出價格 ≥ 700 的書，依價格由低到高排序後印出書名與價格。

---

## 範例

```python
# 預期輸出（任務 1 & 2）
[
  {'id': '1', 'title': 'Python 自動化的樂趣', 'author': 'Al Sweigart', 'price': 580, 'url': '/book/1'},
  {'id': '2', 'title': '流暢的 Python',       'author': 'Luciano Ramalho', 'price': 1080, 'url': '/book/2'},
  {'id': '3', 'title': 'Python Cookbook',     'author': 'David Beazley',   'price': 750,  'url': '/book/3'},
]

# 預期輸出（任務 3，價格 >= 700，由低到高）
Python Cookbook - NT$ 750
流暢的 Python - NT$ 1080
```

---

## 提示

- `BeautifulSoup(html, 'html.parser')` 可在不安裝額外解析器的情況下使用
- `.find_all('div', class_='book')` 或 `.select('.book')` 都可以找到所有書籍區塊
- 取屬性值：`tag['data-id']` 或 `tag.get('href')`
- 取標籤文字：`tag.text` 或 `tag.get_text(strip=True)`
- 去除價格文字中的非數字：`re.sub(r'\D', '', price_str)` 或 `''.join(c for c in s if c.isdigit())`
- 排序：`sorted(books, key=lambda b: b['price'])`
