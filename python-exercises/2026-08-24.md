# 第 7 週今日 Python 練習題：用 BeautifulSoup 解析電影資訊頁面

## 題目說明

你將練習用 **BeautifulSoup** 解析 HTML，從一段模擬的電影列表頁面中擷取結構化資料。這是網頁爬蟲中最核心的技能——拿到 HTML 之後，如何找到你要的資料。

---

## 技術要求

- **概念**：HTML 樹狀結構、Tag 選取、屬性擷取、迴圈遍歷
- **需要的模組**：`bs4`（BeautifulSoup4）、`re`（選做）

安裝：
```bash
pip install beautifulsoup4
```

---

## 具體任務

給定以下 HTML 字串（直接貼入程式，不需要發送 HTTP 請求）：

```html
<div class="movie-list">
  <div class="movie" data-id="1">
    <h2 class="title">星際效應</h2>
    <span class="year">2014</span>
    <span class="rating">8.6</span>
    <p class="director">導演：克里斯托弗·諾蘭</p>
    <ul class="genres">
      <li>科幻</li><li>劇情</li>
    </ul>
  </div>
  <div class="movie" data-id="2">
    <h2 class="title">千與千尋</h2>
    <span class="year">2001</span>
    <span class="rating">9.0</span>
    <p class="director">導演：宮崎駿</p>
    <ul class="genres">
      <li>動畫</li><li>奇幻</li>
    </ul>
  </div>
  <div class="movie" data-id="3">
    <h2 class="title">寄生上流</h2>
    <span class="year">2019</span>
    <span class="rating">8.5</span>
    <p class="director">導演：奉俊昊</p>
    <ul class="genres">
      <li>劇情</li><li>黑色喜劇</li>
    </ul>
  </div>
</div>
```

1. 用 `BeautifulSoup` 解析上方 HTML。
2. 找出所有 `class="movie"` 的 `<div>`，對每部電影擷取：
   - `data-id` 屬性
   - 標題（`.title`）
   - 年份（`.year`）
   - 評分（`.rating`，轉為 `float`）
   - 導演名稱（去掉「導演：」前綴）
   - 類型列表（`<li>` 的文字，組成 Python list）
3. 將結果整理成 **list of dict**，印出每部電影的資訊。
4. 額外任務：找出評分最高的電影並印出其標題與評分。

```
ID: 2 | 千與千尋 (2001) | 評分: 9.0 | 導演: 宮崎駿 | 類型: 動畫, 奇幻

🏆 評分最高：千與千尋（9.0 分）
```

---

## 提示

- `soup.find_all('div', class_='movie')` 可找出所有電影 div（注意 `class_` 有底線）
- 取屬性用 `tag['data-id']` 或 `tag.get('data-id')`
- 取文字用 `tag.get_text(strip=True)`
- 導演欄位的文字是「導演：XXX」，可用 `str.replace('導演：', '')` 去除前綴
- 類型用 `[li.get_text() for li in genres_ul.find_all('li')]`

## 學習重點

| 本週技能 | 與爬蟲的關聯 |
|----------|-------------|
| `find` / `find_all` | 定位頁面中的目標元素 |
| CSS class 選取 | 幾乎所有真實網站都用 class 區分區塊 |
| 屬性擷取 `tag['attr']` | 擷取連結 `href`、圖片 `src`、資料 `data-*` |
| 結果整理成 dict | 為下一步存 CSV 或 DataFrame 做準備 |
