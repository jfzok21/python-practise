# 第 8 週今日 Python 練習題：多頁爬蟲與 CSV 儲存

## 題目說明

上週你已經學會用 BeautifulSoup 解析單一網頁的 HTML。這週進入爬蟲進階：
學習如何**爬取多頁資料**（分頁），並將結果**整齊地儲存為 CSV 檔案**。
這兩個技能是實際爬蟲專案的核心流程。

## 技術要求
- 概念：迴圈爬多頁、解析分頁連結、CSV 寫入
- 需要的模組：`requests`、`bs4`（BeautifulSoup4）、`csv`、`time`

## 具體任務

1. **模擬多頁資料（不需真實網路請求）**
   建立一個函數 `fake_page(page_num)` 回傳模擬的 HTML 字串，
   包含 5 筆「書籍」資料（title、price），並在第 3 頁後回傳空頁（爬蟲停止條件）。

2. **撰寫爬蟲主迴圈**
   從第 1 頁開始，用 BeautifulSoup 解析每一頁，
   擷取所有書籍的 `title` 和 `price`，直到頁面無資料為止。
   每頁之間加入 `time.sleep(1)` 模擬禮貌爬蟲。

3. **將結果寫入 CSV**
   將所有頁面的資料合併，寫入 `books.csv`，欄位為 `title,price,page`。

4. **讀回並驗證**
   用 `csv.reader` 讀回 `books.csv`，印出總筆數與每頁筆數統計。

## 範例

```python
# 預期 CSV 內容（books.csv）
title,price,page
Python 入門,NT$350,1
資料科學實戰,NT$480,1
...（共 15 筆，3 頁 × 5 筆）

# 終端機輸出
爬取第 1 頁... 取得 5 筆
爬取第 2 頁... 取得 5 筆
爬取第 3 頁... 取得 5 筆
爬取第 4 頁... 無資料，停止
已儲存 books.csv（共 15 筆）
--- 讀回驗證 ---
第 1 頁：5 筆
第 2 頁：5 筆
第 3 頁：5 筆
總計：15 筆
```

## 程式骨架

```python
import csv
import time
from bs4 import BeautifulSoup

# === Step 1：模擬假網頁 ===
def fake_page(page_num):
    if page_num > 3:
        return "<html><body></body></html>"  # 空頁
    books = [
        ("Python 入門", "NT$350"),
        ("資料科學實戰", "NT$480"),
        ("機器學習基礎", "NT$520"),
        ("網路爬蟲技術", "NT$390"),
        ("資料視覺化", "NT$410"),
    ]
    items = ""
    for title, price in books:
        items += f'<li class="book"><span class="title">{title} P{page_num}</span><span class="price">{price}</span></li>'
    return f"<html><body><ul>{items}</ul></body></html>"

# === Step 2：爬蟲主迴圈 ===
all_books = []
page = 1
while True:
    print(f"爬取第 {page} 頁...", end=" ")
    html = fake_page(page)
    soup = BeautifulSoup(html, "html.parser")
    books = soup.select("li.book")
    if not books:
        print("無資料，停止")
        break
    for book in books:
        title = book.select_one(".title").text
        price = book.select_one(".price").text
        all_books.append({"title": title, "price": price, "page": page})
    print(f"取得 {len(books)} 筆")
    time.sleep(1)
    page += 1

# === Step 3：寫入 CSV ===
with open("books.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=["title", "price", "page"])
    writer.writeheader()
    writer.writerows(all_books)
print(f"已儲存 books.csv（共 {len(all_books)} 筆）")

# === Step 4：讀回驗證 ===
print("--- 讀回驗證 ---")
page_counts = {}
with open("books.csv", newline="", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    total = 0
    for row in reader:
        p = row["page"]
        page_counts[p] = page_counts.get(p, 0) + 1
        total += 1
for p, count in sorted(page_counts.items()):
    print(f"第 {p} 頁：{count} 筆")
print(f"總計：{total} 筆")
```

## 提示

- `soup.select("li.book")` 選取所有 class 為 `book` 的 `<li>` 元素
- `csv.DictWriter` 可以直接用字典寫入，比 `csv.writer` 更直觀
- `newline=""` 在開啟 CSV 時必加，否則 Windows 會多空行（Linux 也建議加）
- 真實爬蟲中，`time.sleep(1)` 是避免被封鎖的基本禮貌
- 分頁停止條件通常是：頁面無資料、遇到「下一頁」按鈕不存在、或達到指定頁數
