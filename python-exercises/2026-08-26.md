# 第 8 週今日 Python 練習題：多頁爬蟲與 CSV 資料儲存

## 題目說明

在上週學習了用 BeautifulSoup 解析單一 HTML 頁面之後，本週要進一步挑戰「多頁爬蟲」——自動翻頁、收集多頁資料，並將結果整理後寫入 CSV 檔案，以便日後用 Pandas 進行分析。

我們以模擬一個書籍目錄網站（[books.toscrape.com](http://books.toscrape.com)）為練習對象。該網站共有 50 頁，每頁列出 20 本書，是學習多頁爬蟲的絕佳沙盒。

---

## 技術要求

- **概念**：迴圈翻頁、URL 組合、資料清洗、CSV 寫入
- **需要的模組**：
  - `requests`
  - `bs4`（BeautifulSoup）
  - `csv`
  - `time`（避免爬蟲過快被封鎖）

---

## 具體任務

1. **撰寫 `scrape_books(max_pages)` 函數**
   - 接受參數 `max_pages`，控制最多爬取幾頁（預設爬 3 頁即可）
   - 每頁 URL 格式為：
     - 第 1 頁：`http://books.toscrape.com/catalogue/page-1.html`
     - 第 N 頁：`http://books.toscrape.com/catalogue/page-{N}.html`

2. **從每頁解析以下欄位**（每頁約 20 本書）
   - 書名（`title`）
   - 星級評分（`rating`）：將英文文字轉為數字，例如 `"Three"` → `3`
   - 價格（`price`）：去掉 `£` 符號，保留浮點數
   - 是否有庫存（`in_stock`）：`True` / `False`

3. **翻頁邏輯**
   - 每頁爬完後，用 `time.sleep(1)` 等待 1 秒，避免對伺服器造成過大負擔
   - 若該頁回傳狀態碼不是 200，停止爬取並印出警告

4. **將所有資料寫入 `books.csv`**
   - 欄位順序：`title, rating, price, in_stock`
   - 使用 `csv.DictWriter`
   - 最後印出：「共爬取 X 本書，已儲存至 books.csv」

---

## 範例

```python
# 執行
books = scrape_books(max_pages=2)
# 預期輸出（前 2 筆示意）
# [
#   {'title': 'A Light in the Attic', 'rating': 3, 'price': 51.77, 'in_stock': True},
#   {'title': 'Tipping the Velvet',   'rating': 1, 'price': 53.74, 'in_stock': True},
#   ...
# ]
# 共爬取 40 本書，已儲存至 books.csv
```

---

## 提示

- BeautifulSoup 選取書名：`article.find('h3').find('a')['title']`
- 星級文字在 `<p class="star-rating One">` 的 class 清單第二個元素
- 可用字典做映射：`RATING_MAP = {'One':1, 'Two':2, 'Three':3, 'Four':4, 'Five':5}`
- 價格在 `<p class="price_color">` 內，記得用 `float(text.replace('£','').strip())`
- 庫存判斷：`<p class="instock availability">` 的文字包含 `"In stock"` 則為 `True`

## 進階挑戰（選做）

1. **自動偵測總頁數**：從第 1 頁解析 `<li class="next">` 是否存在，動態決定要爬幾頁，直到沒有「下一頁」為止。

3. **篩選高評分書籍**：爬完後，將 `rating >= 4` 且 `price < 20` 的書另存為 `top_picks.csv`。
