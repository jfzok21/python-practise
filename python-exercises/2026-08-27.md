# 第 8 週今日 Python 練習題：多頁爬蟲與 CSV 儲存

## 題目說明

你是一位資料分析師，需要收集某個模擬書店網站的書籍資料。該網站有多頁內容，你需要爬取所有頁面的書名、價格、評分，並將資料整理後儲存成 CSV 檔案供後續分析使用。

本次練習使用的是公開的練習用爬蟲網站：`https://books.toscrape.com`

## 技術要求
- 概念：HTTP 請求、HTML 解析、多頁爬取、CSV 檔案輸出
- 需要的模組：`requests`、`bs4`（BeautifulSoup）、`csv`、`time`

## 具體任務

1. **建立爬蟲主程式** `scraper.py`：
   - 設定起始 URL：`https://books.toscrape.com`
   - 自動偵測並追蹤「下一頁」按鈕，直到沒有下一頁為止
   - 每次請求之間暫停 1 秒（`time.sleep(1)`），避免對伺服器造成過大負擔

2. **解析每頁的書籍資料**：
   - 書名（`title` 屬性，在 `<article class="product_pod">` 的 `<h3><a>` 標籤內）
   - 價格（`<p class="price_color">` 標籤的文字內容，去除 `£` 符號）
   - 評分（`<p class="star-rating">` 的 class 屬性，如 `One`、`Two`、`Three`、`Four`、`Five`，轉為數字 1–5）
   - 庫存狀態（`<p class="instock availability">` 的文字，去除多餘空白）

3. **將所有資料儲存為 CSV 檔案** `books.csv`：
   - 欄位名稱：`title`、`price`、`rating`、`availability`
   - 使用 `utf-8-sig` 編碼（確保 Excel 開啟時不會亂碼）

4. **輸出爬取摘要**：
   - 總共爬取了幾頁
   - 總共收集了幾筆書籍資料
   - CSV 檔案路徑

## 學習重點

本題整合了爬蟲的核心技能，與實戰應用直接相關：

- **多頁爬取**是實際爬蟲的必備能力，電商、新聞、論壇等網站幾乎都有分頁機制
