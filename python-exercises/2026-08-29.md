# 第 8 週今日 Python 練習題：多頁爬蟲與 CSV 儲存

## 題目說明

本週進入爬蟲進階階段。你將學習如何抓取**多個頁面**的資料，並將結果整理後儲存成 **CSV 檔案**，為後續的資料分析做準備。

本練習以模擬的書籍列表網站為例（可使用 `books.toscrape.com`），練習翻頁邏輯與結構化儲存。

---

## 技術要求

- **概念**：多頁爬蟲、翻頁邏輯、URL 組合、CSV 寫入、資料去重
- **需要的模組**：
  - `requests`
  - `bs4`（BeautifulSoup）
  - `csv`
  - `time`（避免對伺服器造成過大壓力）

---

## 具體任務

1. **設定爬取目標**：以 `https://books.toscrape.com/catalogue/page-{n}.html` 為基礎，爬取第 1 至第 5 頁（共 5 頁）。
2. **解析每頁資料**：從每頁抓取所有書籍的：
   - 書名（`title` 屬性或 `<h3>` 內的 `<a>`）
   - 評分（`<p class="star-rating ...">` 的 class 名稱轉換成數字）
   - 價格（`<p class="price_color">`）
3. **翻頁邏輯**：使用迴圈自動產生每頁的 URL，每頁請求之間加上 `time.sleep(1)` 暫停 1 秒。
4. **儲存 CSV**：將所有書籍資料寫入 `books.csv`，欄位為 `title, rating, price`。
5. **輸出摘要**：爬完後印出總共抓到幾本書、平均價格為何。

---

## 範例

```python
# 預期 CSV 輸出（books.csv 前幾行）
title,rating,price
A Light in the Attic,3,£51.77
Tipping the Velvet,1,£53.74
Soumission,1,£50.10
...

# 執行結束後的終端輸出
已爬取 5 頁，共 100 本書。
平均價格：£35.83
CSV 已儲存至 books.csv
```

---

## 提示

- 評分的 class 名稱是英文單字，需要自行對應：`One=1, Two=2, Three=3, Four=4, Five=5`。
- 使用 `csv.DictWriter` 可以更方便地寫入欄位名稱與資料。
- 第一頁的 URL 也可以是 `https://books.toscrape.com/catalogue/page-1.html`，格式一致。
- 若網路不穩，可先用 `requests` 將 HTML 存到本地後再做解析測試。
- 記得在 CSV 中正確處理書名可能包含逗號的情況（DictWriter 會自動處理）。

## 學習重點

| 技能 | 與未來的關聯 |
|------|------------|
| 多頁 URL 組合 | 真實爬蟲專案幾乎都需要翻頁 |

| `csv.DictWriter` | 資料進入 Pandas 前的標準格式 |
| 資料摘要計算 | 後續 NumPy / Pandas 的資料分析基礎 |
