# 第 8 週今日 Python 練習題：多頁爬蟲與 CSV 儲存

## 題目說明

本週是爬蟲進階實戰。你將練習如何爬取**多個分頁**的資料，並將結果整理後儲存成 **CSV 檔案**，模擬真實爬蟲任務的完整流程。

我們以爬取 [Books to Scrape](http://books.toscrape.com/)（合法練習用網站）為例，抓取多頁書籍的標題、價格、評分，並匯出 CSV。

---

## 技術要求

- **概念**：多頁爬蟲、翻頁邏輯、資料整理、CSV 寫入
- **需要的模組**：`requests`、`bs4`（BeautifulSoup）、`csv`、`time`

---

## 具體任務

1. 使用 `requests` 發送 HTTP GET 請求，取得 `http://books.toscrape.com/` 第一頁的 HTML。
2. 用 BeautifulSoup 解析頁面，抓取所有書籍的：
   - 書名（`article.product_pod h3 a` 的 `title` 屬性）
   - 價格（`article.product_pod .price_color`）
   - 評分（`article.product_pod p.star-rating` 的 class，例如 `Three`）
3. 實作翻頁邏輯：檢查是否有「next」按鈕（`li.next a`），若有則拼接下一頁 URL 繼續爬取，**至少爬取前 3 頁**。
4. 每頁爬完後暫停 1 秒（`time.sleep(1)`），避免對伺服器造成壓力。
5. 將所有書籍資料整理成一個 list of dicts，並寫入 `books.csv`，欄位為 `title`、`price`、`rating`。

---

## 範例

```python
# 預期輸出（books.csv 前幾列）
title,price,rating
A Light in the Attic,£51.77,Three
Tipping the Velvet,£53.74,One
Soumission,£50.10,One
Sharp Objects,£47.82,Four
...
```

```python
# 程式骨架
import requests
from bs4 import BeautifulSoup
import csv
import time

BASE_URL = "http://books.toscrape.com/"
books = []

url = BASE_URL
page = 1

while url and page <= 3:
    print(f"爬取第 {page} 頁：{url}")
    response = requests.get(url)
    soup = BeautifulSoup(response.text, "html.parser")

    for article in soup.select("article.product_pod"):
        title = article.select_one("h3 a")["title"]
        price = article.select_one(".price_color").text.strip()
        rating = article.select_one("p.star-rating")["class"][1]  # e.g. "Three"
        books.append({"title": title, "price": price, "rating": rating})

    next_btn = soup.select_one("li.next a")
    if next_btn:
        # 拼接下一頁 URL（需處理相對路徑）
        next_href = next_btn["href"]
        if "catalogue/" in url:
            url = BASE_URL + "catalogue/" + next_href
        else:
            url = BASE_URL + next_href
    else:
        url = None

    page += 1
    time.sleep(1)

# 寫入 CSV
with open("books.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=["title", "price", "rating"])
    writer.writeheader()
    writer.writerows(books)

print(f"完成！共爬取 {len(books)} 本書，已儲存至 books.csv")
```

---

## 提示

- `requests.get(url)` 取得 HTML，再用 `BeautifulSoup(response.text, "html.parser")` 解析。
- 翻頁時注意 URL 的相對路徑：第 2 頁以後的 `next` href 是 `catalogue/page-3.html`，需加上 `BASE_URL`。
- `article["class"]` 會回傳 list，評分的文字在 index 1，例如 `["star-rating", "Three"]`。
- `csv.DictWriter` 比 `csv.writer` 更方便處理 dict 資料。
- 記得加 `time.sleep(1)` 做禮貌性延遲。
