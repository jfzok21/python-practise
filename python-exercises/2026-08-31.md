# 第 8 週今日 Python 練習題：多頁爬蟲與 CSV 儲存

## 題目說明

你將建立一個能自動翻頁爬取資料、並將結果儲存成 CSV 檔案的爬蟲程式。
本次練習模擬爬取一個書籍目錄網站（[books.toscrape.com](http://books.toscrape.com)），
從多個頁面抓取書名、價格與評分，並整理成結構化的 CSV 輸出。

## 技術要求

- **概念**：多頁爬蟲、迴圈翻頁、資料清洗、CSV 寫入
- **需要的模組**：`requests`、`bs4`（BeautifulSoup）、`csv`、`time`

## 具體任務

1. 使用 `requests` 發送 HTTP GET 請求，從第 1 頁開始爬取。
2. 使用 BeautifulSoup 解析每頁的書籍列表，擷取：
   - 書名（`article.product_pod > h3 > a` 的 `title` 屬性）
   - 價格（`.price_color` 的文字內容，去除 `£` 符號）
   - 評分（`p.star-rating` 的 `class` 屬性，將英文文字轉為數字）
3. 自動偵測「下一頁」連結（`li.next > a`），若存在則繼續爬取，直到最後一頁。
4. 加入 `time.sleep(1)` 避免請求過於頻繁。
5. 將所有書籍資料寫入 `books.csv`，欄位為：`title,price,rating`。

## 提示

- 評分英文對照：`One=1, Two=2, Three=3, Four=4, Five=5`
- 翻頁 URL 格式為：`http://books.toscrape.com/catalogue/page-{n}.html`
  - 但也可以從解析出的 `href` 動態組合，更為穩健。
- 使用 `csv.DictWriter` 寫入，方便欄位對應。
- 記得以 `encoding='utf-8-sig'` 開啟 CSV，避免 Excel 開啟時中文亂碼（本例為英文書名，但養成好習慣）。
- 若 `requests.get()` 失敗，加上 `response.raise_for_status()` 可快速發現問題。

## 完整程式骨架

```python
import requests
from bs4 import BeautifulSoup
import csv
import time

BASE_URL = "http://books.toscrape.com/catalogue/"
RATING_MAP = {"One": 1, "Two": 2, "Three": 3, "Four": 4, "Five": 5}

def get_books_from_page(soup):
    books = []
    for article in soup.select("article.product_pod"):
        title = article.select_one("h3 > a")["title"]
        price = article.select_one(".price_color").text.strip().replace("£", "").replace("Â", "")
        rating_class = article.select_one("p.star-rating")["class"]
        rating = RATING_MAP.get(rating_class[1], 0)
        books.append({"title": title, "price": price, "rating": rating})
    return books

def scrape_all_books():
    all_books = []
    url = "http://books.toscrape.com/catalogue/page-1.html"
    page = 1

    while url:
        print(f"正在爬取第 {page} 頁...")
        response = requests.get(url)
        response.raise_for_status()
        soup = BeautifulSoup(response.text, "html.parser")

        books = get_books_from_page(soup)
        all_books.extend(books)
        print(f"已取得 {len(books)} 筆書籍")

        next_btn = soup.select_one("li.next > a")
        url = BASE_URL + next_btn["href"] if next_btn else None
        page += 1
        time.sleep(1)

    return all_books

def save_to_csv(books, filename="books.csv"):
    with open(filename, "w", newline="", encoding="utf-8-sig") as f:
        writer = csv.DictWriter(f, fieldnames=["title", "price", "rating"])
        writer.writeheader()
        writer.writerows(books)
    print(f"爬取完成，共 {len(books)} 筆書籍已儲存至 {filename}")

if __name__ == "__main__":
    books = scrape_all_books()
    save_to_csv(books)
```
