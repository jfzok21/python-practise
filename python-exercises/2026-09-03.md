# 第 9 週今日 Python 練習題：NumPy 陣列操作與統計分析

## 題目說明

你是一位數據分析師，需要分析一組感測器溫度數據（攝氏）。
這些數據雜亂且有異常值，你需要用 NumPy 進行讀取、清理、轉換與統計分析，
最終輸出一份簡易報告。

---

## 技術要求

- **概念**：ndarray 建立、索引與切片、遮罩（boolean mask）、廣播（broadcasting）、
  向量化運算、統計函數
- **需要的模組**：`numpy`

---

## 具體任務

1. **建立資料陣列**
   用以下原始溫度讀數建立一個 NumPy 一維陣列：
   ```
   [22.1, 23.5, -999, 25.0, 24.8, -999, 26.3, 22.9, 30.1, 28.4,
    19.7, 21.0, -999, 27.6, 25.5, 24.0, 23.1, 26.8, 28.0, 29.5]
   ```
   其中 `-999` 為感測器錯誤，代表無效讀數。

2. **清理無效值**
   使用布林遮罩（boolean mask）過濾掉所有 `-999`，得到乾淨的陣列 `clean_data`。

3. **攝氏轉華氏**
   用向量化公式（不用迴圈）將 `clean_data` 全部轉為華氏，存為 `fahrenheit_data`。
   公式：`F = C × 9/5 + 32`

4. **基本統計分析**
   對 `clean_data` 計算並印出：
   - 平均值（mean）
   - 中位數（median）
   - 標準差（std）
   - 最大值與最小值
   - 超過 27°C 的讀數個數

5. **分組切片**
   假設 20 筆原始資料是按時間順序，每 5 筆為一個時段（共 4 個時段）。
   用切片（slicing）取出第 2 個時段的原始資料，並印出其平均值
   （注意：此時段可能包含 `-999`，需先過濾再計算）。

## 範例

```python
# 預期輸出示意
乾淨資料筆數：17
攝氏平均：25.29°C
攝氏中位數：25.25°C
攝氏標準差：2.87°C
最高溫：30.10°C  最低溫：19.70°C
超過 27°C 的次數：5

第 2 時段（索引 5~9）原始資料：[-999.  26.3  22.9  30.1  28.4]
第 2 時段有效平均：26.93°C

華氏前 5 筆：[71.78 74.3  77.   75.64 74.84]
```

---

## 提示

- 布林遮罩：`mask = arr != -999`，然後 `arr[mask]`
- 向量化不要寫 for 迴圈，直接對整個陣列做四則運算
- `np.mean()`、`np.median()`、`np.std()`、`np.max()`、`np.min()` 都是你的好朋友
- 計算「超過 27°C 的個數」：`np.sum(clean_data > 27)`
- 切片第 2 時段：`arr[5:10]`（Python 索引從 0 開始）

## 學習重點

NumPy 是 Python 數據科學的基石，幾乎所有機器學習框架（sklearn、TensorFlow、PyTorch）
底層都依賴 NumPy 的 ndarray。

- **向量化運算**取代迴圈 → 大幅加速（底層是 C 語言）
- **布林遮罩**是 Pandas 資料清理的前身（下週 Pandas 就是建在 NumPy 上）
- **統計函數**是 ML 中特徵工程（Feature Engineering）的基礎操作
- 爬蟲拿到數據後，通常第一步就是存成陣列 → 用 NumPy/Pandas 清理 → 丟進模型

## 進階挑戰（選做）

1. **Z-score 標準化**：將 `clean_data` 標準化為 Z-score（每個值減去平均、除以標準差），
   找出 Z-score 絕對值超過 1.5 的「可疑讀數」並印出其原始攝氏值。

2. **2D 陣列**：將 `clean_data`（17 筆）補一筆 24.5 湊成 18 筆，
   reshape 成 `(6, 3)` 的二維陣列，計算每一列（每列代表一個時段）的平均值。

3. **np.where**：在原始陣列中，用 `np.where` 把所有 `-999` 替換為整個有效資料的平均值
   （即用均值填補，這是 ML 前處理的常用技巧）。
