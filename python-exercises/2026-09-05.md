# 第 9 週今日 Python 練習題：NumPy 陣列操作與統計分析

## 題目說明

你在分析一批感測器蒐集到的溫度資料（攝氏度）。請使用 NumPy 對這批資料進行基本的陣列建立、操作與統計分析，理解 NumPy 向量化運算的威力，並為後續 Pandas 與資料科學的學習打下基礎。

## 技術要求
- 概念：ndarray、dtype、shape、索引與切片、廣播（broadcasting）、向量化運算、基礎統計函式
- 需要的模組：`numpy`

## 具體任務

1. **建立陣列**：將以下溫度資料轉為 NumPy 陣列，並印出其 `shape`、`dtype`、`ndim`。
   ```
   [22.5, 23.1, 21.8, 24.3, 25.0, 23.7, 22.9, 26.1, 20.5, 24.8,
    23.4, 22.0, 25.5, 21.2, 23.9, 24.6, 22.3, 25.8, 21.9, 23.2]
   ```

2. **單位轉換（廣播運算）**：將所有攝氏溫度轉為華氏（公式：`F = C * 9/5 + 32`），不使用任何迴圈，一行完成。

3. **索引與切片**：
   - 取出前 5 筆和後 5 筆資料
   - 取出索引為偶數的資料（第 0、2、4…筆）
   - 取出所有高於平均值的溫度

4. **統計分析**：計算並印出原始攝氏資料的：
   - 最大值、最小值、平均值、中位數
   - 標準差與變異數
   - 第 25、50、75 百分位數（四分位數）

5. **重塑陣列**：將 20 筆資料 reshape 為 4 列 × 5 行的二維陣列，並計算每列（每天）的平均溫度。

## 範例

```python
import numpy as np

temps = np.array([22.5, 23.1, ...])

# 輸出示範
print(temps.shape)     # (20,)
print(temps.dtype)     # float64
print(temps.ndim)      # 1

temps_f = temps * 9/5 + 32
print(temps_f[:3])     # [72.5 73.58 71.24]

print("平均值:", np.mean(temps))   # 23.575
print("標準差:", np.std(temps))    # 約 1.52

temps_2d = temps.reshape(4, 5)
print("每列平均:", temps_2d.mean(axis=1))
```

## 提示
- `np.array()`、`np.zeros()`、`np.arange()` 是常用的陣列建立方式
- NumPy 的運算是**逐元素**（element-wise）進行的，不需要寫迴圈
- 布林索引：`temps[temps > temps.mean()]` 直接篩選出符合條件的元素
- `axis=0` 是「沿列方向（縱向）」，`axis=1` 是「沿行方向（橫向）」
- `reshape()` 後元素總數必須相同（4×5 = 20）

## 學習重點

NumPy 是整個 Python 資料科學生態的基石：
- **Pandas**（第 10 週）的 DataFrame 底層就是 NumPy 陣列
- **Matplotlib**（第 11 週）直接接受 NumPy 陣列繪圖
- **Scikit-learn**（第 12 週）的所有模型輸入／輸出皆為 NumPy 格式
- 向量化運算比 Python for 迴圈快 10～100 倍，處理大量資料時尤為關鍵
- 網頁爬蟲爬下來的數值資料，通常會轉為 NumPy/Pandas 格式後再進行分析
