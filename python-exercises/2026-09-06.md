# 第 9 週今日 Python 練習題：NumPy 陣列與統計分析

## 題目說明

你是一位資料分析師，需要對一批感測器數據進行清洗與統計分析。這批數據包含溫度、濕度、氣壓三組數據，每組各有 20 筆。你將使用 NumPy 來高效處理這些數值資料，並計算各種統計指標。

## 技術要求

- 概念：NumPy 陣列建立、形狀操作、陣列運算、布林遮罩、統計函式
- 需要的模組：`numpy`（`pip install numpy`）

## 具體任務

1. **建立資料陣列**：使用 `np.array()` 或 `np.random.seed(42)` 搭配 `np.random.normal()` 建立三組各 20 筆的感測器數據（溫度：平均 25°C、標準差 3；濕度：平均 60%、標準差 10；氣壓：平均 1013 hPa、標準差 5）。將三組資料合併成一個形狀為 `(3, 20)` 的二維陣列。

2. **基本統計**：對整個二維陣列以及各「感測器類型」（axis=1）分別計算：
   - 平均值（mean）
   - 標準差（std）
   - 最大值與最小值
   - 中位數（median）

3. **資料正規化**：對每一列（每種感測器數據）進行 **min-max 正規化**，使每列的數值範圍落在 `[0, 1]` 之間。公式：`(x - min) / (max - min)`

4. **異常值偵測**：找出原始數據中距離各自平均值超過 **2 個標準差** 的異常值，印出其索引位置與數值。

5. **陣列切片與運算**：
   - 取出溫度資料（第 0 列）的前 10 筆，計算與後 10 筆的差值
   - 計算溫度與濕度的皮爾森相關係數（使用 `np.corrcoef()`）

## 範例

```python
import numpy as np

np.random.seed(42)

# 建立資料
temp     = np.random.normal(25, 3, 20)    # 溫度
humidity = np.random.normal(60, 10, 20)   # 濕度
pressure = np.random.normal(1013, 5, 20)  # 氣壓

data = np.array([temp, humidity, pressure])  # shape: (3, 20)
print("資料形狀：", data.shape)

# 各感測器平均值
print("各感測器平均值：", data.mean(axis=1))

# 正規化（溫度）
t_min, t_max = temp.min(), temp.max()
temp_norm = (temp - t_min) / (t_max - t_min)
print("溫度正規化後（前5筆）：", temp_norm[:5])

# 異常值偵測（溫度）
mean_t, std_t = temp.mean(), temp.std()
outlier_mask = np.abs(temp - mean_t) > 2 * std_t
print("溫度異常值索引：", np.where(outlier_mask)[0])
print("溫度異常值：", temp[outlier_mask])

# 相關係數
corr = np.corrcoef(temp, humidity)
print("溫度與濕度相關係數：", corr[0, 1])
```

預期輸出（數值依隨機種子而定）：

```
資料形狀： (3, 20)
各感測器平均值： [25.xx 59.xx 1013.xx]
溫度正規化後（前5筆）： [0.xx 0.xx ...]
溫度異常值索引： [...]
相關係數： 0.xx
```

## 提示

- `np.random.seed(42)` 確保每次執行結果一致，方便除錯
- `axis=0` 沿列方向運算（跨列），`axis=1` 沿欄方向運算（跨欄）；對 `(3, 20)` 陣列用 `axis=1` 可得每列一個結果
- `np.abs()` 計算絕對值，搭配比較運算子產生布林陣列（遮罩）
- `np.where(mask)` 回傳 True 位置的索引
- 正規化時注意若 `max == min` 會產生除以零的問題（本題數據不太會遇到，但實務上要處理）
- `np.corrcoef()` 回傳相關矩陣，`[0, 1]` 取出兩變數的相關係數
