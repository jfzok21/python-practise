# 第 9 週今日 Python 練習題：NumPy 陣列基礎操作

## 題目說明

NumPy 是 Python 資料科學最重要的基礎套件之一，提供高效率的多維陣列（ndarray）以及大量數學運算函數。本題帶你熟悉 NumPy 陣列的建立、索引、切片與基本統計，為後續 Pandas 及機器學習打下基礎。

## 技術要求
- 概念：ndarray、dtype、索引、切片、廣播（broadcasting）、基本統計函數
- 需要的模組：`numpy`（`pip install numpy`）

## 具體任務

1. **建立陣列**
   - 使用 `np.array()` 建立一個 1D 整數陣列 `scores`，包含 10 個學生的成績（自訂數值）。
   - 使用 `np.zeros()`、`np.ones()`、`np.arange()` 各建立一個陣列並印出形狀（`.shape`）與資料型態（`.dtype`）。

2. **索引與切片**
   - 印出 `scores` 中第 3 個到第 7 個元素（使用切片）。
   - 找出所有成績大於 75 分的學生成績（使用布林遮罩，Boolean masking）。

3. **基本數學運算**
   - 將 `scores` 每個元素加 5（曲分），並存入新陣列 `adjusted`。
   - 計算 `adjusted` 的總分、平均、最高分、最低分與標準差。

4. **2D 陣列**
   - 建立一個形狀為 `(3, 4)` 的 2D 陣列（可用 `np.random.randint(60, 100, (3, 4))`，代表 3 位學生、4 次考試）。
   - 分別計算每位學生的平均分（按列，`axis=1`）和每次考試的平均分（按欄，`axis=0`）。

5. **陣列重塑**
   - 將 `np.arange(12)` 重塑為 `(3, 4)` 的 2D 陣列，再展平回 1D。

## 範例

```python
import numpy as np

# 任務 1
scores = np.array([82, 91, 67, 78, 55, 88, 73, 95, 61, 84])
print("形狀:", scores.shape)   # (10,)
print("型態:", scores.dtype)   # int64

zeros = np.zeros(5)
ones  = np.ones(5)
rng   = np.arange(0, 10, 2)
print(zeros, ones, rng)

# 任務 2
print("第3到第7個:", scores[2:7])
print("大於75分:", scores[scores > 75])

# 任務 3
adjusted = scores + 5
print("曲分後:", adjusted)
print(f"總分={adjusted.sum()}, 平均={adjusted.mean():.2f}, "
      f"最高={adjusted.max()}, 最低={adjusted.min()}, 標準差={adjusted.std():.2f}")

# 任務 4
np.random.seed(42)
exam = np.random.randint(60, 100, (3, 4))
print("各學生平均:", exam.mean(axis=1))
print("各次考試平均:", exam.mean(axis=0))

# 任務 5
arr = np.arange(12).reshape(3, 4)
print(arr)
print(arr.flatten())
```

輸出示例（部分）：
```
形狀: (10,)
型態: int64
大於75分: [82 91 78 88 95 84]
各學生平均: [79.25 81.5  74.75]
各次考試平均: [74.   83.67 80.   77.  ]
```

## 提示
- NumPy 切片語法與 Python list 相同：`arr[start:stop:step]`。
- 布林遮罩：`arr[arr > 75]` 會回傳所有滿足條件的元素，不需要 for 迴圈。
- `axis=0` 代表沿著「列方向（row）」折疊（對各欄加總），`axis=1` 代表沿著「欄方向（column）」折疊（對各列加總）——初學者容易混淆，可多試幾次。
- `np.random.seed(42)` 讓隨機結果可重現，撰寫測試時很常用。

## 學習重點（與爬蟲／ML 的關聯）

| 概念 | 在 ML 中的用途 |
|---|---|
| ndarray | 儲存特徵矩陣（X）和標籤向量（y） |
| 布林遮罩 | 資料清洗、過濾異常值 |
| `mean / std` | 特徵標準化（StandardScaler 的底層） |
| `reshape` | 調整模型輸入形狀（CNN 常需要 reshape） |
| `axis` 參數 | Pandas `groupby` 運算的概念前身 |

NumPy 是 Pandas、scikit-learn、TensorFlow 等所有主流套件的共同底層，熟練後學習速度將大幅提升。
