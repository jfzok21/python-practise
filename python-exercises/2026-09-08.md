# 第 10 週今日 Python 練習題：電影票房資料分析

## 題目說明

你是一位資料分析師，手邊有一份電影票房資料集。請使用 **Pandas** 載入、清理、篩選並統計這份資料，從中找出票房最佳的電影與導演。

---

## 技術要求

- **概念**：DataFrame 建立、資料讀取（`read_csv`）、欄位選取、過濾（布林索引）、排序（`sort_values`）、分組統計（`groupby`）、缺失值處理（`dropna`、`fillna`）
- **需要的模組**：`pandas`

---

## 具體任務

1. **建立資料集**：用下方提供的字典清單建立一個 DataFrame，或將其寫成 CSV 再用 `pd.read_csv()` 讀入。
2. **基本探索**：
   - 印出前 5 筆資料（`head()`）
   - 印出 DataFrame 的形狀與欄位型態（`shape`、`dtypes`）
   - 印出各欄位的基本統計（`describe()`）
3. **資料清理**：
   - 找出並移除票房（`gross_million`）欄位中的缺失值。
4. **篩選與排序**：
   - 篩選出評分（`rating`）大於等於 7.5 的電影。
   - 將結果依票房由高到低排序，印出前 5 名。
5. **分組統計**：
   - 使用 `groupby('director')` 計算每位導演的**平均評分**與**總票房**。
   - 找出總票房最高的導演。

---

## 範例

```python
import pandas as pd

data = {
    'title':        ['星際大戰', '魔戒', '阿凡達', '黑暗騎士', '侏羅紀公園', '鋼鐵人', '復仇者聯盟'],
    'director':     ['盧卡斯', '傑克森', '柯麥隆', '諾蘭', '史匹柏', '法夫洛', '喬斯溫登'],
    'year':         [1977, 2001, 2009, 2008, 1993, 2008, 2012],
    'rating':       [8.6, 8.8, 7.8, 9.0, 8.1, 7.9, 8.0],
    'gross_million':[775, 888, 2923, 1005, 1030, 585, None],
}

df = pd.DataFrame(data)
print(df.head())
# 預期輸出：
#       title director  year  rating  gross_million
# 0    星際大戰    盧卡斯  1977     8.6          775.0
# 1      魔戒    傑克森  2001     8.8          888.0
# ...

# 移除缺失值
df_clean = df.dropna(subset=['gross_million'])

# 評分 >= 7.5，依票房排序
top5 = df_clean[df_clean['rating'] >= 7.5].sort_values('gross_million', ascending=False).head(5)
print(top5[['title', 'rating', 'gross_million']])

# 依導演分組
director_stats = df_clean.groupby('director').agg(
    avg_rating=('rating', 'mean'),
    total_gross=('gross_million', 'sum')
).sort_values('total_gross', ascending=False)
print(director_stats)
```

---

## 提示

- `pd.DataFrame(字典)` 可以直接從字典建立 DataFrame。
- 布林索引：`df[df['欄位'] > 值]` 是 Pandas 篩選資料最常用的寫法。
- `groupby().agg()` 可以同時計算多個統計量，比 `groupby().mean()` 更靈活。
- 記得在 `dropna()` 加上 `subset` 參數，只針對特定欄位移除，避免誤刪其他完整列。

---

## 學習重點（跟爬蟲／ML 的關聯）

| 概念 | 爬蟲應用 | ML 應用 |
|------|----------|---------|
| `read_csv` | 讀取爬蟲輸出的 CSV 結果 | 載入訓練資料集 |
| `dropna` / `fillna` | 清理網頁擷取的不完整欄位 | 特徵工程前的資料清洗 |
| `groupby` | 彙整多頁爬蟲抓到的同類資料 | 按類別統計特徵分布 |
| `sort_values` | 快速找出排名最高的項目 | 模型特徵重要性排序 |
