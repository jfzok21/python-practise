# 第 10 週今日 Python 練習題：用 Pandas 分析商品銷售資料

## 題目說明

你是一間小型電商的資料分析師。你手上有一份產品銷售記錄，需要用 Pandas 載入、整理並分析資料，找出熱銷商品與月份趨勢。

---

## 技術要求

- **概念**：DataFrame 建立與讀取、欄位選取、條件篩選、groupby 聚合、排序、基本統計
- **需要的模組**：`pandas`、`io`（標準函式庫）

---

## 具體任務

1. 用以下原始資料建立一個 Pandas DataFrame（直接貼在程式碼裡，不需要讀外部檔案）。
2. 顯示 DataFrame 的前 5 筆資料與基本資訊（`.head()`、`.info()`、`.describe()`）。
3. 篩選出 **單筆銷售額（`total`）超過 500 元** 的所有訂單。
4. 計算每個 **商品類別（`category`）的總銷售額**，並由高到低排序。
5. 找出 **銷售量（`quantity`）最高的前 3 筆** 訂單（顯示所有欄位）。
6. 新增一欄 `discount_price`，代表打九折後的單價（`price * 0.9`）。
7. 將最終 DataFrame 存成 `sales_result.csv`（不含 index）。

---

## 範例資料

```python
import pandas as pd

data = {
    "order_id": [1001, 1002, 1003, 1004, 1005, 1006, 1007, 1008, 1009, 1010],
    "product":  ["筆電", "滑鼠", "鍵盤", "筆電", "耳機", "滑鼠", "螢幕", "鍵盤", "耳機", "螢幕"],
    "category": ["電腦", "周邊", "周邊", "電腦", "音訊", "周邊", "電腦", "周邊", "音訊", "電腦"],
    "price":    [25000, 350, 1200, 28000, 890, 400, 8500, 950, 1200, 9000],
    "quantity": [1, 3, 2, 1, 4, 5, 1, 3, 2, 2],
}

df = pd.DataFrame(data)
df["total"] = df["price"] * df["quantity"]  # 計算總銷售額
```

## 提示

- 用 `df[df["total"] > 500]` 進行條件篩選。
- `groupby("category")["total"].sum()` 可以做分組加總。
- `.sort_values("quantity", ascending=False).head(3)` 取前 3 名。
- 新增欄位直接用 `df["discount_price"] = df["price"] * 0.9`。
- 存 CSV：`df.to_csv("sales_result.csv", index=False)`。

## 學習重點（與爬蟲／ML 的關聯）

| 技能 | 實際應用 |
|------|---------|
| `groupby` + `sum` | 爬下多頁商品後，按品牌彙總評分或價格 |
| 條件篩選 | 清洗爬蟲資料，去除異常值或缺漏欄位 |
| 新增計算欄 | ML 前的特徵工程（Feature Engineering） |
| 存成 CSV | 提供給 sklearn / matplotlib 使用 |

Pandas 是 Python 資料科學的核心工具：爬蟲把原始資料抓回來，Pandas 負責清洗與整理，再餵給 ML 模型或視覺化套件。

## 進階挑戰（選做）

1. **月份分析**：在 `data` 中加入 `order_date` 欄位（隨意填 10 個日期），轉成 `datetime` 型態後，用 `dt.month` 抽出月份，再統計各月份總銷售額。
2. **樞紐分析表**：用 `pd.pivot_table()` 製作「商品 × 月份」的銷售量交叉表。
3. **缺漏值處理**：故意在某幾筆 `price` 欄位填入 `None`，練習用 `.isna()`、`.fillna()`、`.dropna()` 處理缺漏值。
4. **合併 DataFrame**：建立第二個 DataFrame 存放「商品 → 供應商」對應，用 `pd.merge()` 合併到主表。
