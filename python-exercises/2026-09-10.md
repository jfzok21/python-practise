# 第 10 週今日 Python 練習題：用 Pandas 分析銷售資料

## 題目說明

你剛加入一間電商公司的數據分析團隊，主管給了你一份銷售記錄 CSV，要求你用 Pandas 快速分析各類別商品的銷售表現，並找出高價值訂單。

---

## 技術要求

- **概念**：DataFrame 建立、讀取 CSV、欄位選取、條件篩選、groupby 聚合、排序、描述統計
- **需要的模組**：`pandas`、`io`（標準庫）

---

## 具體任務

1. **建立 DataFrame**：將下方提供的 CSV 字串用 `pd.read_csv()` 搭配 `io.StringIO` 讀入。
2. **基本探索**：
   - 印出前 5 筆資料（`head()`）
   - 印出資料形狀（行數、欄數）
   - 印出各欄位型別（`dtypes`）
3. **描述統計**：對 `金額` 欄位印出 `describe()`，觀察平均、最大值等。
4. **條件篩選**：找出金額 ≥ 500 的訂單，印出結果筆數。
5. **GroupBy 分析**：
   - 以 `類別` 為分組，計算每個類別的「總銷售額」與「平均金額」。
   - 依「總銷售額」由高到低排序後印出。
6. **新增欄位**：在原始 DataFrame 新增 `是否高價值` 欄位（金額 ≥ 500 時為 `True`，否則為 `False`）。
7. **輸出結果**：將步驟 5 的分析結果存成 `category_summary.csv`。

---

## 範例

```python
import pandas as pd
import io

csv_data = """訂單ID,類別,商品,金額,數量
1001,電子,手機,8900,1
1002,服飾,T恤,299,3
1003,電子,耳機,1200,2
1004,食品,咖啡豆,450,5
1005,服飾,牛仔褲,890,1
1006,食品,茶葉,180,10
1007,電子,鍵盤,650,1
1008,服飾,外套,1500,1
1009,食品,巧克力,99,20
1010,電子,滑鼠,320,2
"""

df = pd.read_csv(io.StringIO(csv_data))

# 步驟 2
print(df.head())
print("形狀：", df.shape)
print(df.dtypes)

# 步驟 3
print(df['金額'].describe())

# 步驟 4
high_value = df[df['金額'] >= 500]
print("高金額訂單數：", len(high_value))

# 步驟 5
summary = df.groupby('類別')['金額'].agg(總銷售額='sum', 平均金額='mean')
summary = summary.sort_values('總銷售額', ascending=False)
print(summary)

# 步驟 6
df['是否高價值'] = df['金額'] >= 500
print(df[['訂單ID', '商品', '金額', '是否高價值']])

# 步驟 7
summary.to_csv('category_summary.csv')
print("已存檔 category_summary.csv")
```

**預期輸出（部分）：**
```
類別
電子    11070
服飾     2689
食品      729
```

---

## 提示

- `pd.read_csv(io.StringIO(字串))` 可以不依賴實體 CSV 檔案，直接從字串讀取。
- `groupby('欄位')['目標欄位'].agg(名稱=函數)` 是多重聚合的慣用寫法。
- 新增欄位可直接用條件運算：`df['新欄位'] = df['欄位'] > 值`，Pandas 會自動產生布林 Series。
- `sort_values('欄位', ascending=False)` 代表由大到小。
