# 第 10 週今日 Python 練習題：用 Pandas 分析電商銷售資料

## 題目說明

你是一家小型電商平台的資料分析師。主管給了你一份銷售記錄，請你用 Pandas 讀取資料、清洗、彙總，並回答幾個業務問題。

---

## 技術要求

- **概念**：DataFrame 建立、欄位選取、條件篩選、groupby 彙總、排序、缺失值處理
- **需要的模組**：`pandas`、`io`（標準庫，用來模擬讀取 CSV）

---

## 具體任務

1. **建立資料集**：用以下 CSV 字串（或另存為 `sales.csv`）建立一個 Pandas DataFrame。
2. **資料清洗**：找出並移除 `revenue`（營收）欄位中的缺失值（NaN）。
3. **基本統計**：計算每個 `category`（分類）的總營收和平均訂單數。
4. **排行榜**：找出「總營收前 3 名」的產品（`product`）。
5. **條件篩選**：列出所有 `revenue` 超過 1000 且 `region`（地區）為 `"北部"` 的訂單。
6. **新增欄位**：新增一欄 `profit`，計算方式為 `revenue * 0.3`（利潤率 30%）。

---

## 範例

```python
import pandas as pd
from io import StringIO

csv_data = """order_id,product,category,region,orders,revenue
1001,藍牙耳機,電子,北部,25,3750.0
1002,保溫杯,生活,南部,40,2800.0
1003,瑜珈墊,運動,北部,18,1620.0
1004,機械鍵盤,電子,中部,12,4200.0
1005,棉質T恤,服飾,北部,60,1800.0
1006,乳清蛋白,運動,南部,30,4500.0
1007,料理鍋,生活,中部,22,
1008,無線滑鼠,電子,北部,35,2975.0
1009,瑜珈球,運動,北部,14,840.0
1010,羽絨外套,服飾,中部,19,5320.0
"""

df = pd.read_csv(StringIO(csv_data))
print(df.head())
print(df.dtypes)
```

**預期部分輸出（任務 3）：**
```
category    revenue_sum  orders_mean
電子         10925.0      24.000000
服飾          7120.0      39.500000
運動          6960.0      20.666667
生活          2800.0      31.000000   ← 料理鍋已移除（NaN）
```

---

## 提示

- 用 `df.isnull().sum()` 確認哪些欄位有缺失值。
- `df.dropna(subset=['revenue'], inplace=True)` 可移除指定欄位含 NaN 的列。
- `df.groupby('category').agg({'revenue': 'sum', 'orders': 'mean'})` 是彙總的關鍵。
- 排行榜可用 `.sort_values('revenue', ascending=False).head(3)` 完成。
- 條件篩選：`df[(df['revenue'] > 1000) & (df['region'] == '北部')]`。
- 新增欄位：`df['profit'] = df['revenue'] * 0.3`。

## 學習重點

**與爬蟲 / ML 的關聯：**

- 爬蟲爬回來的原始資料常有空值、格式不一致，Pandas 的清洗技巧（`dropna`、`fillna`、型別轉換）是後續分析的基礎。
- ML 的特徵工程（Feature Engineering）大量使用 `groupby` 計算聚合特徵（如「該地區過去平均消費」），是第 12 週 sklearn 的前置準備。
- `DataFrame` 是 sklearn 模型訓練的主要輸入格式之一，熟悉欄位操作能讓資料準備事半功倍。
