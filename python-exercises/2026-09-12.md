# 第 10 週今日 Python 練習題：Pandas 資料合併與時間序列分析

## 題目說明

你是一間連鎖書店的資料工程師。書店有兩份 CSV：一份記錄每日銷售量，另一份記錄書籍的基本資訊。你的任務是將兩份資料合併，並進行時間序列的彙總與趨勢分析。

---

## 技術要求

- **概念**：`pd.merge`（資料合併）、`pd.to_datetime`、`resample`、`dt` 存取器、`fillna`、`sort_values`
- **需要的模組**：`pandas`、`io`（標準庫）

---

## 具體任務

1. **建立兩個 DataFrame**：分別從下方 CSV 字串建立「銷售記錄」與「書籍資訊」。
2. **資料合併**：以 `book_id` 為鍵，用 `pd.merge` 將兩份資料合併為一個 DataFrame。
3. **日期轉換**：將 `sale_date` 欄位轉為 `datetime` 型別，並設為 DataFrame 的索引。
4. **月份彙總**：用 `resample('ME')` 計算每月各類別（`genre`）的總銷售量。
5. **缺失值補值**：銷售記錄中某些 `quantity`（數量）為 NaN，請用該書籍的平均銷售量補齊。
6. **找出暢銷日**：找出單日總銷售量最高的前 3 天及其銷售數字。

---

## 範例

```python
import pandas as pd
from io import StringIO

# 銷售記錄
sales_csv = """sale_id,book_id,sale_date,quantity
S001,B01,2026-07-03,12
S002,B02,2026-07-03,8
S003,B03,2026-07-05,
S004,B01,2026-07-10,20
S005,B04,2026-07-10,15
S006,B02,2026-07-15,11
S007,B03,2026-07-20,9
S008,B04,2026-07-20,
S009,B01,2026-08-01,25
S010,B02,2026-08-05,6
S011,B03,2026-08-12,14
S012,B04,2026-08-20,18
"""

# 書籍資訊
books_csv = """book_id,title,genre,price
B01,Python 入門,技術,450
B02,深夜的咖啡館,小說,320
B03,健康飲食指南,生活,380
B04,世界史地圖集,知識,520
"""

sales_df = pd.read_csv(StringIO(sales_csv))
books_df = pd.read_csv(StringIO(books_csv))

print(sales_df.head())
print(books_df)
```

**預期部分輸出（任務 4，月份彙總）：**
```
genre      知識   小說   技術   生活
sale_date
2026-07-31  15.0  19.0  32.0  9.0
2026-08-31  18.0   6.0  25.0 14.0
```

---

## 提示

- `pd.merge(sales_df, books_df, on='book_id', how='left')` — `how='left'` 保留所有銷售記錄。
- `df['sale_date'] = pd.to_datetime(df['sale_date'])` 轉換日期型別。
- 設為索引後才能使用 `resample`：`df.set_index('sale_date', inplace=True)`。
- 用 `groupby` 搭配 `transform('mean')` 計算各書籍的平均銷售量，再用 `fillna` 填補。
- 暢銷日：先 `resample('D')['quantity'].sum()`，再 `.sort_values(ascending=False).head(3)`。

---

## 學習重點

**與爬蟲 / ML 的關聯：**

- 爬蟲資料常需要「合併多個來源」（例如商品頁面 + 評價頁面），`pd.merge` / `pd.concat` 是核心工具。
- 時間序列彙總（`resample`）是 ML 中「特徵窗口構造」的基礎，例如「過去 30 天平均銷量」作為預測特徵。
- 缺失值補值策略（平均值、中位數、前向填充 `ffill`）直接影響 sklearn 模型的訓練品質。
