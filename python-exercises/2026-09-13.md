# 第 10 週今日 Python 練習題：用 Pandas 分析銷售數據

## 題目說明

你是一家網路書店的數據分析師。老闆給了你一份銷售記錄，需要你用 Pandas 做基本的數據整理與分析，找出熱門書籍、月份銷售趨勢，並輸出摘要報告。

## 技術要求
- 概念：DataFrame 建立、資料讀取、欄位篩選、groupby、排序、基本統計、條件篩選
- 需要的模組：`pandas`、`io`（標準庫，用於模擬 CSV 字串）

## 具體任務

1. 用以下 CSV 字串建立一個 Pandas DataFrame（模擬從檔案讀取）
2. 顯示前 5 筆資料（`head()`）及基本資訊（`info()`、`describe()`）
3. 計算每本書的**總銷售額**（`price × quantity`），新增為 `total` 欄位
4. 找出**銷售額前 3 名**的書籍
5. 用 `groupby` 計算**每個月份**的總銷售額
6. 篩選出**單筆金額超過 500 元**的訂單
7. 將結果輸出為 `sales_report.csv`

## 範例

```python
import pandas as pd
from io import StringIO

csv_data = """date,title,price,quantity
2026-01-05,Python入門,350,3
2026-01-12,資料科學實戰,580,2
2026-02-03,機器學習基礎,620,1
2026-02-18,網頁爬蟲秘笈,420,4
2026-03-07,Python入門,350,5
2026-03-15,資料科學實戰,580,3
2026-03-22,演算法圖解,490,2
2026-04-01,機器學習基礎,620,2
2026-04-10,網頁爬蟲秘笈,420,1
2026-04-25,演算法圖解,490,3"""

df = pd.read_csv(StringIO(csv_data))

# 任務 3：新增 total 欄位
df['total'] = df['price'] * df['quantity']

# 任務 4：各書籍總銷售額前 3 名
top3 = df.groupby('title')['total'].sum().sort_values(ascending=False).head(3)
print("=== 銷售額前 3 名 ===")
print(top3)

# 任務 5：每月銷售額
df['month'] = pd.to_datetime(df['date']).dt.to_period('M')
monthly = df.groupby('month')['total'].sum()
print("\n=== 每月銷售額 ===")
print(monthly)

# 輸出（預期）：
# === 銷售額前 3 名 ===
# title
# 資料科學實戰    2900
# Python入門     2800
# 機器學習基礎   1860
# Name: total, dtype: int64
```

## 提示
- `pd.read_csv(StringIO(csv_data))` 可以直接從字串讀取 CSV，不需要實體檔案
- `df['新欄位'] = df['A'] * df['B']` 可以直接做欄位運算
- `groupby('欄位')['數值欄位'].sum()` 是最常用的分組加總方式
- `pd.to_datetime()` 將字串轉換為日期，再用 `.dt.to_period('M')` 取得月份
- `df[df['total'] > 500]` 是條件篩選的基本寫法
- `df.to_csv('檔名.csv', index=False)` 輸出 CSV 時加上 `index=False` 避免輸出列號

## 學習重點

Pandas 是爬蟲與 ML 的核心工具：
- **爬蟲應用**：將抓下來的商品列表、新聞標題、股票數據直接存入 DataFrame，快速清理與分析
- **ML 前置處理**：ML 模型需要的特徵工程（新增欄位、groupby 統計、篩選異常值）都靠 Pandas 完成
- `groupby` 的概念與 SQL 的 `GROUP BY` 相同，學會後可無縫轉換
