## 具體任務

### 準備資料
先在程式中建立以下字典並轉為 DataFrame（不需要外部 CSV 檔）：

```python
data = {
    "title":    ["寄生上流", "鈦", "沙丘", "蜘蛛人：新宇宙", "魔鬼終結者：黑暗命運",
                 "奧本海默", "芭比", "星際效應", "獵人克萊文", "蜘蛛人：無家日"],
    "year":     [2019, 2021, 2021, 2018, 2019, 2023, 2023, 2014, 2024, 2021],
    "genre":    ["劇情", "劇情", "科幻", "動畫", "動作", "劇情", "喜劇", "科幻", "動作", "動作"],
    "rating":   [8.6, 6.8, 8.0, 8.4, 6.2, 8.9, 7.0, 8.7, 5.2, 8.2],
    "box_office_M": [258, 9, 401, 375, 261, 952, 1441, 677, 26, 1901]
}
```

### 任務清單

1. **基本資訊**：用 `.shape`、`.dtypes`、`.describe()` 印出 DataFrame 的基本資訊。

2. **條件篩選**：找出評分（rating）≥ 8.0 的電影，印出片名與評分。

3. **排序**：將所有電影依票房（box_office_M）由高到低排序，印出前 5 名。

4. **新增欄位**：新增一欄 `is_blockbuster`，當票房 ≥ 500M 時為 `True`，否則為 `False`。

5. **分組統計**：依 `genre` 分組，計算每個類型的平均評分與票房總和，並排序結果。

6. **篩選 + 統計**：找出 2020 年以後（含）上映、且票房超過 300M 的電影，計算有幾部。

---

## 範例

```python
# 建立 DataFrame
import pandas as pd

data = { ... }  # 同上
df = pd.DataFrame(data)

# 任務 2：高評分電影
high_rated = df[df["rating"] >= 8.0][["title", "rating"]]
print(high_rated)
# 輸出範例：
#          title  rating
# 0       寄生上流     8.6
# 2         沙丘     8.0
# 3  蜘蛛人：新宇宙     8.4
# 5       奧本海默     8.9
# 7       星際效應     8.7
# 9   蜘蛛人：無家日     8.2

# 任務 5：分組統計
genre_stats = df.groupby("genre").agg(
    avg_rating=("rating", "mean"),
    total_box_office=("box_office_M", "sum")
).sort_values("avg_rating", ascending=False)
print(genre_stats)
```

---

## 提示

- `df[df["欄位"] >= 值]` 是條件篩選的標準寫法
- `.agg()` 可以同時計算多個統計量，配合命名輸出更清楚
- 新增欄位：`df["is_blockbuster"] = df["box_office_M"] >= 500`
- 多條件篩選用 `&`（且）或 `|`（或），並用括號包住每個條件：`(條件A) & (條件B)`
- `.sort_values("欄位", ascending=False)` 做降冪排序
