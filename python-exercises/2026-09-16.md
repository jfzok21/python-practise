# 第 11 週今日 Python 練習題：氣溫趨勢視覺化儀表板

## 題目說明

你從氣象網站爬取了過去 30 天的每日最高溫與最低溫資料（CSV 格式）。本次練習將用 matplotlib 將這些資料視覺化，製作一份包含多個子圖的氣溫分析儀表板，讓你能一眼看出氣溫趨勢與分布。

## 技術要求
- 概念：折線圖、長條圖、直方圖、子圖排版、圖例、標題、軸標籤、顏色設定
- 需要的模組：`matplotlib.pyplot`、`pandas`、`numpy`

## 具體任務

1. **準備資料**：建立（或讀取）一個包含以下欄位的 DataFrame：
   - `date`：日期（字串，如 `"2026-08-17"`）
   - `max_temp`：最高溫（°C）
   - `min_temp`：最低溫（°C）
   
   若無真實資料，用 `numpy.random` 模擬 30 天資料（最高溫範圍 28–38°C，最低溫範圍 22–30°C）。

2. **建立 2×2 子圖版面**（`plt.subplots(2, 2, figsize=(14, 10))`），分別繪製：
   - **左上**：最高溫與最低溫的折線圖（雙線），加上圖例
   - **右上**：每日溫差（max - min）的長條圖，依溫差大小設定顏色深淺
   - **左下**：最高溫的直方圖（bins=8），顯示溫度分布
   - **右下**：最高溫與最低溫的散點圖，加上趨勢線（用 `numpy.polyfit`）

3. **美化**：為每個子圖加上標題、x 軸標籤、y 軸標籤；x 軸日期標籤旋轉 45 度避免重疊；整體加上大標題 `plt.suptitle()`。

4. **儲存**：將圖表存成 `temperature_dashboard.png`（dpi=150）。

## 範例

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import matplotlib.dates as mdates

# 模擬資料
np.random.seed(42)
dates = pd.date_range("2026-08-17", periods=30)
max_temps = np.random.randint(28, 39, 30).astype(float)
min_temps = max_temps - np.random.randint(5, 12, 30)

df = pd.DataFrame({"date": dates, "max_temp": max_temps, "min_temp": min_temps})

# 建立子圖
fig, axes = plt.subplots(2, 2, figsize=(14, 10))
fig.suptitle("過去 30 天氣溫分析儀表板", fontsize=16, fontweight="bold")

# 左上：折線圖
ax = axes[0, 0]
ax.plot(df["date"], df["max_temp"], label="最高溫", color="tomato", marker="o", markersize=3)
ax.plot(df["date"], df["min_temp"], label="最低溫", color="steelblue", marker="o", markersize=3)
ax.set_title("每日最高 / 最低溫趨勢")
ax.set_xlabel("日期")
ax.set_ylabel("溫度 (°C)")
ax.legend()
ax.xaxis.set_major_formatter(mdates.DateFormatter("%m/%d"))
plt.setp(ax.xaxis.get_majorticklabels(), rotation=45)

# ... 其餘子圖類似

plt.tight_layout()
plt.savefig("temperature_dashboard.png", dpi=150)
print("圖表已儲存：temperature_dashboard.png")
```

```
圖表已儲存：temperature_dashboard.png
```

## 提示

- 中文字型問題：若圖表中文顯示為方塊，可加上：
  ```python
  plt.rcParams["font.family"] = ["Arial Unicode MS", "sans-serif"]
  ```
- `axes[0, 0]` 對應左上，`axes[0, 1]` 對應右上，以此類推
- 長條圖顏色依數值深淺：可用 `cmap = plt.cm.YlOrRd`，再透過 `norm` 將溫差值對應到顏色
- 趨勢線：`z = np.polyfit(x, y, 1); p = np.poly1d(z)`，再畫 `ax.plot(x, p(x))`
- `plt.tight_layout()` 需在 `plt.suptitle()` 之後呼叫，或用 `rect=[0,0,1,0.96]` 避免大標題被蓋住
