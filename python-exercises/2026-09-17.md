# 第 11 週今日 Python 練習題：用 Matplotlib 分析並視覺化氣溫資料

## 題目說明

你拿到一份過去 30 天的每日最高氣溫資料（模擬數據）。請使用 `matplotlib` 繪製折線圖與長條圖，並標示出最高溫與最低溫，讓資料一目了然。

---

## 技術要求

- **概念**：資料視覺化、子圖（subplot）、標記特殊資料點、圖表美化
- **需要的模組**：`matplotlib.pyplot`、`numpy`（可選）

---

## 具體任務

1. 建立過去 30 天的模擬氣溫資料（可用 `random` 或 `numpy` 生成，範圍 20–38°C）。
2. 繪製一個折線圖，X 軸為「第 1 天」到「第 30 天」，Y 軸為氣溫（°C）。
3. 在折線圖上用不同顏色標記出：
   - 最高溫那天（紅色點 + 標籤）
   - 最低溫那天（藍色點 + 標籤）
4. 在同一畫布（figure）的下方再繪製一個長條圖（bar chart），顯示每日氣溫。
5. 替兩張子圖加上標題、X/Y 軸標籤與格線（grid），並輸出成 `temperature_report.png`。

---

## 範例

```python
# 執行後產生 temperature_report.png，內含：
# 上方：折線圖，標出最高/最低溫
# 下方：長條圖，顯示各天氣溫

import matplotlib.pyplot as plt
import random

random.seed(42)
days = list(range(1, 31))
temps = [random.uniform(20, 38) for _ in days]

max_idx = temps.index(max(temps))
min_idx = temps.index(min(temps))

fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(12, 8))

# 折線圖
ax1.plot(days, temps, color='orange', linewidth=2, label='氣溫')
ax1.scatter(days[max_idx], temps[max_idx], color='red', zorder=5)
ax1.annotate(f'最高 {temps[max_idx]:.1f}°C', xy=(days[max_idx], temps[max_idx]),
             xytext=(days[max_idx]+1, temps[max_idx]+0.5), color='red')
ax1.scatter(days[min_idx], temps[min_idx], color='blue', zorder=5)
ax1.annotate(f'最低 {temps[min_idx]:.1f}°C', xy=(days[min_idx], temps[min_idx]),
             xytext=(days[min_idx]+1, temps[min_idx]-1.5), color='blue')
ax1.set_title('過去 30 天每日最高氣溫（折線圖）')
ax1.set_xlabel('天數')
ax1.set_ylabel('氣溫 (°C)')
ax1.grid(True, linestyle='--', alpha=0.6)
ax1.legend()

# 長條圖
ax2.bar(days, temps, color='steelblue', alpha=0.7)
ax2.set_title('過去 30 天每日最高氣溫（長條圖）')
ax2.set_xlabel('天數')
ax2.set_ylabel('氣溫 (°C)')
ax2.grid(axis='y', linestyle='--', alpha=0.6)

plt.tight_layout()
plt.savefig('temperature_report.png', dpi=150)
print("圖表已儲存：temperature_report.png")
```

**預期輸出：**
```
圖表已儲存：temperature_report.png
```

---

## 提示

- `plt.subplots(2, 1, figsize=(12, 8))` 可建立上下兩個子圖。
- `ax.scatter()` 用來標記特殊點，`zorder=5` 讓點畫在折線上方。
- `ax.annotate()` 可以在圖上加文字說明，`xytext` 控制文字位置。
- `plt.tight_layout()` 自動調整子圖間距，避免標題重疊。
- 存檔用 `plt.savefig()`，顯示用 `plt.show()`（兩者可同時使用）。
