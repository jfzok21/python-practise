# 第 11 週今日 Python 練習題：氣象資料視覺化儀表板

## 題目說明

你手上有一份台灣各城市的月均溫與降雨量資料（以 dict 形式提供）。請使用 `matplotlib` 建立一個包含多張子圖的視覺化儀表板，同時呈現折線圖與長條圖，讓資料一目了然。

## 技術要求
- 概念：matplotlib 子圖（subplots）、折線圖（plot）、長條圖（bar）、圖表標題、軸標籤、圖例、樣式設定
- 需要的模組：`matplotlib.pyplot`、`numpy`（選用）

## 具體任務

1. **準備資料**：使用以下字典作為資料來源：
   ```python
   months = ['1月', '2月', '3月', '4月', '5月', '6月',
             '7月', '8月', '9月', '10月', '11月', '12月']
   taipei_temp  = [16, 17, 19, 23, 26, 29, 32, 31, 28, 25, 21, 17]
   taichung_temp = [15, 16, 19, 23, 26, 29, 31, 31, 28, 24, 20, 16]
   kaohsiung_temp = [19, 21, 23, 26, 28, 30, 30, 30, 29, 27, 24, 20]
   taipei_rain  = [82, 140, 165, 155, 225, 295, 225, 280, 360, 150, 90, 75]
   ```

2. **建立 2×1 子圖** (`plt.subplots(2, 1, figsize=(12, 8))`）：
   - **上圖（折線圖）**：繪製台北、台中、高雄三城市全年月均溫折線圖，每條線使用不同顏色與標記（marker）。
   - **下圖（長條圖）**：繪製台北全年月降雨量長條圖，並為超過 200mm 的月份標上不同顏色（如橘色警示）。

3. **完善圖表細節**：
   - 每張子圖加上繁體中文標題、X 軸（月份）與 Y 軸標籤（℃ / mm）
   - 折線圖加上圖例
   - 設定整份圖表的主標題（`fig.suptitle`）
   - 呼叫 `plt.tight_layout()` 避免重疊

4. **儲存圖片**：將圖表存為 `weather_dashboard.png`（`plt.savefig`），並用 `plt.show()` 顯示。

## 範例

```python
# 預期輸出（儲存檔案）
# weather_dashboard.png — 包含折線圖與長條圖的儀表板

import matplotlib.pyplot as plt
import matplotlib

# 若系統支援中文字型，可指定字型避免亂碼
# matplotlib.rcParams['font.family'] = 'Noto Sans CJK TC'

months = ['1月', '2月', '3月', '4月', '5月', '6月',
          '7月', '8月', '9月', '10月', '11月', '12月']
taipei_temp = [16, 17, 19, 23, 26, 29, 32, 31, 28, 25, 21, 17]
# ... 其餘資料同上

fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(12, 8))

# 折線圖
ax1.plot(months, taipei_temp, marker='o', color='steelblue', label='台北')
# ... 其餘城市

# 長條圖（顏色依降雨量條件設定）
colors = ['orange' if r > 200 else 'cornflowerblue' for r in taipei_rain]
ax2.bar(months, taipei_rain, color=colors)

plt.tight_layout()
plt.savefig('weather_dashboard.png', dpi=150)
plt.show()
```

## 提示
- `plt.subplots(2, 1)` 傳回 `(fig, axes)`，其中 `axes` 是含兩個 `Axes` 物件的陣列，也可用 `(ax1, ax2)` 解包。
- 使用 `ax.set_title()`、`ax.set_xlabel()`、`ax.set_ylabel()` 設定各子圖標籤。
- 長條圖顏色可用 list comprehension 動態決定：`colors = ['orange' if r > 200 else 'steelblue' for r in data]`。
- 若中文顯示為方塊，可在程式開頭加 `matplotlib.rcParams['font.sans-serif'] = ['DejaVu Sans']` 並改用英文標籤，或安裝 `fonts-noto-cjk`。
- `plt.savefig()` 要在 `plt.show()` **之前**呼叫，否則儲存的會是空白圖。

## 學習重點

### 與資料分析／ML 的關聯
資料視覺化是 ML 流程中**不可或缺**的一步：
- **探索性資料分析（EDA）**：在訓練模型前，用折線圖觀察時序趨勢、用長條圖比較類別分佈，快速發現異常值或季節性規律。
- **模型評估**：繪製學習曲線（loss vs. epoch）、混淆矩陣熱力圖、ROC 曲線，都需要 `matplotlib`。
- **呈現結果**：下週學 pandas 後，可直接對 DataFrame 呼叫 `.plot()`，底層即使用 matplotlib；再往後的 sklearn 也以 matplotlib 繪製決策邊界與特徵重要性圖。
