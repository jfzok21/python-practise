# 第 11 週今日 Python 練習題：氣候數據視覺化儀表板

## 題目說明

你獲得了一份台灣各城市 2025 年每月平均氣溫與降雨量的數據集。  
請使用 `matplotlib` 建立一個多圖表儀表板，清楚地呈現這些氣候趨勢，  
並讓讀者能快速比較不同城市之間的差異。

---

## 技術要求
- **概念**：折線圖、長條圖、子圖（subplots）、圖例、標題、軸標籤、顏色設定
- **需要的模組**：`matplotlib.pyplot`、`numpy`（可選，輔助計算）

## 具體任務

1. **準備數據**：在程式中直接定義以下字典結構（無需讀檔）：
   ```python
   data = {
       "台北": {
           "months": list(range(1, 13)),
           "temp":  [16, 17, 19, 23, 27, 30, 33, 32, 29, 25, 21, 17],
           "rain":  [83, 122, 165, 172, 237, 284, 198, 243, 212, 107, 80, 70],
       },
       "台中": {
           "months": list(range(1, 13)),
           "temp":  [15, 17, 20, 24, 27, 30, 32, 32, 29, 25, 21, 16],

       "高雄": {
           "months": list(range(1, 13)),

           "rain":  [16, 22, 31, 56, 168, 394, 421, 360, 195, 33, 12, 9],
       },
   }
   ```

2. **建立 2×2 子圖儀表板**，包含以下四個圖：
   - **左上（折線圖）**：三個城市全年月均溫對比，不同城市用不同顏色線條。
   - **右上（群組長條圖）**：三個城市全年月降雨量對比（每個月並排三個城市的長條）。
   - **左下（區域圖）**：台北的月均溫折線，並用 `fill_between` 填滿曲線下方區域（半透明）。
   - **右下（水平長條圖）**：計算各城市全年總降雨量，以水平長條圖呈現，並在長條末端標示數值。

3. **格式要求**：
   - 每個子圖都要有**中文標題**、**x 軸標籤**（月份）、**y 軸標籤**（單位）。
   - 折線圖與長條圖需加上**圖例**。
   - 整個儀表板加上一個大標題：`"台灣城市氣候數據儀表板 2025"`。
   - 調整圖表間距避免重疊（`plt.tight_layout()`）。

4. **儲存圖片**：將完成的儀表板存為 `climate_dashboard.png`（解析度 150 dpi）。

## 提示

- 使用 `fig, axes = plt.subplots(2, 2, figsize=(14, 10))` 建立 2×2 子圖。
- 群組長條圖需計算每個月三個城市的 x 偏移量：
  ```python
  import numpy as np
  x = np.arange(12)   # 12 個月
  width = 0.25         # 每個長條的寬度
  # 台北：x - width，台中：x，高雄：x + width
  ```
- `fill_between(months, temp, alpha=0.3)` 可繪製半透明填滿區域。
- 水平長條圖使用 `ax.barh()`，並用 `ax.text()` 在長條末端加數值標籤。
- 若終端機顯示中文亂碼，在程式開頭加：
  ```python
  import matplotlib
  matplotlib.rcParams['font.family'] = ['Arial Unicode MS', 'Noto Sans CJK TC', 'DejaVu Sans']
  ```
