# 第 11 週今日 Python 練習題：氣溫趨勢視覺化分析

## 題目說明

你剛從網路爬蟲取得了一份過去 30 天的每日最高氣溫資料（已整理成 CSV）。本題要求你使用 `matplotlib` 將資料視覺化，製作一份清晰、有意義的氣溫趨勢圖，並加上統計標記（平均線、最高/最低點）。

這是資料分析流程中「展示成果」的關鍵步驟：爬蟲取得資料 → Pandas 處理 → **matplotlib 呈現**。

---

## 技術要求

- **概念**：折線圖、散點標記、水平參考線、圖例、標題、軸標籤、樣式設定
- **需要的模組**：`matplotlib.pyplot`、`numpy`（可選，用於生成假資料）

---

## 具體任務

1. **建立資料**
   使用以下假資料（或自行生成），代表過去 30 天的最高氣溫（°C）：
   ```python
   temperatures = [
       31, 33, 35, 34, 30, 28, 29, 32, 36, 37,
       38, 36, 34, 33, 31, 29, 28, 30, 32, 35,
       37, 39, 38, 36, 34, 32, 30, 31, 33, 35
   ]
   days = list(range(1, 31))
   ```

2. **繪製折線圖**
   - 以天數（1–30）為 X 軸，氣溫為 Y 軸
   - 折線顏色設為橘紅色（`#FF6B35`），線寬 2
   - 加上圓形資料點標記（`marker='o'`，大小 4）

3. **標記最高與最低氣溫**
   - 找出最高氣溫的那天，用紅色大星形（`marker='*'`，大小 200）標記
   - 找出最低氣溫的那天，用藍色大三角（`marker='^'`，大小 100）標記
   - 在標記旁加上文字標注（`plt.annotate`），顯示「最高: 39°C」、「最低: 28°C」

4. **加上平均氣溫水平線**
   - 計算 30 天平均氣溫
   - 畫一條灰色虛線（`linestyle='--'`），並在線上標示「平均: XX.X°C」

5. **完整圖表設定**
   - 標題：`「近 30 天最高氣溫趨勢」`
   - X 軸標籤：`「日期（天）」`
   - Y 軸標籤：`「氣溫（°C）」`
   - Y 軸範圍設為 25 至 42（留白空間）
   - 加上格線（`plt.grid`，透明度 0.3）
   - 加上圖例（顯示折線、平均線、最高、最低）
   - 儲存為 `temperature_trend.png`（dpi=150）並顯示

---

## 範例

```python
import matplotlib.pyplot as plt

temperatures = [31, 33, 35, 34, 30, 28, 29, 32, 36, 37,
                38, 36, 34, 33, 31, 29, 28, 30, 32, 35,
                37, 39, 38, 36, 34, 32, 30, 31, 33, 35]
days = list(range(1, 31))

avg = sum(temperatures) / len(temperatures)
max_temp = max(temperatures)
min_temp = min(temperatures)
max_day = temperatures.index(max_temp) + 1
min_day = temperatures.index(min_temp) + 1

fig, ax = plt.subplots(figsize=(12, 5))

# 折線圖
ax.plot(days, temperatures, color='#FF6B35', linewidth=2,
        marker='o', markersize=4, label='每日最高氣溫')

# 最高點
ax.scatter(max_day, max_temp, color='red', marker='*', s=200, zorder=5, label=f'最高: {max_temp}°C')
ax.annotate(f'最高: {max_temp}°C', xy=(max_day, max_temp),
            xytext=(max_day + 0.5, max_temp + 0.8), fontsize=9, color='red')

# 最低點
ax.scatter(min_day, min_temp, color='blue', marker='^', s=100, zorder=5, label=f'最低: {min_temp}°C')
ax.annotate(f'最低: {min_temp}°C', xy=(min_day, min_temp),
            xytext=(min_day + 0.5, min_temp - 1.2), fontsize=9, color='blue')

# 平均線
ax.axhline(y=avg, color='gray', linestyle='--', linewidth=1.2, label=f'平均: {avg:.1f}°C')
ax.text(30.2, avg + 0.3, f'{avg:.1f}°C', fontsize=8, color='gray')

ax.set_title('近 30 天最高氣溫趨勢', fontsize=14, fontweight='bold')
ax.set_xlabel('日期（天）')
ax.set_ylabel('氣溫（°C）')
ax.set_ylim(25, 42)
ax.grid(True, alpha=0.3)
ax.legend()

plt.tight_layout()
plt.savefig('temperature_trend.png', dpi=150)
plt.show()
print("圖表已儲存為 temperature_trend.png")
```

**預期輸出：**
```
圖表已儲存為 temperature_trend.png
```
（產出一張含折線、標記、平均線的完整氣溫趨勢圖）

## 提示

- 安裝模組：`pip install matplotlib`
- 若中文顯示為方塊，在程式開頭加入：
  ```python
  import matplotlib
  matplotlib.rcParams['font.family'] = 'DejaVu Sans'
  # 或在 Mac 上試試 'Heiti TC'，Linux 上試試 'WenQuanYi Micro Hei'
  ```
- `ax.annotate` 的 `xy` 是箭頭指向的位置，`xytext` 是文字顯示的位置
- `zorder=5` 讓標記點顯示在折線上方（不被遮住）
- `plt.tight_layout()` 防止標籤被截斷
