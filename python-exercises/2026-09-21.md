# 第 11 週今日 Python 練習題：氣溫折線圖與長條圖分析

## 題目說明

你有一份記錄某城市一週氣溫的資料，請使用 `matplotlib` 將這些資料視覺化，繪製出「折線圖」與「長條圖」，並加上標題、軸標籤、圖例等元素，讓圖表能清晰傳達資訊。

---

## 技術要求
- **概念**：資料視覺化、折線圖、長條圖、子圖（subplot）
- **需要的模組**：`matplotlib.pyplot`

---

## 具體任務

1. 建立一組一週的日期標籤（例如：`['週一', '週二', ..., '週日']`）以及對應的最高溫與最低溫資料（自行給定合理數值）。
2. 使用 `plt.subplots(1, 2)` 建立並排的兩張子圖：
   - **左圖（折線圖）**：同時畫出最高溫與最低溫的折線，加上標記點（`marker='o'`），並加上圖例。
   - **右圖（長條圖）**：畫出每日最高溫與最低溫的並排長條圖（grouped bar chart）。
3. 兩張子圖都必須有：
   - 標題（`set_title`）
   - X 軸與 Y 軸標籤（`set_xlabel`、`set_ylabel`）
   - 網格線（`ax.grid(True)`）
4. 整張圖加上總標題（`plt.suptitle`）。
5. 將圖表儲存為 `weather_chart.png`，解析度設為 `dpi=150`。

---

```python

high_temps = [33, 35, 34, 30, 28, 31, 36]
low_temps  = [25, 26, 25, 22, 20, 23, 27]

# 預期輸出
# 產生 weather_chart.png，包含折線圖與長條圖各一張
```

---

## 提示

- 長條圖並排技巧：設定 `x = range(len(days))`，第一組長條 `ax.bar(x, high_temps, width=0.4)`，第二組使用 `[i + 0.4 for i in x]` 偏移。
- 使用 `ax.set_xticks` 與 `ax.set_xticklabels` 調整 X 軸刻度位置至中間。
- `plt.tight_layout()` 可避免子圖重疊，建議在 `savefig` 前呼叫。
- 折線圖可用 `linestyle='--'` 讓最低溫線條有所區別。
