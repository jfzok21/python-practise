# 第 12 週今日 Python 練習題：鳶尾花分類器

## 題目說明

使用 scikit-learn 的經典資料集 **Iris（鳶尾花）**，建立一個 K 近鄰分類器（K-Nearest Neighbors, KNN）。  
透過這個練習，你將學會 ML 工作流程的完整步驟：載入資料 → 分割訓練/測試集 → 訓練模型 → 評估結果。

## 技術要求
- **概念**：監督式學習、分類、訓練/測試集分割、準確率評估
- **需要的模組**：`sklearn`（scikit-learn）、`pandas`、`matplotlib`

## 具體任務

1. **載入資料集**  
   使用 `sklearn.datasets.load_iris()` 載入鳶尾花資料集，並用 pandas DataFrame 顯示前 5 筆資料與欄位名稱。

2. **分割訓練集與測試集**  
   使用 `train_test_split` 將資料分為 80% 訓練、20% 測試（設定 `random_state=42`）。

3. **訓練 KNN 分類器**  
   使用 `KNeighborsClassifier(n_neighbors=3)` 訓練模型，然後對測試集進行預測。

4. **評估模型**  
   計算並印出準確率（accuracy），並用 `classification_report` 顯示詳細的精確率、召回率與 F1 分數。

5. **視覺化（選做，但強烈建議）**  
   繪製一張散佈圖，以花瓣長度（petal length）為 X 軸、花瓣寬度（petal width）為 Y 軸，顏色代表不同品種。

## 提示
- `load_iris()` 回傳一個 Bunch 物件，`.data` 是特徵矩陣，`.target` 是標籤，`.feature_names` 是欄位名稱，`.target_names` 是品種名稱
- `from sklearn.model_selection import train_test_split`
- `from sklearn.neighbors import KNeighborsClassifier`
- `from sklearn.metrics import accuracy_score, classification_report`
- 試著改變 `n_neighbors` 的值（1、5、10）觀察準確率變化

## 學習重點

**跟爬蟲的關聯：**  
爬蟲收集到的表格資料（例如商品評價、房價資訊）可以直接餵入 sklearn 進行預測分析。這週學的 ML 流程，正是將爬蟲採集的原始資料轉化為有價值洞察的核心技術。

**核心 ML 概念：**
- **特徵（Features）**：用來預測的輸入變數（花萼長寬、花瓣長寬）
- **標籤（Label）**：要預測的目標（品種 0/1/2）
- **過擬合（Overfitting）**：模型記住訓練資料但在新資料上表現差，改變 k 值可以觀察此現象
