# 第 12 週今日 Python 練習題：鳶尾花分類器

## 題目說明

使用 scikit-learn 建立一個機器學習分類模型，對著名的鳶尾花（Iris）資料集進行分類。你將學習完整的 ML 工作流程：載入資料、拆分訓練／測試集、訓練模型、評估結果，並儲存預測報告。

---

## 技術要求

- **概念**：監督式學習、分類、特徵、標籤、訓練集／測試集、準確率
- **需要的模組**：`sklearn`、`pandas`、`numpy`（可用 `pip install scikit-learn pandas numpy`）

---

## 具體任務

1. **載入資料集**
   使用 `sklearn.datasets.load_iris()` 載入鳶尾花資料集，並將特徵（features）和標籤（labels）轉為 Pandas DataFrame。

2. **探索資料**
   - 印出資料集的前 5 筆資料（`.head()`）
   - 印出每個品種的數量（`.value_counts()`）
   - 印出特徵的基本統計資料（`.describe()`）

3. **拆分資料集**
   使用 `train_test_split` 將資料分為 80% 訓練集、20% 測試集（設定 `random_state=42`）。

4. **訓練模型**
   使用以下任一分類器訓練模型：
   - `KNeighborsClassifier`（K 最近鄰）
   - `DecisionTreeClassifier`（決策樹）
   - 或 `RandomForestClassifier`（隨機森林）

5. **評估模型**
   - 計算測試集準確率（`accuracy_score`）
   - 印出混淆矩陣（`confusion_matrix`）
   - 印出分類報告（`classification_report`）

6. **儲存預測結果**
   將測試集的真實標籤與預測標籤存入 CSV 檔案 `iris_predictions.csv`。

---

## 範例

```python
# 輸入（自動載入，不需手動輸入）
from sklearn.datasets import load_iris
iris = load_iris()

# 預期輸出（範例）
# 準確率：0.9667
# 混淆矩陣：
# [[10  0  0]
#  [ 0  9  1]
#  [ 0  0 10]]
#
# 分類報告：
#               precision  recall  f1-score  support
# setosa           1.00      1.00      1.00       10
# versicolor       1.00      0.90      0.95       10
# virginica        0.91      1.00      0.95       10

# iris_predictions.csv 儲存格式：
# true_label,predicted_label
# setosa,setosa
# versicolor,versicolor
# ...
```

---

## 提示

- `load_iris()` 回傳的是一個 Bunch 物件，`iris.data` 是特徵矩陣，`iris.target` 是標籤（整數），`iris.target_names` 是品種名稱。
- 用 `pd.DataFrame(iris.data, columns=iris.feature_names)` 建立特徵 DataFrame。
- 品種名稱可透過 `iris.target_names[y]` 取得。
- 模型訓練只需 `.fit(X_train, y_train)`，預測只需 `.predict(X_test)`。
- `classification_report(y_test, y_pred, target_names=iris.target_names)` 可顯示含品種名稱的報告。
