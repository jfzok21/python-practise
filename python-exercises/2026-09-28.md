## 題目說明

前幾天練習了**分類問題**（預測「是哪一類」），今天換一個方向：**迴歸問題**（預測「數值大小」）。使用 scikit-learn 內建的糖尿病資料集（Diabetes Dataset），建立線性迴歸模型，預測患者一年後的病情進展指標。

---

## 技術要求

- **概念**：迴歸 vs 分類、線性迴歸、誤差指標（MSE、RMSE、R²）、特徵相關性
- **需要的模組**：`sklearn`、`pandas`、`numpy`、`matplotlib`

---

## 具體任務

1. **載入資料集**
   使用 `sklearn.datasets.load_diabetes()` 載入資料集，並將特徵轉成 Pandas DataFrame。
   - 印出資料集的形狀（幾筆資料、幾個特徵）
   - 印出前 5 筆資料

2. **探索特徵相關性**
   計算每個特徵與目標值（`y`）的相關係數（`.corr()`），並找出相關性最強的前 3 個特徵。

3. **分割訓練集與測試集**
   使用 `train_test_split` 以 80/20 比例分割，設定 `random_state=42`。

4. **訓練線性迴歸模型**
   使用 `LinearRegression` 訓練模型，並對測試集進行預測。

5. **評估模型**
   計算並印出以下指標：
   - **MSE**（Mean Squared Error，均方誤差）
   - **RMSE**（Root MSE，均方根誤差）
   - **R² 分數**（決定係數，越接近 1 越好）

6. **視覺化預測結果**
   畫出「真實值 vs 預測值」散佈圖：
   - X 軸：真實值（`y_test`）
   - Y 軸：預測值（`y_pred`）
   - 加上一條理想線（`y = x`，即預測完全準確的對角線）
   - 儲存為 `diabetes_prediction.png`

## 提示

- `load_diabetes()` 回傳的特徵已被標準化（mean=0, std=1），所以數值看起來很小是正常的
- 相關性計算：先把特徵和目標合成一個 DataFrame，再用 `.corr()['target'].drop('target')`
- `LinearRegression` 只需 `.fit()` 和 `.predict()`，非常簡單
- 誤差計算：
  ```python
  from sklearn.metrics import mean_squared_error, r2_score
  import numpy as np
  mse = mean_squared_error(y_test, y_pred)
  rmse = np.sqrt(mse)
  r2 = r2_score(y_test, y_pred)
  ```
- 理想線的畫法：`plt.plot([y_test.min(), y_test.max()], [y_test.min(), y_test.max()], 'r--')`

## 學習重點

**迴歸 vs 分類的差別：**

| 問題類型 | 輸出 | 評估指標 | 範例 |
|---|---|---|---|
| 分類（Classification） | 類別標籤 | 準確率、F1 | 鳶尾花品種 |
| **迴歸（Regression）** | **連續數值** | **MSE、R²** | **病情指數、房價** |

**與爬蟲／資料分析的關聯：**
- 爬蟲可抓取房價、股價、商品銷售量等連續數值資料
- 用線性迴歸可以找出「哪些特徵影響最終價格」，輸出特徵係數（`.coef_`）即可解讀
- R² 低（如 0.45）不代表程式錯了，而是「線性模型無法完整解釋資料的非線性關係」，這是推動你學習進階模型（如 RandomForest、XGBoost）的動力
