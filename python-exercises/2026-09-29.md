# 第 13 週今日 Python 練習題：匯率追蹤儀表板

## 題目說明

整合前幾週學到的所有技能，打造一個「每日匯率追蹤工具」。
程式會從網路取得即時匯率資料，儲存成 CSV，並用圖表呈現一段時間的匯率走勢。

---

## 技術要求

- **概念**：爬蟲、資料處理、CSV 讀寫、資料視覺化、函數設計
- **需要的模組**：`requests`、`pandas`、`matplotlib`、`csv`、`datetime`

---

## 具體任務

1. **取得匯率資料**
   - 向 `https://api.exchangerate-api.com/v4/latest/USD`（免費、無需 API Key）發送 GET 請求
   - 解析 JSON，提取 TWD、JPY、EUR、GBP 對 USD 的匯率

2. **儲存至 CSV**
   - 建立（或附加至）`rates.csv`，欄位為：`date, USD_TWD, USD_JPY, USD_EUR, USD_GBP`
   - 若今天的資料已存在則不重複寫入（用日期判斷）

3. **讀取並分析歷史資料**
   - 用 `pandas` 讀取 `rates.csv`
   - 計算每個貨幣的最大值、最小值、平均值，並列印摘要表

4. **畫出走勢圖**
   - 用 `matplotlib` 畫出 USD/TWD 的折線圖（x 軸為日期，y 軸為匯率）
   - 標上今日資料點（紅色星號）
   - 存成 `rates_chart.png`

5. **包裝成函數**
   - 將上述步驟分別封裝為：`fetch_rates()`、`save_to_csv(data)`、`analyze_data(filepath)`、`plot_rates(filepath)`
   - 主程式用 `if __name__ == "__main__":` 依序呼叫

---

## 範例

```python
# 執行程式後輸出範例：

# === 今日匯率（2026-09-29）===
# USD → TWD: 32.15
# USD → JPY: 148.20
# USD → EUR: 0.92
# USD → GBP: 0.79

# === 歷史資料摘要 ===
#          USD_TWD   USD_JPY  USD_EUR  USD_GBP
# 最大值     32.80    152.00     0.94     0.81
# 最小值     31.50    143.10     0.89     0.76
# 平均值     32.12    147.55     0.91     0.78

# 圖表已儲存為 rates_chart.png
```

---

## 提示

- `requests.get(url).json()` 可直接得到字典格式的 JSON
- CSV 附加模式用 `open('rates.csv', 'a', newline='')`；判斷是否已有今天資料需先讀取再決定
- `pandas` 讀取 CSV：`df = pd.read_csv('rates.csv', parse_dates=['date'])`
- matplotlib 設定中文字型可用 `plt.rcParams['font.family'] = 'DejaVu Sans'`
- `df['date']` 轉成字串格式後用 `plt.xticks(rotation=45)` 避免日期重疊
