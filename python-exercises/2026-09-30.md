# 第 13 週今日 Python 練習題：個人新聞聚合分析器

## 題目說明

建立一個完整的實戰專案：自動抓取多個新聞來源的標題，儲存成 CSV，分析關鍵字頻率，並輸出視覺化圖表。這個專案整合了你前 12 週學到的所有核心技能。

---

## 技術要求

- **概念**：網頁爬蟲、資料清洗、Pandas 分析、Matplotlib 視覺化、檔案讀寫
- **需要的模組**：`requests`、`beautifulsoup4`、`pandas`、`matplotlib`、`collections`

安裝（若尚未安裝）：
```bash
pip install requests beautifulsoup4 pandas matplotlib
```

---

## 具體任務

1. **爬取新聞標題**
   - 從至少 2 個新聞網站（例如 Hacker News `https://news.ycombinator.com` 與 BBC News `https://feeds.bbci.co.uk/news/rss.xml`）抓取最新標題列表
   - 每筆資料包含：`title`、`source`、`fetched_at`（抓取時間，用 `datetime.now()` 取得）

2. **儲存為 CSV**
   - 用 `pandas.DataFrame` 整理資料
   - 輸出至 `news_data.csv`（若檔案已存在則 append，避免重複標題）

3. **關鍵字頻率分析**
   - 將所有標題合併，切分成單字（`str.split()`）
   - 過濾掉常見停用字（stop words），例如 `["the","a","an","in","of","to","and","for","is","on","at"]`
   - 用 `collections.Counter` 計算最常出現的 10 個關鍵字

4. **視覺化輸出**
   - 畫出「Top 10 關鍵字」橫向長條圖（`barh`）
   - 標題、X 軸標籤、Y 軸標籤要齊全
   - 儲存圖片為 `top_keywords.png`

5. **終端機摘要報告**
   - 印出：抓取時間、總標題數、各來源筆數、Top 5 關鍵字

## 提示

- Hacker News 的標題在 `<a class="storylink">` 或 `<span class="titleline"><a>` 中（視版本而定），建議用 `soup.select('span.titleline a')` 抓取
- BBC RSS 是 XML 格式，用 `soup.find_all('title')` 後略過第一筆（feed 標題本身）
- 避免重複：讀入舊 CSV 後，用 `df.drop_duplicates(subset='title')` 去重再存檔
- 圖表用 `plt.tight_layout()` 確保標籤不被截斷

import schedule, time

**C. 主題分群（sklearn）**
```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.cluster import KMeans
vec = TfidfVectorizer(max_features=100, stop_words='english')
X = vec.fit_transform(df['title'])
km = KMeans(n_clusters=5, random_state=42).fit(X)
df['cluster'] = km.labels_
print(df.groupby('cluster')['title'].count())
```
