## 題目說明

建立一個完整的實戰專案：讀入任意 CSV 檔案，自動偵測資料品質問題（缺值、重複列、離群值），進行清洗，並產出一份「探索性資料分析（EDA）報告」—— 包含統計摘要、分佈圖表與相關性熱圖，最後將清洗後的資料另存為新 CSV。這個專案整合了你前 12 週學到的所有核心技能。

### 3. 自動清洗函數

撰寫函數 `auto_clean(df)` 執行：
- 刪除完全重複的列（`drop_duplicates`）
- 數值欄的缺值以中位數補齊（`fillna(median)`）
- 類別欄的缺值以眾數補齊（`fillna(mode)`）
- 回傳清洗後的 DataFrame 與一份操作日誌（list of strings）

### 4. 統計摘要輸出

對清洗後的資料：
- 印出 `df.describe()` 的格式化版本
- 額外計算每欄的「偏態（skewness）」與「峰度（kurtosis）」

```python
for col in df_clean.select_dtypes(include='number').columns:
    skew = df_clean[col].skew()
    kurt = df_clean[col].kurtosis()
    print(f"  {col:<30} skew={skew:+.3f}  kurt={kurt:+.3f}")
```

### 5. 視覺化報告（輸出至 PNG）

產生一個 **2×2 子圖** 的報告圖：

- 左下：離群值盒鬚圖（boxplot，所有數值欄）
- 右下：相關性熱圖（`imshow` 或 `seaborn.heatmap`）

儲存為 `eda_report.png`。

## 提示

- `df.isnull().sum()` 取得每欄缺值數；`/ len(df) * 100` 換算百分比
- IQR 離群值判斷：
  ```python
  Q1 = df[col].quantile(0.25)
  Q3 = df[col].quantile(0.75)
  IQR = Q3 - Q1
  outlier_count = ((df[col] < Q1 - 1.5*IQR) | (df[col] > Q3 + 1.5*IQR)).sum()
  ```
- 相關性熱圖不需要 seaborn，用 `plt.imshow(df.corr(), cmap='coolwarm', vmin=-1, vmax=1)` 加 `plt.colorbar()` 即可
- `plt.tight_layout()` 防止子圖標籤重疊

**B. 自動判斷並轉換欄位型別**
```python
# 把看起來像數字但被讀成字串的欄位轉換
for col in df.select_dtypes(include='object').columns:
    df[col] = pd.to_numeric(df[col], errors='ignore')
```

**C. 加入 sklearn 管線（Pipeline）**
```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.impute import SimpleImputer

pipe = Pipeline([
    ('impute', SimpleImputer(strategy='median')),
    ('scale',  StandardScaler()),
])
X_clean = pipe.fit_transform(df.select_dtypes(include='number'))
print("Pipeline 完成，形狀：", X_clean.shape)
```
