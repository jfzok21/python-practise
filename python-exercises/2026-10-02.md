# 第 13 週今日 Python 練習題：個人股票追蹤分析儀

## 題目說明

整合前 12 週所學技術，打造一個完整的「個人股票追蹤分析儀」。這個工具能夠從公開 API 抓取股票資料，進行統計分析，輸出視覺化圖表，並將結果儲存為 CSV 報告。

本專案模擬真實資料工程工作流程：**取得資料 → 清理資料 → 分析資料 → 視覺化 → 輸出報告**。

## 技術要求

- **概念**：函數設計、例外處理、資料清理、統計分析、視覺化
- **需要的模組**：`requests`、`pandas`、`matplotlib`、`csv`、`datetime`、`json`

## 具體任務

### 任務一：資料抓取模組

1. 使用 [Yahoo Finance 非官方 API](https://query1.finance.yahoo.com/v8/finance/chart/AAPL?interval=1d&range=1mo) 取得股票歷史資料
   - URL 格式：`https://query1.finance.yahoo.com/v8/finance/chart/{ticker}?interval=1d&range=1mo`
   - 追蹤的股票清單：`["AAPL", "MSFT", "GOOGL", "TSLA", "NVDA"]`
2. 寫一個函數 `fetch_stock_data(ticker: str) -> dict`，回傳包含日期與收盤價的字典
3. 加入 `try/except` 例外處理，遇到網路錯誤時印出訊息並回傳 `None`

### 任務二：資料處理模組

1. 寫一個函數 `build_dataframe(data: dict, ticker: str) -> pd.DataFrame`
   - 欄位：`date`（datetime）、`ticker`（字串）、`close`（浮點數）
2. 計算每支股票的以下統計數據：
   - 月平均收盤價
   - 月最高 / 最低收盤價
   - 月報酬率（`(最後收盤 - 最初收盤) / 最初收盤 × 100`，保留 2 位小數）
3. 用 `pandas` 將所有股票合併成一個完整 DataFrame

### 任務三：視覺化模組

1. 畫出折線圖：所有股票 **過去一個月收盤價走勢**（同一張圖，不同顏色）
2. 畫出長條圖：各股票 **月報酬率比較**（正值為綠，負值為紅）
3. 儲存圖表為 `report/stock_chart.png`（如目錄不存在則自動建立）

### 任務四：報告輸出模組

1. 將統計摘要儲存為 `report/stock_summary_2026-10-02.csv`，欄位如下：

| ticker | avg_close | max_close | min_close | monthly_return_pct |
|--------|-----------|-----------|-----------|-------------------|

2. 在 terminal 印出格式化摘要，例如：

```
=== 股票月報告 2026-10-02 ===
AAPL : 平均 $185.32 | 報酬率 +3.24%
MSFT : 平均 $412.10 | 報酬率 -1.05%
...
```

## 範例

```python
# 執行入口
if __name__ == "__main__":
    tickers = ["AAPL", "MSFT", "GOOGL", "TSLA", "NVDA"]
    all_dfs = []

    for ticker in tickers:
        raw = fetch_stock_data(ticker)
        if raw:
            df = build_dataframe(raw, ticker)
            all_dfs.append(df)

    combined = pd.concat(all_dfs, ignore_index=True)
    stats = compute_stats(combined)
    plot_charts(combined, stats)
    save_report(stats)
    print_summary(stats)
```

## 提示

- `requests.get(url, headers={"User-Agent": "Mozilla/5.0"})` 可避免被拒絕
- Yahoo Finance API 回傳的時間戳是 Unix timestamp，用 `pd.to_datetime(ts, unit='s')` 轉換
- `matplotlib` 設定中文字型：`plt.rcParams['font.sans-serif'] = ['DejaVu Sans']`（雲端環境無中文字型時跳過中文標籤）
- 先用 `os.makedirs("report", exist_ok=True)` 確保目錄存在
- `df.groupby("ticker").agg(...)` 可一次計算所有統計數據
