# 第 13 週今日 Python 練習題：新聞爬蟲 + 資料分析整合專案

## 題目說明

結合前 12 週所學，建立一個完整的實戰專案：從網路上爬取新聞資料、清理整理、進行簡單的文字分析，最後將結果儲存為 CSV 並產生視覺化圖表。這個專案模擬真實的資料工程流程，從資料蒐集到洞察輸出。

## 技術要求
- 概念：網路爬蟲、資料清理、Pandas 分析、Matplotlib 視覺化、檔案 I/O
- 需要的模組：`requests`、`beautifulsoup4`、`pandas`、`matplotlib`、`collections`

## 具體任務

1. **爬取資料**：使用 `requests` + `BeautifulSoup` 從 `https://news.ycombinator.com`（Hacker News）爬取首頁所有文章標題、連結與分數（points）。

2. **清理與整理**：
   - 將爬到的資料存入 Pandas DataFrame（欄位：`title`、`url`、`score`、`domain`）
   - 從 URL 中擷取網域名稱（`domain`），若無 URL 則填入 `"self.hn"`
   - 移除 `score` 為 None 的列

3. **分析**：
   - 計算平均分數、最高分文章標題
   - 找出出現最多的前 5 個網域
   - 統計標題中最常出現的 10 個關鍵字（先去掉 `a`、`the`、`to`、`of`、`in`、`and`、`for`、`is`、`on`、`with` 等停用詞）

4. **儲存**：將 DataFrame 儲存為 `hn_news_YYYY-MM-DD.csv`（日期為今天）

5. **視覺化**：
   - 長條圖：前 5 大網域的文章數量
   - 儲存為 `hn_top_domains_YYYY-MM-DD.png`

## 範例

```python
# 爬取資料片段
import requests
from bs4 import BeautifulSoup
import pandas as pd
import matplotlib.pyplot as plt
from collections import Counter
from datetime import date
import re

url = "https://news.ycombinator.com"
res = requests.get(url, headers={"User-Agent": "Mozilla/5.0"})
soup = BeautifulSoup(res.text, "html.parser")

rows = []
for item in soup.select(".athing"):
    title_tag = item.select_one(".titleline > a")
    title = title_tag.text if title_tag else ""
    link = title_tag["href"] if title_tag else ""
    
    subtext = item.find_next_sibling("tr")
    score_tag = subtext.select_one(".score") if subtext else None
    score = int(score_tag.text.replace(" points", "")) if score_tag else None
    
    rows.append({"title": title, "url": link, "score": score})

# 建立 DataFrame
df = pd.DataFrame(rows)
# ... 繼續清理與分析
```

## 提示
- Hacker News 的文章列表使用 `.athing` class，分數在下一個 `<tr>` 的 `.score` 中
- 從 URL 擷取網域可用 `re.search(r'https?://([^/]+)', url)`
- 停用詞過濾可先 `title.lower().split()` 再搭配 `Counter`
- `matplotlib` 儲存圖片用 `plt.savefig("檔名.png", dpi=150, bbox_inches="tight")`
