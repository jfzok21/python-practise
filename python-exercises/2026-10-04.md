## 題目說明

運用過去 12 週所學的所有技能，建立一個完整的股票資料分析工具。你將從公開 API 抓取股票歷史資料，進行資料清理與統計分析，最後繪製視覺化圖表，並輸出分析報告至 CSV 檔案。

本題整合了：網路爬蟲、Pandas 資料處理、NumPy 計算、matplotlib 視覺化，是前 12 週學習成果的綜合實戰。

## 技術要求
- **概念**：資料管線（Data Pipeline）、移動平均、報酬率計算、多子圖繪製
- **需要的模組**：`requests`、`pandas`、`numpy`、`matplotlib`、`json`、`csv`、`datetime`

## 具體任務

### 任務一：資料獲取
1. 使用 `requests` 呼叫 Yahoo Finance 非官方 API（或使用下方提供的模擬資料函式）取得股票近 60 天的收盤價
2. 將 JSON 回應解析並轉換為 Pandas DataFrame，欄位包含：`date`、`close`、`volume`

### 任務二：資料處理
3. 使用 Pandas 計算以下指標：
   - **5 日移動平均**（MA5）
   - **20 日移動平均**（MA20）
   - **每日報酬率**：`(今日收盤 - 昨日收盤) / 昨日收盤 * 100`
   - **累積報酬率**：從第一天到每一天的總報酬
4. 找出報酬率最高與最低的前 3 天

### 任務三：視覺化
5. 使用 `matplotlib` 建立包含 **3 個子圖**的圖表：
   - 子圖 1：收盤價折線圖 + MA5 + MA20（三條線）
   - 子圖 2：成交量長條圖
   - 子圖 3：每日報酬率折線圖（正值用綠色，負值用紅色）
6. 設定標題、軸標籤、圖例，儲存為 `stock_analysis.png`

### 任務四：報告輸出
7. 將分析結果（包含 MA5、MA20、每日報酬率、累積報酬率）輸出至 `stock_report.csv`
8. 在終端機印出摘要報告，格式如下：
   ```
   === 股票分析摘要 ===
   分析區間：2026-08-05 ~ 2026-10-03
   總交易天數：43
   起始價格：$185.20
   最終價格：$210.45
   期間最高：$215.30（2026-09-22）
   期間最低：$180.10（2026-08-12）
   累積報酬率：+13.63%
   最佳單日：+3.21%（2026-09-10）
   最差單日：-2.85%（2026-08-20）
   ```

        date += timedelta(days=1)
    
    return pd.DataFrame({"date": dates, "close": prices, "volume": volumes})

## 提示
- `DataFrame.rolling(window=5).mean()` 可計算移動平均
- `DataFrame["close"].pct_change() * 100` 可計算每日報酬率
- `(1 + df["daily_return"] / 100).cumprod() - 1` 可計算累積報酬率
- 用 `ax.bar()` 畫成交量，正報酬日 `color='green'`，負報酬日 `color='red'`
- `plt.tight_layout()` 避免子圖重疊
- `df.nlargest(3, "daily_return")` 可取得報酬率前 3 名
