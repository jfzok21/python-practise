## 題目說明

運用前 12 週所有技能，打造一個完整的文字情感分析工具。你將生成模擬商品評論資料、用 Pandas 進行文字前處理與特徵工程、以 scikit-learn 訓練情感分類模型，再用 matplotlib 呈現模型表現與評論分佈。

本題整合了：字串處理、Pandas 資料清洗、NumPy 向量運算、matplotlib 視覺化、sklearn 機器學習。

## 技術要求
- **概念**：TF-IDF 特徵提取、文字分類、訓練/測試分割、混淆矩陣、準確率評估
- **需要的模組**：`pandas`、`numpy`、`matplotlib`、`sklearn`、`random`、`re`

## 具體任務

### 任務一：產生模擬評論資料
1. 撰寫 `generate_reviews(n=300)` 函式，隨機產生 300 筆商品評論，每筆包含：
   - `review_id`：流水號（1 起始）
   - `text`：由預設詞庫拼接的評論句子（正面/負面各一套詞庫，見範例）
   - `rating`：整數 1–5（1–2 → 負面，4–5 → 正面，3 → 中性，佔比約 3:1:1）
   - `label`：根據 `rating` 自動設為 `"正面"` / `"負面"` / `"中性"`
2. 將資料存入 `reviews.csv`

### 任務二：資料探索
3. 用 `pandas.read_csv()` 載入 `reviews.csv`
4. 計算並印出：
   - 各標籤數量與佔比
   - 平均 rating 與標準差
   - 最長 / 最短評論的字元數
5. 新增 `text_len` 欄（評論字元數），計算各標籤的平均長度

### 任務三：特徵工程與模型訓練
6. 用 `sklearn.feature_extraction.text.TfidfVectorizer` 將評論文字轉為數值特徵矩陣
   - `max_features=500`、`ngram_range=(1, 2)`
7. 用 `sklearn.model_selection.train_test_split` 切分資料（測試集 20%，`random_state=42`）
8. 分別訓練以下三個分類器並比較準確率：
   - `LogisticRegression(max_iter=500)`
   - `MultinomialNB()`（樸素貝氏）
   - `RandomForestClassifier(n_estimators=100, random_state=42)`
9. 選出準確率最高的模型，印出 `classification_report`（含 precision、recall、F1）

### 任務四：視覺化
10. 使用 `matplotlib` 建立 **2×2 四格子圖**：
    - 左上（長條圖）：各標籤評論數量
    - 右上（直方圖）：評論長度分佈（三種標籤疊加、半透明）
    - 左下（混淆矩陣熱圖）：最佳模型的混淆矩陣（用 `imshow` 繪製，標注數字）
    - 右下（長條圖）：三個模型準確率比較，最高的欄位用醒目色標示
11. 設定整體標題、子圖標題、軸標籤，儲存為 `sentiment_report.png`

### 任務五：即時預測 CLI
12. 撰寫 `predict_sentiment(text, model, vectorizer)` 函式，接受任意字串並回傳預測標籤與信心分數
13. 實作簡易互動迴圈：
    ```
    請輸入評論（輸入 q 離開）：這個商品品質很好，非常滿意！
    → 預測：正面（信心 93.2%）
    ```

```python
import pandas as pd
import numpy as np

# ── 步驟一：詞庫設定 ─────────────────────────────────────────────
POSITIVE_PHRASES = [

    "使用體驗極佳", "做工精緻", "很滿意這次購物", "會再回購", "五星好評",

NEGATIVE_PHRASES = [

    "使用兩天就壞", "做工粗糙", "非常失望", "不值這個價格", "差評",
    "收到是壞品", "客服態度很差", "顏色跟照片不符", "尺寸不準確", "退貨麻煩",
]
NEUTRAL_PHRASES = [
    "普通還行", "沒有特別驚喜", "中規中矩", "還可以接受",
    "跟描述差不多", "一般般", "不好不壞",
]

def generate_reviews(n=300, seed=42):
    random.seed(seed)
    records = []
    for i in range(1, n + 1):
        roll = random.random()
        if roll < 0.6:            # 60% 正面
            rating = random.choice([4, 5])
            text = "，".join(random.sample(POSITIVE_PHRASES, k=random.randint(2, 4)))
            label = "正面"
        elif roll < 0.8:          # 20% 負面
            rating = random.choice([1, 2])
            text = "，".join(random.sample(NEGATIVE_PHRASES, k=random.randint(2, 4)))
            label = "負面"
        else:                     # 20% 中性
            rating = 3
            text = "，".join(random.sample(NEUTRAL_PHRASES, k=random.randint(1, 3)))
            label = "中性"
        records.append({"review_id": i, "text": text, "rating": rating, "label": label})
    return pd.DataFrame(records)

df = generate_reviews()
df.to_csv("reviews.csv", index=False, encoding="utf-8-sig")
```

## 提示
- `TfidfVectorizer` 回傳稀疏矩陣，`MultinomialNB` 需要非負數值；`LogisticRegression` 與 `RandomForest` 都相容
- 混淆矩陣：`from sklearn.metrics import confusion_matrix`；用 `ax.imshow(cm, cmap="Blues")` 繪製，再用雙層迴圈 `ax.text(j, i, cm[i,j])` 標注數字
- 信心分數：`model.predict_proba(X)[0]` 回傳各類別機率，`.max()` 取最高值
- `classification_report` 的 `target_names` 參數可指定中文標籤順序
- 中文字型問題：可將標籤改英文（Positive / Negative / Neutral）以避免 Linux 中文亂碼
