# 第 14 週今日 Python 練習題：股票資料爬蟲與分析儀表板

## 題目說明

綜合運用前幾週所學的爬蟲、資料處理與視覺化技能，建立一個能夠從網路抓取股票歷史資料、進行基礎統計分析，並產生視覺化報告的實戰專案。

## 技術要求
- 概念：HTTP 請求、HTML 解析、Pandas 資料處理、matplotlib 視覺化、CSV 儲存
- 需要的模組：`requests`、`bs4`（BeautifulSoup）、`pandas`、`matplotlib`、`csv`、`datetime`

## 具體任務

1. **資料抓取**：使用 `requests` 從 Yahoo Finance（或其他公開財經網站）抓取指定股票代碼（如 AAPL）的最近 30 天收盤價資料
2. **資料清理**：用 Pandas 讀入資料，去除空值，將日期欄位轉為 `datetime` 型態並設為索引
3. **統計分析**：計算以下指標
   - 平均收盤價（mean）
   - 最高／最低收盤價（max / min）
   - 5 日移動平均線（rolling mean）
   - 每日漲跌幅（pct_change）
4. **視覺化**：使用 `matplotlib` 繪製含有兩個子圖的圖表
   - 上圖：收盤價折線 + 5 日均線
   - 下圖：每日漲跌幅長條圖（漲為綠、跌為紅）
5. **儲存結果**：將清理後的資料含統計欄位存成 `stock_report_AAPL.csv`

## 提示

- Yahoo Finance 的 URL 格式通常為：`https://finance.yahoo.com/quote/{TICKER}/history`，但若遭到封鎖，可改用 `yfinance` 套件（`pip install yfinance`）作為資料來源
- 使用 `yfinance`：`import yfinance as yf; df = yf.download("AAPL", period="1mo")`
- `rolling(5).mean()` 可計算 5 日移動平均
- `pct_change()` 回傳百分比變化（小數格式）
- `matplotlib` 子圖：`fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(12, 8))`
- 漲跌顏色：`colors = ['green' if x >= 0 else 'red' for x in df['pct_change']]`

## 學習重點

這道題目是爬蟲（第 6-8 週）、Pandas（第 10 週）與 matplotlib（第 11 週）的綜合應用：
