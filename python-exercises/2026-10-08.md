# 第 14 週今日 Python 練習題：新聞爬蟲與資料分析儀表板

## 題目說明

建立一個完整的「新聞爬蟲與分析儀表板」專案，整合前幾週學過的所有核心技能：
網頁爬蟲、資料清理、Pandas 分析、以及 Matplotlib 視覺化。
你將從 Hacker News（https://news.ycombinator.com/）抓取文章清單，
統計各類關鍵字的出現頻率，並將結果儲存為 CSV 與圖表。

## 技術要求
- 概念：requests、BeautifulSoup、Pandas、Matplotlib、CSV 檔案寫入、字串處理
- 需要的模組：`requests`、`bs4`、`pandas`、`matplotlib`、`collections`、`csv`、`datetime`

## 具體任務

1. **爬取新聞標題**
   - 使用 `requests` + `BeautifulSoup` 抓取 Hacker News 首頁（https://news.ycombinator.com/）
   - 取出所有文章標題（`<span class="titleline">` 內的 `<a>` 標籤文字）
   - 同時取出各文章的分數（`<span class="score">`，若無則設為 0）

2. **關鍵字統計**
   - 定義一組技術關鍵字清單，例如：
     `["python", "ai", "llm", "rust", "go", "linux", "cloud", "data", "security", "web"]`
   - 對每個標題（轉為小寫）逐一檢查包含哪些關鍵字
   - 用 `collections.Counter` 統計各關鍵字出現次數

3. **整理成 Pandas DataFrame**
   - 建立 DataFrame，欄位為：`title`、`score`、`keywords`（逗號分隔字串）
   - 計算每篇文章包含的關鍵字數量，新增 `keyword_count` 欄位
   - 依 `score` 降序排列，印出前 10 名

4. **儲存結果**
   - 將 DataFrame 存為 `hn_articles_YYYY-MM-DD.csv`
   - 將關鍵字統計結果另存為 `hn_keywords_YYYY-MM-DD.csv`（欄位：`keyword`、`count`）

5. **繪製圖表**
   - 用長條圖（`bar chart`）呈現關鍵字出現頻率（由高到低排序）
   - X 軸：關鍵字；Y 軸：次數
   - 標題：`Hacker News 關鍵字頻率 - YYYY-MM-DD`
   - 儲存圖片為 `hn_keywords_YYYY-MM-DD.png`（`dpi=150`）

## 提示

- 取標題時注意有些 `<a>` 有子元素，用 `.get_text()` 較安全
- 分數文字格式為 `"312 points"`，用 `.split()[0]` 取出數字再轉 `int`
- 若某篇文章沒有分數元素，用 `try/except` 或 `.find()` 配合預設值 0
- 關鍵字比對記得 `.lower()` 轉小寫，避免大小寫差異
- `matplotlib` 長條圖排序：先對 `Counter` 的 `.most_common()` 結果解壓縮
