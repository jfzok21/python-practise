## 具體任務

### 任務一：資料擷取（requests + JSON）
1. 使用以下模擬函式生成測試資料（或選用真實免費 API 如 Yahoo Finance）
2. 抓取至少 3 支股票或資產（可用假資料）過去 30 天的收盤價
3. 將資料儲存為 CSV 檔案（`assets_data.csv`）

### 任務二：資料分析（Pandas）
1. 讀取 CSV，計算每支資產的：
   - 平均值（mean）
   - 最大值與最小值
   - 標準差（std）
   - 7 日移動平均（rolling mean）
2. 找出漲幅最大與跌幅最大的一天

### 任務三：視覺化（matplotlib）
1. 繪製每支資產的折線圖（含 7 日移動平均線）
2. 用子圖（subplot）排列，每支資產一個圖
3. 加上標題、軸標籤、圖例

### 任務四：趨勢預測（sklearn）
1. 使用線性回歸（LinearRegression）預測未來 7 天的走勢
2. 將預測結果畫在圖上（用虛線表示）

## 範例

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression
from datetime import datetime, timedelta
import csv

# 生成模擬資料
def generate_mock_data():
    assets = {
        'AAPL': 150.0,
        'TSLA': 250.0,
        'BTC':  30000.0
    }
    dates = [datetime.today() - timedelta(days=i) for i in range(29, -1, -1)]
    rows = []
    for date in dates:
        for symbol, base in assets.items():
            price = base * (1 + np.random.uniform(-0.03, 0.03))
            rows.append({'date': date.strftime('%Y-%m-%d'), 'symbol': symbol, 'close': round(price, 2)})
    return rows

# 存入 CSV
data = generate_mock_data()
with open('assets_data.csv', 'w', newline='') as f:
    writer = csv.DictWriter(f, fieldnames=['date', 'symbol', 'close'])
    writer.writeheader()
    writer.writerows(data)

# 讀取並分析
df = pd.read_csv('assets_data.csv', parse_dates=['date'])
print(df.groupby('symbol')['close'].agg(['mean', 'std', 'min', 'max']))

# 繪圖（含移動平均與線性回歸預測）
symbols = df['symbol'].unique()
fig, axes = plt.subplots(len(symbols), 1, figsize=(12, 4 * len(symbols)))

for ax, symbol in zip(axes, symbols):
    data_s = df[df['symbol'] == symbol].sort_values('date')
    x = np.arange(len(data_s))
    y = data_s['close'].values
    
    # 移動平均
    rolling = pd.Series(y).rolling(7).mean()
    
    # 線性回歸預測未來 7 天
    model = LinearRegression()
    model.fit(x.reshape(-1, 1), y)
    future_x = np.arange(len(x), len(x) + 7).reshape(-1, 1)
    future_y = model.predict(future_x)
    
    ax.plot(x, y, label='收盤價')
    ax.plot(x, rolling, label='7日移動平均', linestyle='--')
    ax.plot(range(len(x), len(x) + 7), future_y, label='預測（未來7天）', linestyle=':', color='red')
    ax.set_title(symbol)
    ax.legend()

plt.tight_layout()
plt.savefig('assets_chart.png')
plt.show()
print("圖表已儲存為 assets_chart.png")
```

## 提示
- `pd.DataFrame.rolling(7).mean()` 可計算 7 日移動平均
- `sklearn.linear_model.LinearRegression` 需要 2D 輸入：`x.reshape(-1, 1)`
- `plt.subplots(n, 1)` 建立 n 個垂直排列的子圖
- `parse_dates=['date']` 讓 Pandas 自動解析日期欄位
- 可用 `np.random.seed(42)` 讓每次結果一致，方便除錯
