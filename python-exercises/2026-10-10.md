# 第 14 週今日 Python 練習題：新聞聚合器實戰專案

## 題目說明

綜合運用前 13 週所學，打造一個完整的「新聞聚合器」程式。
程式會從公開 RSS 新聞來源抓取最新文章標題、連結與摘要，
整理成結構化資料後存為 CSV 檔，並計算關鍵字出現頻率產生報表。

---

## 技術要求

- **概念：** 爬蟲、資料清理、Pandas 分析、matplotlib 視覺化、檔案讀寫
- **需要的模組：**
  - `requests` — HTTP 請求
  - `xml.etree.ElementTree`（標準庫）— 解析 RSS XML
  - `pandas` — 資料整理與分析
  - `matplotlib` — 關鍵字長條圖
  - `collections.Counter` — 計算詞頻
  - `csv` / `datetime`（標準庫）— 輸出與時間戳記

---

## 具體任務

1. **抓取 RSS**
   使用 `requests.get()` 取得以下任一 RSS feed（選一即可）：
   - BBC 科技：`https://feeds.bbci.co.uk/news/technology/rss.xml`
   - 紐約時報科技：`https://rss.nytimes.com/services/xml/rss/nyt/Technology.rss`
   
   以 `xml.etree.ElementTree` 解析，擷取每篇文章的：
   - `title`（標題）
   - `link`（連結）
   - `pubDate`（發布日期，格式化為 `YYYY-MM-DD`）
   - `description`（摘要，去除 HTML 標籤）

2. **清理資料 & 存為 CSV**
   - 用 Pandas 建立 DataFrame
   - 移除重複文章（依 `link` 去重）
   - 將結果存為 `news_YYYY-MM-DD.csv`（檔名含今日日期）

3. **關鍵字頻率分析**
   - 合併所有標題文字，轉為小寫，分割為單詞列表
   - 過濾掉停用詞（`stop_words = {"the","a","an","in","of","to","is","for","on","and","with","at",...}`）
   - 使用 `Counter` 取出出現次數 Top 10 的關鍵字

4. **視覺化**
   - 用 `matplotlib` 畫水平長條圖，顯示 Top 10 關鍵字與出現次數
   - 加上標題、軸標籤，存為 `news_keywords_YYYY-MM-DD.png`

5. **整合主程式**
   定義 `main()` 函數串接以上步驟，並在最後 `print()` 摘要：
   ```
   ✅ 共抓取 XX 篇文章
   📁 已存為 news_2026-10-10.csv
   🔑 Top 3 關鍵字：AI(5), data(4), ...
   🖼 圖表已存為 news_keywords_2026-10-10.png
   ```

## 提示

- 用 `re.sub(r'<[^>]+>', '', text)` 移除 HTML 標籤
- `pubDate` 格式各 RSS 不同，可用 `email.utils.parsedate()` 轉換後再格式化
- 若網路連線失敗，用 `try/except requests.exceptions.RequestException` 捕捉錯誤並提示使用者
- 函數拆分建議：`fetch_rss()` → `parse_articles()` → `clean_data()` → `analyze_keywords()` → `plot_chart()`
