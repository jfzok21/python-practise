# 第 14 週今日 Python 練習題：天氣趨勢分析與預測

## 題目說明

綜合運用前 13 週所學，打造一個完整的「天氣趨勢分析與預測」程式。
程式會從免費的 Open-Meteo API 取得指定城市過去 30 天的每日氣溫資料，
用 Pandas 整理並統計摘要，以 matplotlib 繪製趨勢圖，
最後利用 scikit-learn 線性回歸預測未來 7 天的最高氣溫。

---

## 技術要求

- **概念：** API 爬蟲、資料清理、統計分析、時序視覺化、線性回歸預測
- **需要的模組：**
  - `requests` — HTTP 請求（Open-Meteo 免費 API，無需金鑰）
  - `pandas` — 資料整理與統計
  - `matplotlib` — 趨勢折線圖
  - `sklearn.linear_model.LinearRegression` — 溫度預測
  - `numpy` — 數值處理
  - `datetime`（標準庫）— 日期計算

---

## 具體任務

1. **從 Open-Meteo API 取得氣溫資料**
   Open-Meteo 提供免費的歷史天氣資料，範例 URL（台北，過去 30 天）：
   ```
   https://api.open-meteo.com/v1/forecast?
     latitude=25.04&longitude=121.53
     &daily=temperature_2m_max,temperature_2m_min
     &past_days=30&forecast_days=1
     &timezone=Asia%2FTaipei
   ```
   使用 `requests.get()` 取得 JSON，解析出：
   - `daily.time`（日期列表）
   - `daily.temperature_2m_max`（每日最高溫）
   - `daily.temperature_2m_min`（每日最低溫）

2. **清理資料 & 統計摘要**
   - 用 Pandas 建立 DataFrame，欄位為 `date`、`tmax`、`tmin`
   - 計算並 `print()` 統計摘要：
     - 30 天平均最高溫、平均最低溫
     - 最熱的一天（日期 + 溫度）
     - 最涼的一天（日期 + 溫度）
     - 日溫差最大的一天（`tmax - tmin` 最大）
   - 將 DataFrame 存為 `weather_YYYY-MM-DD.csv`

3. **視覺化：趨勢折線圖**
   - 用 `matplotlib` 畫折線圖，同一張圖顯示：
     - 最高溫（紅色實線）
     - 最低溫（藍色實線）
     - 日均溫 `(tmax + tmin) / 2`（灰色虛線）
   - 加上標題、軸標籤、圖例，X 軸日期每隔 5 天顯示一次，旋轉 45°
   - 存為 `weather_trend_YYYY-MM-DD.png`

4. **線性回歸預測未來 7 天最高溫**
   - 將日期轉為距起始日的天數（0, 1, 2, … 29）作為特徵 X
   - 以 `tmax` 作為目標 y，訓練 `LinearRegression` 模型
   - 預測第 31–37 天（對應未來 7 天）的最高溫
   - 在折線圖末端以**橘色虛線**延伸標示預測值，並加上「Predicted」圖例
   - 重新存圖（覆蓋同一個 `weather_trend_YYYY-MM-DD.png`）

5. **整合主程式**
   定義 `main()` 函數串接以上步驟，最後輸出摘要：
   ```
   🌡 過去 30 天資料（台北）
   📊 平均最高溫：XX.X°C  |  平均最低溫：XX.X°C
   🔥 最熱一天：2026-XX-XX（XX.X°C）
   ❄  最涼一天：2026-XX-XX（XX.X°C）
   📁 已存為 weather_2026-10-11.csv
   🖼 圖表已存為 weather_trend_2026-10-11.png
   📈 未來 7 天預測最高溫：[28.1, 27.9, 28.3, ...]
   ```

## 提示

- Open-Meteo 是免費 API，不需要 API 金鑰，直接 `requests.get(url)` 即可
- 解析日期字串：`pd.to_datetime(df['date'])` 讓 Pandas 處理日期型態
- X 軸日期格式化：`ax.xaxis.set_major_formatter(mdates.DateFormatter('%m/%d'))`，記得 `import matplotlib.dates as mdates`
- 線性回歸特徵：`X = np.arange(len(df)).reshape(-1, 1)`，目標 `y = df['tmax'].values`
- 預測天數：`X_pred = np.arange(len(df), len(df) + 7).reshape(-1, 1)`
- 若 API 失敗，用 `try/except` 捕捉並提示使用者檢查網路
