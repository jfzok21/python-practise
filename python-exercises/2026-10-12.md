# 第 14 週今日 Python 練習題：個人股票投資組合分析器

## 題目說明

建立一個完整的「個人股票投資組合分析器」，能夠讀取模擬交易紀錄、計算損益、分析績效，並生成視覺化報告。這是一個整合爬蟲、Pandas、Matplotlib 與基礎機器學習的實戰專案。

## 技術要求
- 概念：資料讀寫、Pandas 資料處理、Matplotlib 視覺化、sklearn 線性迴歸預測
- 需要的模組：`pandas`, `matplotlib`, `numpy`, `sklearn`, `csv`, `datetime`

## 具體任務

### 1. 建立模擬資料
建立一個 CSV 檔案 `portfolio.csv`，包含以下欄位並填入至少 10 筆交易紀錄：
```
date,stock_id,stock_name,action,quantity,price
2026-01-05,2330,台積電,buy,10,950
2026-01-10,2317,鴻海,buy,20,155
...
```

### 2. 讀取與清理資料
- 使用 Pandas 讀取 CSV
- 將 `date` 欄位轉換為 `datetime` 型態
- 計算每筆交易的「總金額」（quantity × price）

### 3. 計算投資組合績效
- 計算每支股票的平均買入成本
- 假設今日收盤價（自行設定），計算每支股票的損益金額與損益百分比
- 計算整體投資組合的報酬率

### 4. 視覺化報告（至少 2 張圖）
- **圓餅圖**：各股票佔總投資金額的比例
- **長條圖**：每支股票的損益百分比（正值綠色、負值紅色）

### 5. 線性趨勢預測（選做，但建議完成）
- 假設某支股票過去 30 天的收盤價存在 `prices.csv`
- 使用 `sklearn.linear_model.LinearRegression` 預測未來 5 天的趨勢
- 在折線圖上繪製歷史價格與預測延伸線

## 範例

```python
# 輸入：portfolio.csv 範例
# date,stock_id,stock_name,action,quantity,price
# 2026-01-05,2330,台積電,buy,10,950
# 2026-02-15,2330,台積電,buy,5,1020
# 2026-03-01,2317,鴻海,buy,30,148

# 預期輸出
print("=== 投資組合摘要 ===")
print("台積電：持有 15 股，平均成本 973.3 元，今日 1050 元，損益 +7.9%")
print("鴻海：持有 30 股，平均成本 148 元，今日 141 元，損益 -4.7%")
print("整體投資組合報酬率：+4.2%")
```

```python
# 圓餅圖範例
import matplotlib.pyplot as plt
import matplotlib
matplotlib.rcParams['font.family'] = ['Arial Unicode MS', 'sans-serif']

labels = ['台積電', '鴻海', '聯發科']
sizes = [145995, 4440, 30000]
plt.pie(sizes, labels=labels, autopct='%1.1f%%', startangle=90)
plt.title('投資組合配置')
plt.savefig('portfolio_pie.png', dpi=150)
plt.show()
```

## 提示
- 使用 `pd.to_datetime()` 轉換日期欄位
- 用 `groupby('stock_id').agg(...)` 彙整每支股票的統計資料
- Matplotlib 中文字型問題：在程式最上方加入
  ```python
  import matplotlib
  matplotlib.rcParams['font.family'] = ['Arial Unicode MS', 'Noto Sans CJK TC', 'sans-serif']
  ```
- 損益長條圖可用 `color=['green' if x > 0 else 'red' for x in profits]` 決定顏色
- 線性迴歸：`X = np.arange(len(prices)).reshape(-1, 1)`，`y = prices`
