# 第 15 週今日 Python 練習題：個人股票投資組合追蹤器

## 題目說明

建立一個命令列工具，讓使用者能管理自己的股票投資組合。系統需支援新增持股、查詢目前市值、計算損益，並將資料持久化至 CSV 檔案。這道題整合了過去所有學過的技術：資料結構、檔案讀寫、字串處理、API 呼叫（選做）及簡易資料分析。

## 技術要求
- 概念：dict、list、CSV 讀寫、函數設計、迴圈、條件判斷、格式化輸出
- 需要的模組：`csv`、`os`、`datetime`（選做進階：`requests`、`pandas`）

## 具體任務

1. **定義資料結構**  
   每筆持股記錄包含：
   - `symbol`（股票代號，如 `AAPL`）
   - `shares`（持有股數，浮點數）
   - `buy_price`（買入均價，浮點數）
   - `buy_date`（買入日期，字串 `YYYY-MM-DD`）

2. **實作以下函數**

   | 函數名稱 | 功能說明 |
   |----------|----------|
   | `load_portfolio(filepath)` | 從 CSV 讀取投資組合，回傳 `list[dict]` |
   | `save_portfolio(filepath, portfolio)` | 將投資組合存入 CSV |
   | `add_stock(portfolio, symbol, shares, buy_price, buy_date)` | 新增一筆持股（若已存在則累加均攤） |
   | `remove_stock(portfolio, symbol, shares)` | 減少或移除持股 |
   | `summary(portfolio, current_prices)` | 印出損益摘要表格 |
   | `total_value(portfolio, current_prices)` | 回傳目前總市值 |

3. **主程式（互動式選單）**  
   執行 `python portfolio.py` 後顯示：
   ```
   === 投資組合管理系統 ===
   1. 查看持股摘要
   2. 新增持股
   3. 賣出持股
   4. 離開
   ```

4. **CSV 格式**  
   標頭列：`symbol,shares,buy_price,buy_date`

## 範例

```python
# 初始化（空的或從檔案讀取）
portfolio = load_portfolio("portfolio.csv")

# 新增持股
add_stock(portfolio, "AAPL", 10, 150.0, "2026-08-01")
add_stock(portfolio, "TSLA", 5, 200.0, "2026-09-15")

# 模擬目前價格（dict）
current_prices = {"AAPL": 175.0, "TSLA": 180.0}

# 印出摘要
summary(portfolio, current_prices)
```

預期輸出：
```
代號    股數    買入均價   目前價格   成本        市值         損益        損益%
AAPL    10.0    150.00     175.00     1500.00     1750.00     +250.00     +16.67%
TSLA    5.0     200.00     180.00     1000.00     900.00      -100.00     -10.00%
────────────────────────────────────────────────────────────────────────────────
總計                                  2500.00     2650.00     +150.00     +6.00%
```

## 提示

- 使用 `csv.DictReader` 和 `csv.DictWriter` 處理 CSV，保留欄位名稱清晰。
- 損益計算：`profit = (current_price - buy_price) * shares`
- 損益百分比：`profit_pct = (current_price / buy_price - 1) * 100`
- 累加均攤公式：`new_avg = (old_shares * old_price + new_shares * new_price) / (old_shares + new_shares)`
- 用 `f"{value:>10.2f}"` 對齊數字欄位，讓表格整齊。
- 若 CSV 不存在，`load_portfolio` 應回傳空 list，不要拋出錯誤。

## 學習重點
