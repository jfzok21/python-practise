# 第 15 週今日 Python 練習題：個人財務追蹤器（CSV + Pandas + 視覺化）

## 題目說明

建立一個**個人財務追蹤小工具**：從 CSV 檔讀取收支紀錄，用 Pandas 分析消費模式，再用 matplotlib 生成月度收支報表圖。這是一個整合前幾週所有技能的完整實戰專案。

## 技術要求
- 概念：CSV 讀寫、Pandas DataFrame 操作、資料聚合、matplotlib 圖表
- 需要的模組：`pandas`、`matplotlib`、`csv`、`datetime`

## 具體任務

1. **建立資料**  
   建立 `finance.csv`，格式如下（含至少 10 筆紀錄）：
   ```
   date,type,category,amount,note
   2026-10-01,支出,餐飲,150,午餐便當
   2026-10-02,收入,薪資,50000,月薪
   ```

2. **讀取與清理資料**  
   用 Pandas 讀取 CSV，確認：
   - `date` 欄位轉為 `datetime` 型態
   - `amount` 欄位為數字型態
   - 刪除空白列（如果有）

3. **分析消費模式**  
   計算並印出：
   - 本月總收入 vs 總支出
   - 各「類別」的支出合計（由高到低排序）
   - 支出最多的那一天

4. **生成視覺化報表**  
   畫出以下兩張圖（可以用 `subplot` 放在同一個視窗）：
   - **圓餅圖**：各類別支出佔比
   - **長條圖**：每天的支出金額

5. **存成報表檔**  
   將圖表儲存為 `finance_report_2026-10.png`

## 範例

```python
# 範例輸出
=== 10 月財務摘要 ===
總收入：50,000 元
總支出：8,320 元
結餘：41,680 元

各類別支出：
  餐飲       3,200 元
  交通       1,500 元
  娛樂       2,100 元
  日用品     1,520 元

支出最多的一天：2026-10-15（1,800 元）

報表已儲存：finance_report_2026-10.png
```

## 提示

- 用 `pd.read_csv('finance.csv', parse_dates=['date'])` 自動解析日期
- 篩選支出：`df[df['type'] == '支出']`
- 用 `groupby('category')['amount'].sum()` 做類別加總
- 圓餅圖：`plt.pie(sizes, labels=labels, autopct='%1.1f%%')`
- 長條圖：`plt.bar(dates, amounts)`
- 儲存圖片：`plt.savefig('finance_report_2026-10.png', dpi=150, bbox_inches='tight')`
