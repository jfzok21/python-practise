# 第 15 週今日 Python 練習題：個人股票監控小工具

## 題目說明

建立一個可以從網路抓取多支股票即時資訊、分析漲跌、並將結果儲存成 CSV 的完整小工具。這個專案整合了前幾週學過的 requests、BeautifulSoup、Pandas、matplotlib，讓你體驗一個「從資料收集到視覺化」的完整流程。

## 技術要求
- 概念：網頁爬蟲、資料清理、Pandas 分析、matplotlib 繪圖、CSV 讀寫
- 需要的模組：`requests`、`beautifulsoup4`、`pandas`、`matplotlib`

安裝指令（如尚未安裝）：
```bash
pip install requests beautifulsoup4 pandas matplotlib
```

## 具體任務

1. **定義股票清單**：建立一個 Python dict，包含至少 5 支你感興趣的台股代號與名稱，例如：
   ```python
   stocks = {"2330": "台積電", "2317": "鴻海", "2454": "聯發科", "2308": "台達電", "3008": "大立光"}
   ```

2. **爬取資料**：對每支股票，從台灣證交所（TWSE）公開 API 取得當日收盤資訊：
   ```
   https://mis.twse.com.tw/stock/api/getStockInfo.jsp?ex_ch=tse_{代號}.tw
   ```
   解析 JSON 回應，取出：股票代號、名稱、現價（`z`）、昨收（`y`）、漲跌（計算）、漲跌幅（%）。

3. **整理成 DataFrame**：用 Pandas 將所有股票資料組成一個 DataFrame，欄位為：
   `代號`、`名稱`、`現價`、`昨收`、`漲跌`、`漲跌幅(%)`

4. **篩選與排序**：
   - 印出漲幅 > 0 的股票（今日上漲）
   - 依漲跌幅由高到低排序後印出完整表格

5. **儲存 CSV**：將 DataFrame 儲存為 `stock_data_YYYY-MM-DD.csv`（日期為今天）

6. **繪製長條圖**：以 matplotlib 畫出各股票的漲跌幅（%）長條圖，上漲用紅色、下跌用綠色（台灣習慣），並存成 `stock_chart_YYYY-MM-DD.png`

## 提示
- TWSE API 有時需要加上 `User-Agent` header 才不會被擋，可使用：
  ```python
  headers = {"User-Agent": "Mozilla/5.0"}
  ```
- JSON 中若股價欄位為 `"-"` 表示休市，記得做判斷（可跳過或填 NaN）
- `float()` 轉換前先確認字串不是 `"-"`
- matplotlib 長條圖可用 `bar()` 搭配 `color` 清單：
  ```python
  colors = ["red" if x > 0 else "green" for x in changes]
  plt.bar(names, changes, color=colors)
  ```
- 記得加上中文字型設定，否則圖表中文會顯示方塊：
  ```python
  import matplotlib
  matplotlib.rcParams['font.family'] = 'DejaVu Sans'  # 或系統支援的中文字型
  ```
