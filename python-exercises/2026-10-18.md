## 題目說明

整合過去幾週所學的爬蟲、Pandas、matplotlib 與基本 ML，打造一個能自動抓取公開股票或匯率歷史資料、進行統計分析，並輸出視覺化圖表的實戰小工具。本題以 Yahoo Finance 的公開 CSV 下載（不需登入）為資料來源，不需要申請 API key。

---

## 技術要求

- **概念**：requests、Pandas 資料清理、移動平均、matplotlib 繪圖、簡單線性回歸預測
- **需要的模組**：`requests`、`pandas`、`matplotlib`、`scikit-learn`（選做 ML 部分）

---

## 具體任務

1. **抓取歷史資料**
   - 使用 `requests` 下載以下 Yahoo Finance CSV（以台積電 ADR `TSM` 為例，最近 90 天）：
     ```
     https://query1.finance.yahoo.com/v7/finance/download/TSM?range=3mo&interval=1d&events=history
     ```
   - 將回傳的 CSV 文字用 `pandas.read_csv(io.StringIO(...))` 解析成 DataFrame。

2. **資料清理**
   - 確認 `Date` 欄位轉為 `datetime` 型態。
   - 移除任何含有 NaN 的列。
   - 只保留 `Date`、`Open`、`High`、`Low`、`Close`、`Volume` 六欄。

3. **統計計算**
   - 計算並新增欄位：
     - `MA7`：7 日移動平均收盤價
     - `MA20`：20 日移動平均收盤價
     - `Daily_Return`：每日漲跌幅（%）= `(Close - Close.shift(1)) / Close.shift(1) * 100`

4. **視覺化**
   - 圖一：折線圖，同時顯示 Close、MA7、MA20（三條線，不同顏色）。
   - 圖二：長條圖，顯示每日 Daily_Return（正值綠色、負值紅色）。
   - 每張圖需有標題、x/y 軸標籤、圖例。

5. **儲存結果**
   - 將清理後的 DataFrame（含新欄位）存成 `stock_analysis.csv`。
   - 將兩張圖合併存成 `stock_chart.png`（使用 `plt.savefig`）。

---

## 範例

```python
import io
import requests
import pandas as pd
import matplotlib.pyplot as plt

# 步驟 1：抓資料
url = "https://query1.finance.yahoo.com/v7/finance/download/TSM?range=3mo&interval=1d&events=history"
headers = {"User-Agent": "Mozilla/5.0"}
resp = requests.get(url, headers=headers)
df = pd.read_csv(io.StringIO(resp.text))

# 步驟 2：清理
df["Date"] = pd.to_datetime(df["Date"])
df = df.dropna()
df = df[["Date", "Open", "High", "Low", "Close", "Volume"]]

# 步驟 3：計算
df["MA7"] = df["Close"].rolling(7).mean()
df["MA20"] = df["Close"].rolling(20).mean()
df["Daily_Return"] = df["Close"].pct_change() * 100

# 步驟 4：繪圖（圖一）
fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(12, 8))

ax1.plot(df["Date"], df["Close"], label="Close", color="blue")
ax1.plot(df["Date"], df["MA7"],  label="MA7",   color="orange", linestyle="--")
ax1.plot(df["Date"], df["MA20"], label="MA20",  color="red",    linestyle="--")
ax1.set_title("TSM 收盤價與移動平均")
ax1.set_xlabel("日期")
ax1.set_ylabel("價格（USD）")
ax1.legend()

# 步驟 4：繪圖（圖二）
colors = ["green" if v >= 0 else "red" for v in df["Daily_Return"]]
ax2.bar(df["Date"], df["Daily_Return"], color=colors)
ax2.set_title("TSM 每日漲跌幅 (%)")
ax2.set_xlabel("日期")
ax2.set_ylabel("漲跌幅 (%)")

plt.tight_layout()
plt.savefig("stock_chart.png", dpi=150)
plt.show()

# 步驟 5：儲存 CSV
df.to_csv("stock_analysis.csv", index=False)
print("完成！已儲存 stock_analysis.csv 與 stock_chart.png")
```

```

```

## 提示

- 若 Yahoo Finance 回傳 `401` 或封鎖，可改用本地測試資料：用 `pandas` 手動建立假的 DataFrame（日期、隨機收盤價）來測試後續步驟。
- `rolling(n).mean()` 前 n-1 筆會是 NaN，繪圖時會自動跳過，無需特別處理。
- `pct_change()` 第一筆同樣是 NaN，記得在繪圖前用 `.fillna(0)` 或直接跳過。
- `plt.subplots(2, 1)` 可在同一個 PNG 畫兩張子圖。
