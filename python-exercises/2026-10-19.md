# 第 15 週今日 Python 練習題：全台空氣品質指數（AQI）監控工具

## 題目說明

運用台灣環境部（環保署）完全免費、無需申請 API Key 的公開資料，建立一個能自動抓取全台即時 AQI（空氣品質指數）、分析各縣市空氣狀況、並輸出報表與視覺化圖表的實戰小工具。這個專案整合了 requests、Pandas、matplotlib，讓你體驗一個「政府開放資料 → 分析 → 視覺化」的完整流程。

## 具體任務

1. **抓取即時 AQI 資料**
   - 使用 `requests` 呼叫環境部開放資料 API（JSON 格式、完全免費）：
     ```
     https://data.moenv.gov.tw/api/v2/aqx_p_432?api_key=e8dd42e6-9b8b-43f8-991e-b3dee723a52d&limit=1000&sort=ImportDate%20desc&format=JSON
     ```
   - 解析回傳 JSON，取出 `records` 清單，每筆含：`sitename`（測站）、`county`（縣市）、`aqi`（AQI 值）、`status`（狀態描述）、`pm2.5`、`pm10`、`o3`、`co`。

2. **整理成 DataFrame**
   - 用 Pandas 將資料組成 DataFrame。
   - 將 `aqi`、`pm2.5`、`pm10` 等數值欄位從字串轉為數字（`pd.to_numeric(errors='coerce')`）。
   - 移除 `aqi` 為 NaN 的列（部分測站可能無資料）。

3. **統計分析**
   - 依縣市（`county`）分組，計算各縣市平均 AQI（取整數）。
   - 找出 AQI 最高與最低的縣市。
   - 列出所有 `status` 為「對所有族群不健康」或「非常不健康」或「危害」的測站（若有）。

4. **視覺化**
   - 畫一張**水平長條圖**，X 軸為縣市平均 AQI，Y 軸為縣市名稱，依 AQI 由高到低排序。
   - 每個長條依 AQI 值上色（參考 AQI 標準色彩）：
     - 0–50：綠色（良好）
     - 51–100：黃色（普通）
     - 101–150：橘色（對敏感族群不健康）
     - 151–200：紅色（對所有族群不健康）
     - 201+：紫色（非常不健康 / 危害）
   - 加上標題、X 軸標籤、AQI 數值標注在長條右側。

5. **儲存結果**
   - 將縣市平均 AQI DataFrame 存成 `aqi_report_YYYY-MM-DD.csv`。
   - 將圖表存成 `aqi_chart_YYYY-MM-DD.png`。
   - 在終端機印出摘要報告（最好、最差縣市及全台平均 AQI）。

## 範例

```python
import requests
import pandas as pd
import matplotlib.pyplot as plt
from datetime import date

today = date.today().isoformat()

# 步驟 1：抓資料
url = (
    "https://data.moenv.gov.tw/api/v2/aqx_p_432"
    "?api_key=e8dd42e6-9b8b-43f8-991e-b3dee723a52d"
    "&limit=1000&sort=ImportDate%20desc&format=JSON"
)
resp = requests.get(url, timeout=10)
records = resp.json()["records"]

# 步驟 2：整理 DataFrame
df = pd.DataFrame(records)
for col in ["aqi", "pm2.5", "pm10", "o3", "co"]:
    df[col] = pd.to_numeric(df[col], errors="coerce")
df = df.dropna(subset=["aqi"])

# 步驟 3：縣市平均 AQI
county_avg = (
    df.groupby("county")["aqi"]
    .mean()
    .round()
    .astype(int)
    .reset_index()
    .rename(columns={"aqi": "avg_aqi"})
    .sort_values("avg_aqi", ascending=False)
)

best = county_avg.iloc[-1]
worst = county_avg.iloc[0]
overall_avg = int(df["aqi"].mean())
print(f"全台平均 AQI：{overall_avg}")
print(f"最差縣市：{worst['county']}（AQI {worst['avg_aqi']}）")
print(f"最佳縣市：{best['county']}（AQI {best['avg_aqi']}）")

# 步驟 4：上色函數
def aqi_color(val):
    if val <= 50:   return "green"
    if val <= 100:  return "yellow"
    if val <= 150:  return "orange"
    if val <= 200:  return "red"
    return "purple"

colors = [aqi_color(v) for v in county_avg["avg_aqi"]]

# 步驟 4：繪圖
fig, ax = plt.subplots(figsize=(10, 8))
bars = ax.barh(county_avg["county"], county_avg["avg_aqi"], color=colors)
for bar, val in zip(bars, county_avg["avg_aqi"]):
    ax.text(bar.get_width() + 1, bar.get_y() + bar.get_height() / 2,
            str(val), va="center", fontsize=9)
ax.set_xlabel("平均 AQI")
ax.set_title(f"全台縣市平均 AQI（{today}）")
ax.invert_yaxis()  # AQI 最高在最上方
plt.tight_layout()
plt.savefig(f"aqi_chart_{today}.png", dpi=150)
plt.show()

# 步驟 5：儲存 CSV
county_avg.to_csv(f"aqi_report_{today}.csv", index=False)
print(f"✅ 已儲存 aqi_report_{today}.csv 與 aqi_chart_{today}.png")
```

預期終端機輸出（數字為示意）：
```
全台平均 AQI：58
最差縣市：雲林縣（AQI 95）
最佳縣市：臺東縣（AQI 28）
✅ 已儲存 aqi_report_2026-10-19.csv 與 aqi_chart_2026-10-19.png
```

## 提示

- 若 API 連線逾時，可先將 JSON 存成本機檔案，離線測試分析部分。
- `ax.invert_yaxis()` 讓最差縣市顯示在圖表最上方，更直覺。
- 中文顯示問題：在 matplotlib 加上 `plt.rcParams['font.family'] = 'DejaVu Sans'`（英文縣市名）或安裝 `apt-get install fonts-noto-cjk` 後改用 `'Noto Sans CJK TC'`。
- `pd.to_numeric(errors='coerce')` 是處理「空字串或非數字」的好習慣，在真實爬蟲資料中非常常見。
