# 第 16 週今日 Python 練習題：個人書單追蹤與分析系統

## 題目說明

建立一個「個人書單追蹤與分析系統」，讓使用者能夠新增書籍閱讀紀錄、查詢進度、並透過圖表分析閱讀習慣。這是一個綜合實戰專案，涵蓋資料輸入、CSV 儲存、Pandas 分析，以及 Matplotlib 視覺化。

---

## 技術要求
- 概念：資料結構（dict/list）、函數設計、錯誤處理、檔案讀寫
- 需要的模組：`csv`、`pandas`、`matplotlib`、`datetime`、`os`

---

## 具體任務

### 任務 1：建立資料管理模組 `book_manager.py`

實作以下函數：

1. `add_book(title, author, pages, genre)` — 新增一本書，記錄「書名、作者、頁數、分類、新增日期、閱讀狀態（未開始/閱讀中/已完成）、完成日期（預設 None）」，儲存到 `books.csv`。
2. `update_status(title, status, finish_date=None)` — 更新書的閱讀狀態；若狀態為「已完成」，自動填入今天日期。
3. `list_books(status=None)` — 列出所有書籍，可依狀態過濾。

### 任務 2：建立分析模組 `book_analyzer.py`

使用 Pandas 分析 `books.csv`，實作：

1. `summary()` — 輸出統計摘要：總書數、已完成數、閱讀中數、平均頁數。
2. `genre_distribution()` — 計算各分類書籍數量（使用 `value_counts()`）。
3. `reading_speed(pages_per_day)` — 估算「閱讀中」的書籍各需幾天讀完。

### 任務 3：建立視覺化模組 `book_chart.py`

1. `plot_genre_pie()` — 用圓餅圖（`pie`）顯示各分類書籍比例。
2. `plot_status_bar()` — 用長條圖（`bar`）顯示各閱讀狀態的書籍數量。
3. 圖表需包含標題、圖例，儲存為 `reading_report.png`。

### 任務 4：建立主程式 `main.py`

製作簡單的文字選單讓使用者互動：

```
=== 書單管理系統 ===
1. 新增書籍
2. 更新閱讀狀態
3. 顯示書單
4. 查看統計摘要
5. 產生分析圖表
0. 離開
```

## 範例

```python
# 新增書籍
add_book("Python 入門", "王小明", 350, "技術")
add_book("三體", "劉慈欣", 600, "科幻")
add_book("原子習慣", "James Clear", 280, "勵志")

# 更新狀態
update_status("Python 入門", "已完成")
update_status("三體", "閱讀中")

# 統計摘要輸出範例
# 總書數：3
# 已完成：1
# 閱讀中：1
# 未開始：1
# 平均頁數：410.0 頁
```

## 提示

- 使用 `pandas.read_csv()` 和 `pandas.DataFrame.to_csv()` 處理 CSV，注意 `index=False`。
- 讀取 CSV 前先用 `os.path.exists()` 檢查檔案是否存在。
- 新增書籍時用 `datetime.date.today().isoformat()` 取得今天日期。
- Matplotlib 中文顯示問題：加入 `plt.rcParams['font.sans-serif'] = ['DejaVu Sans']`，或改用英文標籤。
- 更新書籍時讀取整份 CSV → 修改目標列 → 寫回，注意不要覆蓋其他資料。
