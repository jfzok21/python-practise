# 第 16 週今日 Python 練習題：股票資料分析儀表板

## 題目說明

從公開的 CSV 資料集讀取多支股票的歷史價格，進行資料清理、統計分析，並以 matplotlib 繪製視覺化圖表，最終產生一份 HTML 格式的簡易分析報告。

本題整合了前幾週的核心技能：CSV 讀寫（第 5 週）、Pandas 資料處理（第 10 週）、matplotlib 視覺化（第 11 週），以及字串格式化與檔案輸出。

---

## 技術要求

- 概念：資料清理、移動平均、百分比報酬率、多圖排版
- 需要的模組：`pandas`、`matplotlib`、`os`、`datetime`

---

## 具體任務

1. **建立模擬資料**
   用 Python 產生 3 支股票（`AAPL`、`GOOGL`、`TSLA`）過去 90 天的模擬收盤價 CSV（使用 `random.gauss` 產生隨機漲跌），欄位格式：

   ```
   date,ticker,close
   2026-07-23,AAPL,185.40
   ...
   ```

2. **資料讀取與清理**
   - 用 `pandas` 讀取 CSV
   - 將 `date` 欄轉為 `datetime` 型態
   - 確認無缺值（如有則填補前一日收盤價）

3. **計算指標**
   - 每支股票的 **7 日移動平均**（`rolling(7).mean()`）
   - 每支股票的 **累積報酬率**（`(price / price.iloc[0] - 1) * 100`）
   - 最終日期各股票的報酬率排名

4. **繪製圖表**
   - 上方：各股票收盤價 + 7 日均線（同一張圖，不同顏色）
   - 下方：各股票累積報酬率折線圖
   - 加上標題、圖例、X 軸日期格式（`YYYY-MM-DD`）

5. **輸出報告**
   將分析結果輸出為 `report.html`，包含：
   - 報告標題與日期
   - 各股票最終報酬率表格
   - 嵌入的圖表圖片（base64 編碼或本機路徑）

# 執行後產生的檔案

# stock_chart.png  — matplotlib 圖表

## 提示

- `pd.DataFrame.pivot(index='date', columns='ticker', values='close')` 可讓每支股票變成一欄，方便一次畫多條線
- `matplotlib.dates.DateFormatter('%m-%d')` 可格式化 X 軸日期標籤
- `plt.subplots(2, 1, figsize=(12, 8))` 建立上下兩張子圖
- 圖片嵌入 HTML：`import base64`，讀取 PNG bytes 後轉 base64 字串，放進 `<img src="data:image/png;base64,...">` 標籤

## 學習重點

**與爬蟲的關聯：** 本題使用模擬資料，但真實情境中這份 CSV 可以來自 `requests` 抓取財經 API（如 Yahoo Finance），或 BeautifulSoup 解析股票頁面——資料流程完全相同，只需替換資料來源。

**與 ML 的關聯：** 移動平均是時間序列預測的基礎特徵；累積報酬率是訓練漲跌分類模型（第 12 週 sklearn）時常用的目標變數。這份儀表板可以直接當作 ML 前處理管線的視覺化驗證工具。
