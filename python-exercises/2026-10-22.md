# 第 16 週今日 Python 練習題：新聞資料爬取與分析儀表板

## 題目說明

建立一個整合型實戰專案：從新聞網站爬取文章資料，使用 Pandas 進行統計分析，並產生一份包含圖表的 HTML 報告。這個專案整合了你前幾週學習到的所有技術——網頁爬蟲、資料處理、視覺化——模擬真實資料工程師的日常工作流程。

## 技術要求
- 概念：爬蟲、資料清理、統計分析、視覺化、報告生成
- 需要的模組：`requests`、`BeautifulSoup4`、`pandas`、`matplotlib`、`csv`、`datetime`

## 具體任務

1. **爬取資料（模擬版）**：建立一個 `generate_mock_news()` 函數，產生 30 筆模擬新聞資料，每筆包含：
   - `title`（標題）
   - `category`（分類：科技/財經/體育/國際/生活）
   - `publish_date`（發布日期，過去 30 天內隨機）
   - `word_count`（字數，100–2000 之間隨機）
   - `views`（瀏覽次數，50–50000 之間隨機）

2. **資料存儲**：將爬取的資料存入 `news_data.csv`。

3. **資料分析**：使用 Pandas 計算：
   - 各分類文章數量與平均瀏覽次數
   - 每日發布文章數（時間序列）
   - 瀏覽次數最高的前 5 篇文章
   - 字數與瀏覽次數的相關係數

4. **視覺化**：使用 matplotlib 製作以下圖表並儲存為 PNG：
   - 長條圖：各分類文章數量
   - 折線圖：每日發布趨勢
   - 散點圖：字數 vs 瀏覽次數

5. **報告生成**：自動產生 `report.html`，內嵌所有圖表（Base64 格式）與統計摘要表格。

## 提示

- 使用 `random.seed(42)` 讓每次執行產生相同的模擬資料，方便除錯
- Pandas 的 `groupby()` + `agg()` 可以一次計算多個統計值
- `matplotlib.pyplot.savefig()` 儲存圖表前記得設定 `dpi=100` 以控制品質
- 將圖片轉 Base64 嵌入 HTML：
  ```python
  import base64
  with open('chart.png', 'rb') as f:
      img_b64 = base64.b64encode(f.read()).decode()
  html_img = f'<img src="data:image/png;base64,{img_b64}">'
  ```
- 時間序列分析：先用 `pd.to_datetime()` 轉換日期欄位，再用 `dt.date` 取得日期
