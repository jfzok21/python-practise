打造一個**命令列個人記帳系統**，整合你在前 15 週所學的所有技能：變數、迴圈、函數、資料結構、CSV 檔案讀寫、pandas 資料分析，以及 matplotlib 視覺化。

## 具體任務

### 1. 建立資料儲存結構
建立 `records.csv`，欄位設計如下：
```
日期,類別,說明,金額
```

### 2. 實作以下五個函數

**`add_record(date, category, description, amount)`**
- 將一筆消費記錄新增到 `records.csv`
- 若檔案不存在，自動建立並加上標題列

**`view_records()`**
- 讀取並印出所有記錄，格式整齊對齊

**`monthly_summary(year_month)`**
- 接受格式如 `"2026-10"` 的字串
- 印出該月各類別的總支出
- 使用 pandas 做分組計算（`groupby`）

**`plot_expenses(year_month)`**
- 用 matplotlib 畫出該月各類別支出的**長條圖**
- 圖表要有標題、X 軸標籤、Y 軸標籤

**`main_menu()`**
- 提供互動式主選單，持續循環直到使用者輸入 `5`（離開）：
  ```
  === 個人記帳系統 ===
  1. 新增記錄
  2. 查看所有記錄
  3. 月份摘要
  4. 產生圖表
  5. 離開
  請選擇：
  ```

### 3. 支援的消費類別
餐飲、交通、娛樂、購物、醫療、其他

## 提示

- 用 `csv.DictReader` / `csv.DictWriter` 讓欄位名稱更直觀
- `datetime.today().strftime('%Y-%m-%d')` 可自動填入今天日期
- pandas 讀取 CSV：`df = pd.read_csv('records.csv')`
- 篩選月份：`df[df['日期'].str.startswith('2026-10')]`
- matplotlib 長條圖：`plt.bar(categories, amounts)`
- 用 `try/except` 處理使用者輸入錯誤的金額（例如輸入文字）
- 把每個功能拆成獨立函數，`main_menu()` 只負責呼叫它們
