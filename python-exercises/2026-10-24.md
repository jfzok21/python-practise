# 第 16 週今日 Python 練習題：個人習慣追蹤器

## 題目說明

打造一個**命令列習慣追蹤系統（Habit Tracker）**，幫助你記錄每日完成的習慣，並分析執行率與連續天數（streak）。這個專案整合 CSV 檔案讀寫、pandas 資料分析、matplotlib 視覺化，以及日期處理技巧。

  - `csv`（Python 內建）

## 具體任務

### 1. 建立資料儲存結構
建立 `habits.csv`，欄位設計如下：
```
日期,習慣名稱,完成
```
其中「完成」欄位填入 `1`（完成）或 `0`（未完成）。

---

### 2. 實作以下六個函數

**`add_habit_log(date, habit_name, done)`**
- 將一筆習慣紀錄寫入 `habits.csv`
- 若檔案不存在，自動建立標題列
- `done` 為 `True` 或 `False`，轉換成 `1` / `0` 再存入

**`view_today(date)`**
- 印出指定日期所有習慣的完成狀況，格式如下：
  ```
  === 2026-10-24 習慣狀況 ===
  ✅ 早起運動
  ✅ 閱讀 30 分鐘
  ❌ 喝 8 杯水
  ```

**`completion_rate(habit_name)`**
- 計算指定習慣的整體完成率（%）
- 使用 pandas 讀取 CSV 並過濾欄位

**`streak(habit_name)`**
- 計算指定習慣目前的**連續完成天數**（從最新日期往回算，連續為 1 才計入）
- 若昨天未完成則 streak 為 0

**`plot_weekly(habit_name)`**
- 用 matplotlib 畫出過去 7 天的長條圖（X 軸：日期，Y 軸：0 或 1）
- 長條顏色：完成為綠色，未完成為紅色
- 圖表要有標題與軸標籤

**`main_menu()`**
- 提供互動式主選單，持續循環直到輸入 `6`：
  ```
  === 習慣追蹤器 ===
  1. 記錄今日習慣
  2. 查看今日狀況
  3. 查看完成率
  4. 查看連續天數
  5. 產生週報圖表
  6. 離開
  請選擇：
  ```

## 提示

- 讀取 CSV：`df = pd.read_csv('habits.csv')`
- 過濾特定習慣：`df[df['習慣名稱'] == habit_name]`
- 計算完成率：`df['完成'].mean() * 100`
- 日期排序：`df.sort_values('日期', ascending=False)`
- streak 計算：將「完成」欄轉成 list，從最新往前遍歷，遇到 0 就停
- matplotlib 長條顏色：`colors = ['green' if x == 1 else 'red' for x in values]`，再傳入 `plt.bar(x, y, color=colors)`
- 用 `datetime.today().strftime('%Y-%m-%d')` 取得今天日期
