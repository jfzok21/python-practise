# 第 16 週今日 Python 練習題：個人書單管理系統（SQLite 版）

## 題目說明

打造一個**命令列書單管理 CLI 工具**，以 SQLite 作為持久化儲存後端。相比前幾天用 CSV 儲存資料，SQLite 支援 SQL 查詢、索引、關聯表，是進入後端開發與資料工程的重要基礎。

這個專案將整合：`sqlite3`（內建）、`argparse`、`pandas`、`matplotlib`，模擬真實的小型應用程式開發流程。

- 概念：SQLite 資料庫、SQL 語法（DDL / DML）、CLI 參數解析、資料分析
- 需要的模組：`sqlite3`（內建）、`argparse`（內建）、`pandas`、`matplotlib`

## 具體任務

### 1. 建立資料庫與資料表

用 `sqlite3` 建立 `books.db`，包含一張 `books` 資料表：

| 欄位 | 型別 | 說明 |
|------|------|------|
| id | INTEGER PRIMARY KEY AUTOINCREMENT | 自動流水號 |
| title | TEXT NOT NULL | 書名 |
| author | TEXT NOT NULL | 作者 |
| genre | TEXT | 類型（e.g. 小說、技術、傳記）|
| status | TEXT | 閱讀狀態（想讀 / 閱讀中 / 已讀）|
| rating | INTEGER | 評分（1–5，可為 NULL）|
| added_date | TEXT | 加入日期（YYYY-MM-DD）|

### 2. 實作 CLI 子指令

使用 `argparse` 的 `subparsers` 實作以下子指令：

```bash
python book_manager.py add    --title "流浪地球" --author "劉慈欣" --genre 科幻 --status 已讀 --rating 5
python book_manager.py list   [--status 已讀] [--genre 科幻]
python book_manager.py update --id 3 --status 已讀 --rating 4
python book_manager.py delete --id 3
python book_manager.py stats
python book_manager.py export --output my_books.csv
```

### 3. 實作 `stats` 子指令

用 `pandas` 讀取整張表，輸出：
- 各閱讀狀態的書籍數量
- 各類型的平均評分（降冪排列）
- 評分最高的前 3 本書

### 4. 產生視覺化圖表

`stats` 指令執行時，同時用 `matplotlib` 產生並儲存 `book_stats.png`，包含兩個子圖：
1. 各閱讀狀態的圓餅圖（pie chart）
2. 各類型平均評分的橫向長條圖（barh chart）

### 5. 匯出功能

`export` 子指令將整張表匯出為 CSV（用 `pandas.to_csv()`）。

## 提示

- **連線管理**：使用 `with sqlite3.connect('books.db') as conn:` 確保自動 commit/rollback
- **防止 SQL Injection**：永遠使用參數化查詢 `cursor.execute("... WHERE id = ?", (id,))`，不要用 f-string 拼接 SQL
- **讀入 pandas**：`pd.read_sql_query("SELECT * FROM books", conn)`
- **`argparse` subparsers**：
  ```python
  parser = argparse.ArgumentParser()
  subparsers = parser.add_subparsers(dest='command')
  add_parser = subparsers.add_parser('add')
  add_parser.add_argument('--title', required=True)
  ```
- 在 `list` 子指令中，用 `str.ljust()` 或 `tabulate`（可選安裝）讓輸出對齊

## 學習重點

### 與爬蟲／ML 的關聯

| 技術 | 應用場景 |
|------|---------|
| SQLite | 爬蟲資料落地（比 CSV 更好查詢）、ML 特徵儲存 |
| SQL SELECT + WHERE | 取代 pandas 的 `.loc[]` 過濾，效能更佳 |
| argparse subparsers | 構建 MLOps CLI 工具（train / predict / evaluate）|
| pandas + SQL | `pd.read_sql_query` 是資料科學家最常用的入口 |
