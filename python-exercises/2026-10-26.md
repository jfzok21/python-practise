# 第 16 週今日 Python 練習題：天氣預報 CLI 工具

## 題目說明

打造一個**命令列天氣查詢工具**，從免費的 [Open-Meteo](https://open-meteo.com/) API（無需 API Key）取得天氣預報資料，將每次查詢結果存入 SQLite 資料庫，並支援歷史趨勢視覺化。

這個專案整合了你過去 16 週的核心技能：`requests` 呼叫 HTTP API、JSON 解析、`sqlite3` 持久化、`pandas` 分析、`matplotlib` 視覺化、`argparse` CLI 設計。

- 概念：REST API 呼叫、JSON 解析、SQLite 儲存、時序資料分析、折線圖
- 需要的模組：`requests`、`sqlite3`（內建）、`pandas`、`matplotlib`、`argparse`（內建）

## 具體任務

### 1. 取得座標並呼叫 Open-Meteo API

Open-Meteo 用**經緯度**查詢天氣，以下是幾個常用城市座標：

| 城市   | 緯度    | 經度     |
|--------|---------|----------|
| 台北   | 25.0330 | 121.5654 |
| 台中   | 24.1477 | 120.6736 |
| 高雄   | 22.6273 | 120.3014 |
| 東京   | 35.6762 | 139.6503 |
| 首爾   | 37.5665 | 126.9780 |

API 端點範例（取未來 7 天每小時溫度）：

```
https://api.open-meteo.com/v1/forecast
  ?latitude=25.0330
  &longitude=121.5654
  &hourly=temperature_2m,precipitation,weathercode
  &timezone=Asia%2FTaipei
  &forecast_days=7
```

回傳 JSON 結構：
```json
{
  "hourly": {
    "time": ["2026-10-26T00:00", ...],
    "temperature_2m": [22.1, 21.8, ...],
    "precipitation": [0.0, 0.1, ...],
    "weathercode": [0, 1, ...]
  }
}
```

### 2. 建立 SQLite 資料庫

建立 `weather.db`，包含兩張表：

**`queries` 表**（每次查詢記錄）：

| 欄位 | 型別 | 說明 |
|------|------|------|
| id | INTEGER PRIMARY KEY AUTOINCREMENT | |
| city | TEXT | 城市名稱 |
| latitude | REAL | 緯度 |
| longitude | REAL | 經度 |
| queried_at | TEXT | 查詢時間（ISO 格式）|

**`forecasts` 表**（逐小時預報）：

| 欄位 | 型別 | 說明 |
|------|------|------|
| id | INTEGER PRIMARY KEY AUTOINCREMENT | |
| query_id | INTEGER | 外鍵 → queries.id |
| forecast_time | TEXT | 預報時間 |
| temperature | REAL | 溫度（°C）|
| precipitation | REAL | 降水量（mm）|
| weathercode | INTEGER | 天氣代碼 |

### 3. 實作 CLI 子指令

```bash
# 查詢並儲存天氣預報
python weather.py fetch --city 台北

# 顯示最近一次查詢的今日逐小時預報
python weather.py today --city 台北

# 顯示過去所有查詢記錄
python weather.py history

# 畫出某城市的溫度趨勢圖
python weather.py plot --city 台北
```

### 4. 天氣代碼轉文字

Open-Meteo 的 `weathercode` 對應說明（部分）：

| 代碼 | 說明 |
|------|------|
| 0 | 晴天 ☀️ |
| 1, 2, 3 | 多雲 🌤️ |
| 45, 48 | 霧 🌫️ |
| 61, 63, 65 | 雨 🌧️ |
| 80, 81, 82 | 陣雨 🌦️ |
| 95 | 雷雨 ⛈️ |

實作 `decode_weather(code: int) -> str` 函數。

### 5. 視覺化（`plot` 子指令）

從 SQLite 讀取該城市最近一次查詢的 7 天預報，用 `matplotlib` 產生 `weather_<城市>.png`，包含兩個子圖：
1. **溫度折線圖**：X 軸為時間，Y 軸為溫度（°C），標題顯示城市名稱
2. **降水量長條圖**：X 軸為時間，Y 軸為降水量（mm），以藍色長條顯示

## 提示

- **Open-Meteo 回傳的時間**是 ISO 格式字串（`"2026-10-26T00:00"`），可用 `pd.to_datetime()` 解析
- **requests 錯誤處理**：
  ```python
  resp = requests.get(url, params=params, timeout=10)
  resp.raise_for_status()  # HTTP 4xx/5xx 會拋出例外
  data = resp.json()
  ```
- **外鍵關聯**：啟用 SQLite 外鍵支援需先執行 `conn.execute("PRAGMA foreign_keys = ON")`
- **`pd.read_sql_query` 搭配參數**：
  ```python
  df = pd.read_sql_query(
      "SELECT * FROM forecasts WHERE query_id = ?",
      conn, params=(query_id,)
  )
  ```
- **matplotlib 中文顯示**：若字體出錯，可用英文城市名稱或加 `matplotlib.rcParams['font.family'] = 'DejaVu Sans'`
