## 具體任務

### 1. 呼叫 Wikipedia API 取得文章純文字

Wikipedia 提供免費的 MediaWiki REST API，以下端點可取得文章的純文字摘要：

```
https://en.wikipedia.org/api/rest_v1/page/summary/{標題}
```

回傳 JSON 結構（重要欄位）：

```json
{
  "title": "Python (programming language)",
  "extract": "Python is a high-level, general-purpose programming language...",
  "pageid": 23862,
  "timestamp": "2026-10-20T08:30:00Z"
}
```

若需完整正文（非摘要），可使用：

```
https://en.wikipedia.org/w/api.php
  ?action=query
  &titles={標題}
  &prop=extracts
  &explaintext=true
  &format=json
```

### 2. 文字清理與分詞

從 API 取得的文字包含標點符號、數字、常見停用詞，需清理後才能進行有意義的詞頻分析：

```python
import re
from collections import Counter

STOPWORDS = {
    'the', 'a', 'an', 'and', 'or', 'but', 'in', 'on', 'at', 'to',
    'for', 'of', 'with', 'by', 'from', 'is', 'are', 'was', 'were',
    'it', 'its', 'that', 'this', 'as', 'be', 'been', 'have', 'has',
    'he', 'she', 'they', 'we', 'you', 'i', 'not', 'also', 'which',
    'such', 'can', 'may', 'more', 'than', 'other', 'used', 'use',
    'most', 'some', 'been', 'one', 'two', 'three', 'new', 'first'
}

def tokenize(text: str) -> list[str]:
    # 小寫、只保留英文字母、過濾停用詞和長度 < 4 的詞
    words = re.findall(r'[a-z]{4,}', text.lower())
    return [w for w in words if w not in STOPWORDS]
```

## 範例

```python
# analyze 實作骨架
import requests
import re
from collections import Counter
import pandas as pd
import matplotlib.pyplot as plt
import argparse

def fetch_summary(topic: str) -> str:
    url = f"https://en.wikipedia.org/api/rest_v1/page/summary/{topic.replace(' ', '_')}"
    resp = requests.get(url, timeout=10, headers={"User-Agent": "WikiAnalyzer/1.0"})
    resp.raise_for_status()
    return resp.json().get("extract", "")

def top_keywords(text: str, n: int = 20) -> list[tuple[str, int]]:
    tokens = tokenize(text)
    return Counter(tokens).most_common(n)

def cmd_analyze(args):
    text = fetch_summary(args.topic)
    keywords = top_keywords(text, args.top)
    total = sum(c for _, c in Counter(tokenize(text)).items())

    print(f"\n🔍 分析：{args.topic}（摘要共 {total} 字）")
    df = pd.DataFrame(keywords, columns=["關鍵詞", "次數"])
    df.index += 1
    df["佔比"] = (df["次數"] / total * 100).map("{:.2f}%".format)
    print(df.to_string())

    if args.export:
        df.to_csv(args.export, index=True, encoding="utf-8-sig")
        print(f"\n✅ 已匯出：{args.export}")
```

## 提示

- **Wikipedia 題目格式**：空格換底線，例如 `Machine_learning`；API 會自動處理大小寫
- **requests 錯誤處理**（404 代表文章不存在）：
  ```python
  try:
      resp.raise_for_status()
  except requests.HTTPError as e:
      print(f"❌ 找不到文章：{e}")
      return ""
  ```
- **中文維基百科**：換用 `zh.wikipedia.org`，分詞需用 `jieba`（`pip install jieba`）
- **`pd.DataFrame` 直接建構**：
  ```python
  df = pd.DataFrame(keywords, columns=["關鍵詞", "次數"])
  ```
- **水平長條圖**：`ax.barh(y, width)` — y 為關鍵詞列表，width 為次數；記得 `ax.invert_yaxis()` 讓最高頻在最上方

## 學習重點

### 與爬蟲／ML 的關聯

| 技術 | 應用場景 |
|------|---------|
| `requests` + Wikipedia API | 大量語料蒐集（NLP 訓練資料前處理）|
| `re.findall` 分詞 | 文字特徵提取的第一步（TF-IDF 前置處理）|
| `Counter.most_common` | 樸素貝葉斯分類器中詞彙重要性評估的基礎 |
| `pandas` 多欄合併 | ML 特徵矩陣建構（每篇文章 = 一列，每個詞 = 一欄）|
| 水平長條圖 | 特徵重要性圖（Feature Importance Plot）的標準形式 |
| `compare` 共同詞 | TF-IDF 的直觀版本：跨文件詞頻比較 |

## 進階挑戰（選做）

1. **TF-IDF 排名**：實作 `tfidf(word, doc, corpus)` 函數，讓詞頻排名更能凸顯每篇文章的獨特詞彙
2. **詞雲資料**：產生 `words.txt`，每行 `詞語 次數`，可貼入 [wordart.com](https://wordart.com) 生成詞雲圖
3. **多語言支援**：自動偵測 `--lang zh` 參數，切換至中文維基百科並用 `jieba` 分詞
4. **相似度比較**：用 Jaccard 相似度計算兩篇文章關鍵詞集合的重疊程度：
   ```python
   def jaccard(set_a: set, set_b: set) -> float:
       return len(set_a & set_b) / len(set_a | set_b)
   ```
5. **批次分析**：從 CSV 讀取多個 Wikipedia 題目，批次分析後合併輸出一份總表
