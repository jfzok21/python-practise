## 具體任務

### 1. 取得市值前 N 名的加密貨幣清單

CoinGecko 提供免費的市場資料 API（無需 Key，每分鐘約 10~30 次請求）：

```
https://api.coingecko.com/api/v3/coins/markets
  ?vs_currency=usd
  &order=market_cap_desc
  &per_page=20
  &page=1
  &sparkline=false
  &price_change_percentage=1h,24h,7d
```

回傳 JSON 陣列，每個元素代表一枚幣，重要欄位：

```json
{
  "id": "bitcoin",
  "symbol": "btc",
  "name": "Bitcoin",
  "current_price": 67234.5,
  "market_cap": 1327000000000,
  "total_volume": 28400000000,
  "price_change_percentage_24h": 2.34,
  "price_change_percentage_7d_in_currency": -1.82,
  "market_cap_rank": 1,
  "high_24h": 68100.0,
  "low_24h": 65800.0
}
```

### 2. 取得特定幣的 7 天歷史價格

```
https://api.coingecko.com/api/v3/coins/{coin_id}/market_chart
  ?vs_currency=usd
  &days=7
  &interval=daily
```

回傳：

```json
{
  "prices": [[1729123200000, 67234.5], [1729209600000, 66800.1], ...],
  "market_caps": [[...], ...],
  "total_volumes": [[...], ...]
}
```

`prices` 的第一欄為 Unix 毫秒時間戳，第二欄為價格。

## 範例

```python
import requests
import pandas as pd
import matplotlib.pyplot as plt
import argparse
from datetime import datetime

BASE_URL = "https://api.coingecko.com/api/v3"
HEADERS = {"Accept": "application/json"}

def fetch_markets(top: int = 20) -> pd.DataFrame:
    """取得市值前 N 名的市場資料"""
    params = {
        "vs_currency": "usd",
        "order": "market_cap_desc",
        "per_page": min(top, 250),
        "page": 1,
        "sparkline": False,
        "price_change_percentage": "24h,7d",
    }
    resp = requests.get(f"{BASE_URL}/coins/markets", params=params,
                        headers=HEADERS, timeout=15)
    resp.raise_for_status()
    data = resp.json()

    df = pd.DataFrame([{
        "rank":      c["market_cap_rank"],
        "symbol":    c["symbol"].upper(),
        "name":      c["name"],
        "price":     c["current_price"],
        "market_cap_b": c["market_cap"] / 1e9,
        "volume_b":  c["total_volume"] / 1e9,
        "pct_24h":   c.get("price_change_percentage_24h") or 0,
        "pct_7d":    c.get("price_change_percentage_7d_in_currency") or 0,
        "high_24h":  c["high_24h"],
        "low_24h":   c["low_24h"],
    } for c in data])
    return df

def fetch_trend(coin_id: str, days: int = 7) -> pd.DataFrame:
    """取得某枚幣的歷史價格"""
    params = {"vs_currency": "usd", "days": days, "interval": "daily"}
    resp = requests.get(f"{BASE_URL}/coins/{coin_id}/market_chart",
                        params=params, headers=HEADERS, timeout=15)
    resp.raise_for_status()
    prices = resp.json()["prices"]
    df = pd.DataFrame(prices, columns=["timestamp_ms", "price"])
    df["date"] = pd.to_datetime(df["timestamp_ms"], unit="ms")
    return df[["date", "price"]]

def cmd_list(args):
    df = fetch_markets(args.top)
    now = datetime.utcnow().strftime("%Y-%m-%d %H:%M UTC")
    print(f"\n💰 加密貨幣市場快照（{now}）\n")

    fmt_df = df.copy()
    fmt_df["price_fmt"]  = fmt_df["price"].map("${:,.2f}".format)
    fmt_df["mcap_fmt"]   = fmt_df["market_cap_b"].map("{:.1f}B".format)
    fmt_df["pct_24h_fmt"]= fmt_df["pct_24h"].map("{:+.2f}%".format)
    fmt_df["pct_7d_fmt"] = fmt_df["pct_7d"].map("{:+.2f}%".format)

    print(fmt_df[["rank","symbol","name","price_fmt","mcap_fmt","pct_24h_fmt","pct_7d_fmt"]]
          .to_string(index=False))

    up   = (df["pct_24h"] > 0).sum()
    down = (df["pct_24h"] <= 0).sum()
    print(f"\n📊 市場整體統計")
    print(f"  上漲幣數：{up} 枚（{up/len(df)*100:.1f}%）")
    print(f"  下跌幣數：{down} 枚（{down/len(df)*100:.1f}%）")
    print(f"  24h 平均漲幅：{df['pct_24h'].mean():+.2f}%")
    best7 = df.loc[df["pct_7d"].idxmax()]
    worst7 = df.loc[df["pct_7d"].idxmin()]
    print(f"  7d 最強幣：{best7['symbol']}（{best7['pct_7d']:+.2f}%）")
    print(f"  7d 最弱幣：{worst7['symbol']}（{worst7['pct_7d']:+.2f}%）")
    total_mcap = df["market_cap_b"].sum() / 1000
    print(f"  總市值：${total_mcap:.2f} 兆 USD")

    if args.export:
        df.to_csv(args.export, index=False, encoding="utf-8-sig")
        print(f"\n✅ 已匯出：{args.export}")
```

## 提示

- **CoinGecko 免費 API 速率限制**：每分鐘 10~30 次；若收到 429（Too Many Requests），等 60 秒再重試
- **`price_change_percentage_7d_in_currency` 有時為 `None`**（新上架幣），記得用 `or 0` 處理：
  ```python
  c.get("price_change_percentage_7d_in_currency") or 0
  ```
- **Unix 毫秒時間戳轉日期**：
  ```python
  df["date"] = pd.to_datetime(df["timestamp_ms"], unit="ms")
  ```
- **左右並列子圖**：
  ```python
  fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 6))
  plt.tight_layout()
  ```
- **動態顏色（漲跌）**：
  ```python
  colors = ["#26a69a" if v >= 0 else "#ef5350" for v in df["pct_24h"]]
  ax.barh(df["name"], df["pct_24h"], color=colors)
  ```
- **數字格式化（大數字）**：用 `f"${v/1e12:.2f}T"` 顯示兆，`f"${v/1e9:.1f}B"` 顯示億

## 學習重點

### 與爬蟲／ML 的關聯

| 技術 | 應用場景 |
|------|---------|
| CoinGecko REST API | 金融資料蒐集的範本（Yahoo Finance、Alpha Vantage 同理）|
| Unix 毫秒時間戳轉換 | ML 時序特徵工程（lag/rolling 特徵）的必要前置步驟 |
| `or 0` 缺失值預設 | 資料清理中「業務邏輯補值」vs `fillna` 的抉擇策略 |
| 漲跌動態配色 | 儀表板設計：語義配色（紅跌綠漲）讓圖表更直覺 |
| `price_change_percentage` 多欄 | 多週期特徵矩陣（1h / 24h / 7d）是短線預測模型的輸入 |
| `idxmax` / `idxmin` | 找最佳／最差排名，等同 `np.argmax`，常用於模型排行評估 |
