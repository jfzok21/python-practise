### 1. 下載歷史股價資料

使用 `yfinance` 取得任意股票的歷史資料（預設取最近 6 個月）：

```python

ticker = yf.Ticker("AAPL")

# df 包含欄位：Open, High, Low, Close, Volume, Dividends, Stock Splits
```

### 2. 計算以下 4 個技術指標

#### a. 簡單移動平均線（SMA）
```
SMA_N = Close 的 N 日滾動平均
```
計算 `SMA_20` 和 `SMA_50`。

#### b. 指數移動平均線（EMA）
```
EMA_N = Close.ewm(span=N, adjust=False).mean()
```
計算 `EMA_12` 和 `EMA_26`，並衍生出 MACD：
```
MACD_line  = EMA_12 - EMA_26
Signal     = MACD_line.ewm(span=9, adjust=False).mean()
Histogram  = MACD_line - Signal
```

#### c. 相對強弱指數（RSI）
```
delta  = Close.diff()
gain   = delta.clip(lower=0)
loss   = (-delta).clip(lower=0)
avg_gain = gain.ewm(com=13, adjust=False).mean()   # com=N-1=13 for period=14
avg_loss = loss.ewm(com=13, adjust=False).mean()
RS  = avg_gain / avg_loss
RSI = 100 - (100 / (1 + RS))
```
RSI 超過 70 視為**超買**，低於 30 視為**超賣**。

#### d. 布林通道（Bollinger Bands）
```
Middle Band = SMA_20
Upper Band  = SMA_20 + 2 × 20日標準差
Lower Band  = SMA_20 - 2 × 20日標準差
%B          = (Close - Lower Band) / (Upper Band - Lower Band)
```

## 範例

```python
import yfinance as yf
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import matplotlib.gridspec as gridspec
import argparse

def fetch_data(ticker: str, period: str = "6mo") -> pd.DataFrame:
    df = yf.Ticker(ticker).history(period=period)
    df.index = pd.to_datetime(df.index.date)   # 去掉時區，保留日期
    return df

def add_indicators(df: pd.DataFrame) -> pd.DataFrame:
    # SMA
    df["SMA20"] = df["Close"].rolling(20).mean()
    df["SMA50"] = df["Close"].rolling(50).mean()
    # EMA & MACD
    df["EMA12"] = df["Close"].ewm(span=12, adjust=False).mean()
    df["EMA26"] = df["Close"].ewm(span=26, adjust=False).mean()
    df["MACD"]  = df["EMA12"] - df["EMA26"]
    df["Signal"]= df["MACD"].ewm(span=9, adjust=False).mean()
    df["Hist"]  = df["MACD"] - df["Signal"]
    # RSI
    delta = df["Close"].diff()
    gain  = delta.clip(lower=0)
    loss  = (-delta).clip(lower=0)
    df["RSI"] = 100 - 100 / (
        1 + gain.ewm(com=13, adjust=False).mean() /
            loss.ewm(com=13, adjust=False).mean()
    )
    # Bollinger Bands
    std20 = df["Close"].rolling(20).std()
    df["BB_Upper"]  = df["SMA20"] + 2 * std20
    df["BB_Lower"]  = df["SMA20"] - 2 * std20
    df["BB_PctB"]   = (df["Close"] - df["BB_Lower"]) / (df["BB_Upper"] - df["BB_Lower"])
    return df

def print_summary(df: pd.DataFrame, ticker: str) -> None:
    last = df.iloc[-1]
    start_price = df["Close"].iloc[0]
    returns = (last["Close"] - start_price) / start_price * 100
    daily_returns = df["Close"].pct_change().dropna()
    volatility = daily_returns.std() * np.sqrt(252) * 100

    print(f"\n📈 {ticker} 技術分析摘要（{df.index[0]} ~ {df.index[-1]}）\n")
    print("價格概覽")
    print(f"  現價：${last['Close']:.2f}    期間最高：${df['High'].max():.2f}    期間最低：${df['Low'].min():.2f}")
    print(f"  期間報酬：{returns:+.1f}%    年化波動率：{volatility:.1f}%")

    print("\n技術指標（截至最新一日）")
    print(f"  SMA20：${last['SMA20']:.2f}   SMA50：${last['SMA50']:.2f}")
    print(f"  MACD：{last['MACD']:+.2f}   Signal：{last['Signal']:+.2f}   Histogram：{last['Hist']:+.2f}")
    rsi_label = "超買" if last['RSI'] > 70 else "超賣" if last['RSI'] < 30 else "中性"
    print(f"  RSI(14)：{last['RSI']:.1f}（{rsi_label}）")
    print(f"  布林通道：Upper ${last['BB_Upper']:.2f} / Middle ${last['SMA20']:.2f} / Lower ${last['BB_Lower']:.2f}")
    print(f"  %B：{last['BB_PctB']:.2f}")
```

## 提示

- **yfinance 資料缺口**：部分小型股或 ETF 可能有交易日缺口，使用 `.dropna(subset=['Close'])` 清理
- **SMA50 需要至少 50 日資料**：若選 `--period 1mo`，SMA50 會全為 NaN，繪圖時加 `dropna()` 或改用 `--period 3mo`
- **gridspec 控制子圖高度比例**：
  ```python
  gs = gridspec.GridSpec(4, 1, height_ratios=[4, 1.5, 2, 1.5], hspace=0.05)
  ax1 = fig.add_subplot(gs[0])
  ax2 = fig.add_subplot(gs[1], sharex=ax1)
  ```
- **填滿布林通道區域**：
  ```python
  ax.fill_between(df.index, df["BB_Upper"], df["BB_Lower"],
                  alpha=0.1, color="gray", label="布林通道")
  ```
- **RSI 超買超賣填色**：
  ```python
  ax.fill_between(df.index, 70, 100, alpha=0.1, color="red")
  ax.fill_between(df.index, 0, 30,  alpha=0.1, color="green")
  ```
- **X 軸日期格式**：
  ```python
  import matplotlib.dates as mdates
  ax.xaxis.set_major_formatter(mdates.DateFormatter("%m/%d"))
  plt.setp(ax.xaxis.get_majorticklabels(), rotation=45)
  ```

## 學習重點

### 與爬蟲／ML 的關聯

| 技術 | 應用場景 |
|------|---------|
| `rolling().mean()` | ML 特徵工程中的滑動視窗特徵（lag feature） |
| `ewm(span=N)` | 時序模型中的指數平滑（與 LSTM 隱藏狀態更新同理） |
| RSI 超買超賣訊號 | 分類標籤生成：可作為監督式學習的 Y 變數 |
| 布林通道 %B | 標準化特徵（0~1 範圍），直接可輸入 ML 模型 |
| `yf.Ticker.history()` | 批量抓取多股票資料與爬蟲邏輯相同（節流、重試、快取） |
| `gridspec` 多面板 | 探索性資料分析（EDA）的標準視覺化排版 |
