# 第 17 週今日 Python 練習題：新聞關鍵字趨勢分析儀

## 題目說明

結合爬蟲、資料清理、Pandas 分析與視覺化，打造一個能自動抓取新聞標題、統計關鍵字出現頻率，並輸出趨勢圖表的完整分析工具。這是一個整合前 16 週所有核心技能的實戰專案。

## 技術要求
- 概念：HTTP 請求、HTML 解析、字串處理、資料結構、Pandas、Matplotlib、CSV 儲存
- 需要的模組：`requests`、`beautifulsoup4`、`pandas`、`matplotlib`、`collections`

## 具體任務

1. **資料爬取**  
   使用 `requests` + `BeautifulSoup` 抓取 [https://news.ycombinator.com](https://news.ycombinator.com)（Hacker News）首頁所有文章標題（至少 30 筆）。

2. **關鍵字清理**  
   - 將所有標題轉成小寫，移除標點符號  
   - 過濾掉常見停用詞（stop words），例如：`the`, `a`, `an`, `to`, `of`, `in`, `and`, `for`, `is`, `on`, `with`, `how`, `why`, `what`  
   - 統計每個詞的出現次數，取前 20 名

3. **資料儲存**  
   將結果（詞彙、出現次數）存入 `keyword_report.csv`，欄位為：`keyword`、`count`

4. **Pandas 分析**  
   - 讀取剛剛存的 CSV  
   - 計算平均出現次數、最高頻關鍵字  
   - 篩選出出現次數 ≥ 2 的關鍵字

5. **視覺化輸出**  
   使用 `matplotlib` 畫出前 10 名關鍵字的橫向長條圖（barh），儲存為 `keyword_chart.png`

## 範例

```python
# 執行後終端機輸出類似：

Top 20 關鍵字：
python        5
ai            4
open          3
...

平均出現次數：1.8
最高頻關鍵字：python (5 次)

✅ 已儲存 keyword_report.csv
✅ 已儲存 keyword_chart.png
```

## 提示

- 抓取標題元素：Hacker News 的標題在 `<span class="titleline">` 內的 `<a>` 標籤
- 移除標點可用 `str.translate(str.maketrans('', '', string.punctuation))`
- `collections.Counter` 是統計詞頻的最佳工具
- `df.sort_values('count', ascending=False)` 可排序 DataFrame
- `plt.barh()` 畫橫向長條圖，記得加 `plt.tight_layout()` 避免標籤被截斷

## 學習重點

這個專案是爬蟲 → 資料清理 → Pandas → 視覺化的完整流程，也是 ML 前處理的基礎——文字分析（NLP）的第一步就是詞頻統計（Bag of Words）。掌握這個流程後，只需替換資料來源，就能分析股市新聞、社群貼文或任何文字資料。
