# 第 18 週今日 Python 練習題：新聞資料爬蟲與關鍵字分析儀表板

## 題目說明

建立一個完整的實戰專案：從網路上爬取新聞標題，進行基本的文字分析，並將結果儲存為 CSV 與簡易報表。這個專案整合了前幾週學到的爬蟲、資料處理、Pandas 與視覺化技能。

## 技術要求
- 概念：HTTP 請求、HTML 解析、文字統計分析、資料視覺化、CSV 輸出
- 需要的模組：`requests`、`bs4`（BeautifulSoup）、`pandas`、`matplotlib`、`collections`

## 具體任務

1. **爬取新聞標題**
   - 從 `https://news.ycombinator.com`（Hacker News）爬取首頁所有文章標題
   - 取出每篇文章的：標題、分數（points）、留言數

2. **儲存為 CSV**
   - 將爬取結果存入 `hacker_news_YYYY-MM-DD.csv`
   - 欄位：`title`、`score`、`comments`

3. **關鍵字統計**
   - 將所有標題合併，以空格拆分成單字列表
   - 使用 `collections.Counter` 計算出現次數最多的前 20 個單字
   - 過濾掉常見停用詞（the, a, an, in, of, to, for, is, on, and, with, how, why, what）

4. **用 Pandas 分析**
   - 計算平均分數、最高分文章、留言最多的文章
   - 找出分數前 5 名的標題

5. **視覺化（選做基礎版）**
   - 用 `matplotlib` 畫長條圖，呈現前 10 個高頻關鍵字

## 範例

```python
# 預期輸出（部分）
import requests
from bs4 import BeautifulSoup
import pandas as pd
from collections import Counter

URL = "https://news.ycombinator.com"
response = requests.get(URL)
soup = BeautifulSoup(response.text, "html.parser")

# 取標題
titles = soup.select(".titleline > a")
for t in titles[:3]:
    print(t.text)

# 預期輸出（內容每天不同）：
# Show HN: I built a Python linter in Rust
# Ask HN: What tools do you use for personal finance?
# New approach to LLM context management
```

```python
# Counter 範例
from collections import Counter

words = "python rust llm tools python tools python".split()
stop_words = {"the", "a", "in", "of", "to"}
filtered = [w.lower() for w in words if w.lower() not in stop_words]
counter = Counter(filtered)
print(counter.most_common(3))
# [('python', 3), ('tools', 2), ('rust', 1)]
```

## 提示
- `soup.select(".titleline > a")` 可以選取 Hacker News 的標題連結
- `.select(".score")` 可取得分數，記得用 `.text` 取得文字後再轉 `int`
- 有些文章可能沒有分數，記得加 `try/except` 或 `if` 判斷
- 用 `zip()` 可以同時迭代多個列表
- `pd.DataFrame(rows)` 可以把列表的字典轉成 DataFrame
