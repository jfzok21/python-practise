# 第 18 週今日 Python 練習題：個人習慣追蹤與分析系統

## 題目說明

建立一個**命令列個人習慣追蹤系統**，讓使用者能記錄每日完成的習慣（如「運動」、「閱讀」、「喝水 2000ml」），將資料儲存為 CSV，並以 `pandas` 統計完成率、連續達標天數（streak），最後用 `matplotlib` 繪製視覺化報表。這個專案整合了檔案讀寫、資料結構、pandas、matplotlib 等核心技能。

---

## 技術要求

- **概念**：CSV 讀寫、datetime 操作、pandas 統計、matplotlib 視覺化、命令列互動
- **需要的模組**：`csv`、`datetime`、`pandas`、`matplotlib`（標準庫 + 第三方）

---

## 具體任務

1. **設計資料格式**  
   建立 `habits.csv`，欄位包含：`date`（YYYY-MM-DD）、`habit`（習慣名稱）、`done`（1/0）。

2. **打卡功能**  
   命令列執行 `python habit_tracker.py log` 後，列出預設習慣清單，讓使用者輸入今日是否完成（y/n），並自動寫入 CSV。

3. **統計分析**  
   執行 `python habit_tracker.py stats` 後，以 pandas 讀取 CSV，計算：
   - 每個習慣的**整體完成率**（%）
   - 每個習慣的**當前連續達標天數**（streak）
   - 過去 7 天的**每日完成數量**

4. **視覺化報表**  
   執行 `python habit_tracker.py chart` 後，繪製：
   - 長條圖：各習慣的完成率比較
   - 折線圖：過去 30 天每日完成習慣數量趨勢
   - 儲存圖片為 `habit_report.png`

5. **防重複打卡**  
   若今天已打卡，`log` 功能應提示「今日已打卡」，詢問是否覆寫。

## 提示

- 使用 `datetime.date.today()` 取得今日日期，轉為字串 `str(date.today())`
- 計算 streak 時，從今天往回查，找到第一個 `done == 0` 的日期即停止
- `pandas.pivot_table()` 可方便地將長格式 CSV 轉為習慣 × 日期的交叉表
- 用 `matplotlib.pyplot.subplot()` 在同一張圖中排列多個子圖
- 建議將「習慣清單」存在程式頂部的 `HABITS` 常數列表，方便日後修改

```python
HABITS = [
    "早起 (06:30 前)",
    "運動 30 分鐘",
    "閱讀 20 分鐘",
    "喝水 2000ml",
]
```
