# 第 18 週今日 Python 練習題：PTT 熱門文章爬蟲與資料分析儀表板

## 題目說明

綜合運用前幾週所學的網頁爬蟲、Pandas 資料處理、以及 matplotlib 視覺化技能，建立一個完整的 PTT 熱門文章爬蟲與資料分析小工具。你將從 PTT 八卦板（或其他板）抓取文章清單，分析推文數、作者分布、熱門時段等，最後輸出一份 CSV 報告並繪製圖表。

## 技術要求
- 概念：requests、BeautifulSoup、Pandas、matplotlib、CSV 儲存、資料清洗
- 需要的模組：`requests`、`beautifulsoup4`、`pandas`、`matplotlib`

## 具體任務

1. **爬取文章清單**
   - 目標網址：`https://www.ptt.cc/bbs/Gossiping/index.html`（需加 Cookie `over18=1`）
   - 擷取每篇文章的：標題、作者、推文數、發文日期
   - 爬取最近 **3 頁**的文章

2. **資料清洗**
   - 推文數欄位可能出現 `爆`（代表 100+）、`XX`（負分）、或空白，請統一轉換為整數：
     - `爆` → `100`
     - `X數字`（如 `X1`）→ `-10`（統一視為負）
     - 空白 → `0`
   - 移除標題為 `[公告]` 開頭的系統文章

3. **資料分析（使用 Pandas）**
   - 計算：平均推文數、最高推文數文章、推文數前 5 名
   - 統計每位作者的發文篇數，列出發文最多的前 3 位

4. **視覺化（使用 matplotlib）**
   - 圖一：推文數的長條圖（前 10 篇文章）
   - 圖二：推文數分布直方圖（histogram）
   - 儲存為 `ptt_analysis.png`

5. **輸出 CSV**
   - 將清洗後的完整資料存為 `ptt_gossiping.csv`
   - 欄位：`title`、`author`、`score`、`date`

## 範例

```python
# 預期輸出（終端機）

已儲存：ptt_gossiping.csv
圖表已儲存：ptt_analysis.png
```

## 提示
- PTT 需要在 headers 加入 Cookie：`{'Cookie': 'over18=1'}`
- 推文數欄位的 HTML class 為 `nrec`，作者為 `author`，標題為 `title`
- 使用 `pd.DataFrame(articles)` 建立 DataFrame，再用 `.apply()` 或 `map()` 清洗推文欄位
- `BeautifulSoup` 中用 `find_all('div', class_='r-ent')` 取得每篇文章的區塊
- 翻頁：找到「上頁」按鈕的連結 `a[href]`，拼接 `https://www.ptt.cc` 即可
