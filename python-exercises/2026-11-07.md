# 第 18 週今日 Python 練習題：世界銀行經濟指標爬取與跨國比較分析

## 題目說明

世界銀行（World Bank）提供完全免費、不需要 API Key 的公開數據 API，涵蓋全球 200+ 個國家的 GDP、人均所得、人口、預期壽命等指標。本練習將整合 requests（JSON API）、Pandas（資料分析）、matplotlib（視覺化）等技能，建立一個完整的「跨國經濟指標分析工具」。

## 技術要求
- 概念：requests（JSON API）、Pandas、matplotlib、資料清洗、多圖表布局
- 需要的模組：`requests`、`pandas`、`matplotlib`

## 具體任務

1. **呼叫世界銀行 API 取得數據**
   - API 格式：`https://api.worldbank.org/v2/country/{country_code}/indicator/{indicator}?format=json&per_page=30&date=1994:2023`
   - 分析以下 **3 個指標**，各取得 5 個國家的近 30 年資料：
     - GDP（現值美元）：指標代碼 `NY.GDP.MKTP.CD`
     - 人均 GDP：指標代碼 `NY.GDP.PCAP.CD`
     - 人口數：指標代碼 `SP.POP.TOTL`
   - 國家代碼：台灣 `TW`、日本 `JP`、韓國 `KR`、新加坡 `SG`、美國 `US`

2. **解析與整理 JSON 回應**
   - 世界銀行 API 回傳格式為：`[metadata, [data_list]]`
   - 每筆資料包含 `date`（年份）與 `value`（數值，可能為 `null`）
   - 移除 `value` 為 `null` 的資料列
   - 建立一個以年份為索引、各國為欄位的 DataFrame

3. **資料分析（使用 Pandas）**
   - 計算每個國家 2000–2023 年的 **GDP 成長率**（與 2000 年相比的倍數）
   - 找出各指標在 2023 年排名第一的國家
   - 計算台灣與其他 4 國在人均 GDP 上的差距（百分比）

4. **視覺化（使用 matplotlib）**
   - 圖一：5 個國家 GDP 趨勢折線圖（1994–2023）
   - 圖二：2023 年各國人均 GDP 橫向長條圖（依大小排序）
   - 圖三：5 個國家人口趨勢折線圖（1994–2023）
   - 以 `subplot(1, 3, ...)` 排成一排，儲存為 `worldbank_analysis.png`

5. **輸出報告**
   - 將整合後的資料存為 `worldbank_data.csv`，欄位：`year`、`country`、`gdp`、`gdp_per_capita`、`population`

## 範例

```python
# API 呼叫範例
import requests

def fetch_indicator(country_code, indicator):
    url = (
        f"https://api.worldbank.org/v2/country/{country_code}"
        f"/indicator/{indicator}?format=json&per_page=30&date=1994:2023"
    )
    res = requests.get(url)
    metadata, data = res.json()
    return [(d['date'], d['value']) for d in data if d['value'] is not None]
```

## 提示
- 世界銀行 API 有時回應較慢，建議加上 `timeout=10` 參數：`requests.get(url, timeout=10)`
- 迴圈呼叫 API 時，加上 `time.sleep(0.5)` 避免過於頻繁請求
- 台灣的資料在世界銀行有限，部分年份可能缺漏，要做好空值處理
- `pd.pivot_table(df, values='gdp', index='year', columns='country')` 可快速轉成寬表格
- matplotlib 中文顯示：若遇亂碼，可用 `plt.rcParams['font.sans-serif'] = ['DejaVu Sans']` 並改用英文國名
