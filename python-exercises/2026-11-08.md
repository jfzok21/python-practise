1. **建立資料庫與資料表**
   - 使用 `sqlite3.connect('learning_log.db')` 建立資料庫
   - 建立 `study_sessions` 資料表，欄位如下：
     ```sql
     CREATE TABLE IF NOT EXISTS study_sessions (
         id INTEGER PRIMARY KEY AUTOINCREMENT,
         date TEXT NOT NULL,
         topic TEXT NOT NULL,
         duration_minutes INTEGER NOT NULL,
         notes TEXT,
         created_at TEXT DEFAULT (datetime('now', 'localtime'))
     );
     ```

2. **實作 CRUD 操作（包裝成函數）**
   - `add_session(date, topic, duration, notes)` — 新增一筆記錄（INSERT）
   - `list_sessions(limit=10)` — 列出最近 N 筆記錄（SELECT … ORDER BY … LIMIT）

3. **互動式選單**

4. **統計分析（使用 Pandas）**
   - 用 `pd.read_sql_query(sql, conn)` 將 SQL 查詢結果直接讀入 DataFrame

     - 學習時數最長的前 3 個主題
   - 輸出純文字統計表格（`df.to_string(index=False)`）

## 範例

```python
import sqlite3
import pandas as pd
from datetime import date

DB_PATH = 'learning_log.db'

def get_conn():
    return sqlite3.connect(DB_PATH)

def add_session(session_date, topic, duration, notes=''):
    with get_conn() as conn:
        conn.execute(
            "INSERT INTO study_sessions (date, topic, duration_minutes, notes) VALUES (?, ?, ?, ?)",
            (session_date, topic, duration, notes)
        )
    print(f"✅ 已新增：{topic}（{duration} 分鐘）")

def get_stats():
    with get_conn() as conn:
        df = pd.read_sql_query(
            "SELECT topic, SUM(duration_minutes) as total_min FROM study_sessions GROUP BY topic ORDER BY total_min DESC",
            conn
        )
    df['total_hours'] = (df['total_min'] / 60).round(1)
    print("\n=== 各主題學習時數 ===")
    print(df[['topic', 'total_hours']].to_string(index=False))

# 預期輸出
=== 各主題學習時數 ===
     topic  total_hours
    Pandas          4.5
   Web 爬蟲          3.0
    機器學習          2.5
  Python 基礎          2.0
       SQL          1.5
```

## 提示
- `with sqlite3.connect(DB_PATH) as conn:` 會在 `with` 結束時自動 `commit()`，不需手動呼叫
- `conn.execute(sql, (param1, param2))` 使用 `?` 佔位符可防止 SQL Injection
- `pd.read_sql_query(sql, conn)` 傳入連線物件即可，`conn` 不需要關閉
- 日期建議統一用 `date.today().isoformat()` 格式（`'2026-11-08'`），方便後續 `ORDER BY`
- 刪除前可先 `list_sessions()` 確認 ID，再輸入 ID 刪除，避免誤刪

## 學習重點

SQLite 是 Python 生態中最常見的嵌入式資料庫，直接對應到：
- **爬蟲儲存**（第 8 週）：用資料庫取代 CSV，支援查詢與更新，不怕重複抓取
- **Pandas（第 10 週）**：`pd.read_sql_query` 讓 SQL 與 DataFrame 無縫整合
- **ML 前處理**：訓練資料通常存在資料庫，用 SQL 篩選特定條件的樣本再丟給 sklearn

掌握 sqlite3 後，切換到 PostgreSQL 或 MySQL 只需換 `connect()` 的驅動，邏輯完全相同。
