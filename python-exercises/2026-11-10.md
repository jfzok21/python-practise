## 題目說明

綜合前 18 週學習的技能，打造一個完整的「個人支出分析儀表板」。從模擬的銀行交易記錄出發，完成資料生成 → Pandas 清洗 → 統計分析 → matplotlib 視覺化 → 報告輸出的完整數據管線，並用 sklearn 的分群算法找出消費行為模式。

## 技術要求
- 概念：資料生成、Pandas 資料分析、matplotlib 多圖表繪製、sklearn KMeans 分群、CSV / JSON 報告輸出
- 需要的模組：`pandas`、`matplotlib`、`sklearn`、`csv`、`json`、`random`、`datetime`

## 具體任務

1. **生成模擬交易資料**
   - 建立函數 `generate_transactions(n=200, seed=42)`，使用 `random` 模組產生 `n` 筆交易記錄，存為 `transactions.csv`
   - 每筆記錄包含：
     - `date`：過去 180 天內的隨機日期（格式 `YYYY-MM-DD`）
     - `category`：從 `['餐飲', '交通', '娛樂', '購物', '醫療', '住宿', '學習', '其他']` 中隨機選取
     - `amount`：各類別有不同的金額範圍（餐飲 50–300、交通 20–200、購物 100–3000、其他依此類推）
     - `description`：簡短描述（可用類別名稱加編號，如「餐飲-001」）

2. **Pandas 資料清洗與分析**
   - 讀入 `transactions.csv`，確保 `date` 欄為 `datetime` 型態、`amount` 為 `float`
   - 計算以下統計量並印出：
     - 各類別總支出與百分比
     - 每月總支出趨勢（以 `YYYY-MM` 分組）
     - 單筆消費最高 Top 5
     - 每週平均支出（星期幾最花錢？）

3. **matplotlib 四格視覺化**
   - 建立 `2×2` 的子圖佈局（`fig, axes = plt.subplots(2, 2, figsize=(14, 10))`），繪製：
     - 左上：各類別支出的**圓餅圖**（`pie`），顯示百分比
     - 右上：每月支出趨勢的**折線圖**（`plot`），標示最高與最低月
     - 左下：各類別支出的**橫條圖**（`barh`），按金額排序
     - 右下：每週各天支出分布的**長條圖**（`bar`），X 軸為星期一到日
   - 設定整體標題、各子圖標題、軸標籤，存為 `expense_dashboard.png`

4. **sklearn KMeans 消費行為分群**
   - 將每個類別的「月均支出」和「消費頻次」作為特徵，對 8 個類別進行 K=3 的分群
   - 標示每個群組的特性（如：高頻低消費、低頻高消費、均衡型）
   - 印出分群結果

5. **輸出分析報告**
   - 將以下資訊寫入 `expense_report.json`（`ensure_ascii=False`，`indent=2`）：
     ```json
     {
       "analysis_date": "2026-11-10",
       "total_transactions": 200,
       "total_spent": 12345.67,
       "avg_per_transaction": 61.73,
       "top_category": "購物",
       "highest_month": "2026-09",
       "category_breakdown": {...},
       "spending_clusters": {...}
     }
     ```

## 範例

```python
import pandas as pd
import numpy as np
import matplotlib
matplotlib.use('Agg')  # 無介面環境必須加這行
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
import random
import json
from datetime import date, timedelta

# ── 1. 生成資料 ──────────────────────────────────
def generate_transactions(n=200, seed=42):
    random.seed(seed)
    categories_range = {
        '餐飲': (50, 300),
        '交通': (20, 200),
        '娛樂': (100, 800),
        '購物': (100, 3000),
        '醫療': (200, 1500),
        '住宿': (500, 4000),
        '學習': (100, 2000),
        '其他': (30, 500),
    }
    start = date.today() - timedelta(days=180)
    rows = []
    counters = {c: 0 for c in categories_range}
    for _ in range(n):
        d = start + timedelta(days=random.randint(0, 180))
        cat = random.choice(list(categories_range))
        lo, hi = categories_range[cat]
        amt = round(random.uniform(lo, hi), 0)
        counters[cat] += 1
        rows.append({
            'date': d.isoformat(),
            'category': cat,
            'amount': amt,
            'description': f"{cat}-{counters[cat]:03d}",
        })
    df = pd.DataFrame(rows).sort_values('date').reset_index(drop=True)
    df.to_csv('transactions.csv', index=False, encoding='utf-8-sig')
    print(f"已生成 {len(df)} 筆交易記錄 → transactions.csv")
    return df

# ── 2. 分析 ──────────────────────────────────────
def analyze(df):
    df['date'] = pd.to_datetime(df['date'])
    df['amount'] = df['amount'].astype(float)
    df['month'] = df['date'].dt.to_period('M').astype(str)
    df['weekday'] = df['date'].dt.day_name()

    cat_summary = df.groupby('category')['amount'].agg(['sum', 'count'])
    cat_summary['pct'] = (cat_summary['sum'] / cat_summary['sum'].sum() * 100).round(1)
    print("\n=== 各類別支出 ===")
    print(cat_summary.sort_values('sum', ascending=False))

    monthly = df.groupby('month')['amount'].sum()
    print("\n=== 每月支出 ===")
    print(monthly)

    print("\n=== 單筆 Top 5 ===")
    print(df.nlargest(5, 'amount')[['date', 'category', 'amount', 'description']])

    weekday_order = ['Monday','Tuesday','Wednesday','Thursday','Friday','Saturday','Sunday']
    weekday_avg = df.groupby('weekday')['amount'].mean().reindex(weekday_order)
    print("\n=== 各天平均消費 ===")
    print(weekday_avg)

    return cat_summary, monthly, weekday_avg

# ── 3. 視覺化（此處略，自行補完）────────────────
def visualize(df, cat_summary, monthly, weekday_avg):
    fig, axes = plt.subplots(2, 2, figsize=(14, 10))
    fig.suptitle('個人支出分析儀表板', fontsize=16, fontweight='bold')
    # TODO: 補完四個子圖
    plt.tight_layout()
    plt.savefig('expense_dashboard.png', dpi=150, bbox_inches='tight')
    print("儀表板已存為 expense_dashboard.png")

if __name__ == '__main__':
    df = generate_transactions()
    cat_summary, monthly, weekday_avg = analyze(df)
    visualize(df, cat_summary, monthly, weekday_avg)
```

## 提示
- `matplotlib.use('Agg')` 必須在 `import matplotlib.pyplot` 之前呼叫，否則無 GUI 環境會報錯
- 中文字型問題：`plt.rcParams['font.family'] = ['DejaVu Sans']`，或安裝 `noto-fonts-cjk` 後設定 `Noto Sans CJK TC`
- Pandas Period：`df['date'].dt.to_period('M')` 轉為月份分組，再 `.astype(str)` 可當 key
- KMeans 分群前務必用 `StandardScaler` 標準化特徵，否則金額量級會壓過頻次
- `plt.subplots_adjust(hspace=0.4, wspace=0.3)` 可調整子圖間距
- 存 JSON 時注意 `numpy.int64` 需轉為 `int`：`json.dumps(data, default=lambda x: int(x) if hasattr(x, '__int__') else x)`
