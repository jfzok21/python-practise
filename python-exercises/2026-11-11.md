# 第 19 週今日 Python 練習題：股票數據爬蟲與分析儀表板

## 題目說明

建立一個完整的實戰專案：從網路爬取股票歷史數據，使用 Pandas 進行資料清洗與分析，再以 matplotlib 繪製視覺化圖表，最後將結果匯出為 CSV 與 PNG 報告。本題整合前幾週所有學過的技術。

## 技術要求
- 概念：爬蟲、資料清洗、Pandas 分析、matplotlib 視覺化、CSV 匯出
- 需要的模組：`requests`, `BeautifulSoup4`, `pandas`, `matplotlib`, `csv`, `os`

## 具體任務

1. **爬取數據**：使用 `requests` + `BeautifulSoup` 從 [Yahoo Finance](https://finance.yahoo.com) 或模擬資料爬取至少一支股票（如 AAPL）的過去 30 天收盤價與成交量。若無法存取外部網路，可用以下模擬函式產生假資料：
   ```python
   import random
   from datetime import date, timedelta

   def generate_mock_stock(ticker, days=30):
       data = []
       price = 150.0
       start = date.today() - timedelta(days=days)
       for i in range(days):
           price += random.uniform(-3, 3)
           volume = random.randint(50_000_000, 150_000_000)
           data.append({
               "date": str(start + timedelta(days=i)),
               "close": round(price, 2),
               "volume": volume
           })
       return data
   ```

2. **清洗與分析**：用 Pandas 載入資料，計算：
   - 5 日移動平均線（MA5）
   - 20 日移動平均線（MA20）
   - 每日漲跌幅（%）
   - 最高收盤價與最低收盤價

3. **視覺化**：用 matplotlib 繪製雙子圖（subplot）：
   - 上圖：收盤價折線圖 + MA5（橙色虛線）+ MA20（紅色虛線）
   - 下圖：成交量長條圖（漲日用綠色，跌日用紅色）

4. **匯出報告**：
   - 將分析後的 DataFrame 存為 `stock_report.csv`
   - 將圖表存為 `stock_chart.png`

## 範例

```python
# 預期輸出（終端機）

報告已儲存：stock_report.csv
圖表已儲存：stock_chart.png
```

## 提示

- Pandas 移動平均：`df['MA5'] = df['close'].rolling(window=5).mean()`
- 漲跌幅計算：`df['change_pct'] = df['close'].pct_change() * 100`
- matplotlib 雙子圖：`fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(12, 8), sharex=True)`
- 成交量顏色：`colors = ['green' if c >= 0 else 'red' for c in df['change_pct']]`
- 存圖：`plt.savefig('stock_chart.png', dpi=150, bbox_inches='tight')`
