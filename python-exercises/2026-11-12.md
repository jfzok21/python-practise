# 第 19 週今日 Python 練習題：天氣資料爬蟲與分析儀表板

## 題目說明

綜合運用前幾週學到的技能，建立一個完整的天氣資料分析工具。  
你將從開放資料 API 抓取天氣資訊，用 Pandas 整理後，產出統計分析並以 matplotlib 繪製視覺化圖表，最後將結果存成 CSV 和 PNG 圖片。

## 技術要求
- 概念：requests、JSON 解析、Pandas 資料清理、matplotlib 視覺化、CSV 輸出
- 需要的模組：`requests`、`pandas`、`matplotlib`、`csv`、`datetime`

## 具體任務

1. **取得資料**  
   使用 [Open-Meteo](https://open-meteo.com/) 免費天氣 API 取得台北（latitude=25.05, longitude=121.53）過去 7 天的每小時氣溫與降雨量：
   ```
   https://api.open-meteo.com/v1/forecast?latitude=25.05&longitude=121.53&hourly=temperature_2m,precipitation&past_days=7&forecast_days=0
   ```

2. **整理資料**  
   - 將 JSON 解析後放入 `pandas.DataFrame`
   - 欄位名稱統一改為：`datetime`、`temperature`、`precipitation`
   - `datetime` 欄位轉為 `datetime` 型別
   - 移除任何 NaN 列

3. **統計分析**  
   計算並印出：
   - 7 天平均氣溫、最高氣溫、最低氣溫
   - 7 天總降雨量
   - 每天最高氣溫的日期

4. **繪製圖表**  
   用 `matplotlib` 畫一個雙 Y 軸折線圖：
   - 左 Y 軸（藍線）：每小時氣溫（°C）
   - 右 Y 軸（綠柱）：每小時降雨量（mm）
   - X 軸：日期時間
   - 加上標題、圖例、格線
   - 儲存為 `weather_report.png`

5. **輸出 CSV**  
   將每天的摘要（日期、平均氣溫、最高氣溫、最低氣溫、當日累積雨量）存成 `weather_summary.csv`

## 範例


## 提示

- `open-meteo` 回傳的 `hourly.time` 是字串 list，可用 `pd.to_datetime()` 轉換
- 雙 Y 軸：`ax2 = ax1.twinx()`，再對 `ax2` 畫柱狀圖
- 日期分組統計：`df.groupby(df['datetime'].dt.date).agg(...)`
- `plt.xticks(rotation=45)` 避免日期重疊
- 儲存 PNG 前記得 `plt.tight_layout()`
