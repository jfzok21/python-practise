# 第 19 週今日 Python 練習題：天氣資料爬取與趨勢分析儀表板

## 題目說明

綜合運用前幾週所學的網頁爬取、Pandas 資料處理、Matplotlib 視覺化，以及 scikit-learn 機器學習技術，建立一個完整的「天氣資料分析管線」。你將從開放氣象 API 取得資料、清洗整理、繪製趨勢圖，並用線性迴歸預測未來溫度走勢。

## 技術要求
- 概念：資料管線（data pipeline）、特徵工程、線性迴歸預測、資料視覺化
- 需要的模組：`requests`、`pandas`、`matplotlib`、`sklearn`、`csv`、`datetime`

## 具體任務

1. **取得天氣資料**
   使用 [Open-Meteo](https://open-meteo.com/) 免費 API（無需 API key）取得台北過去 30 天的每日最高氣溫：
   ```
   https://api.open-meteo.com/v1/forecast?latitude=25.05&longitude=121.53&daily=temperature_2m_max&past_days=30&timezone=Asia%2FTaipei&forecast_days=1
   ```

2. **用 Pandas 清洗與整理**
   - 將 JSON 回應轉成 DataFrame
   - 將日期欄位轉成 `datetime` 型態並設為索引
   - 新增一欄 `day_index`（第幾天，從 0 開始），供模型訓練用

3. **儲存成 CSV**
   將整理好的 DataFrame 存成 `weather_taipei.csv`

4. **線性迴歸預測未來 7 天**
   - 以 `day_index` 為特徵（X），`temperature_2m_max` 為目標（y）
   - 訓練 `LinearRegression` 模型
   - 預測接下來 7 天的最高氣溫

5. **視覺化**
   用 Matplotlib 畫出：
   - 藍色折線：過去 30 天實際氣溫
   - 橘色虛線：未來 7 天預測氣溫
   - 加上標題、X/Y 軸標籤、圖例
   - 儲存成 `weather_forecast.png`

## 提示

- `requests.get(url).json()` 可直接解析 JSON 回應
- `pd.to_datetime()` 轉換日期字串
- `df.set_index('time', inplace=True)` 設定日期為索引
- `np.arange()` 產生未來日期的 day_index
- `model.predict(X_future.reshape(-1, 1))` 進行預測
- `plt.axvline()` 可畫垂直分隔線區分歷史與預測區段
