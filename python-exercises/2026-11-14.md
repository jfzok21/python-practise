# 第 19 週今日 Python 練習題：股票新聞情緒分析儀表板

## 題目說明

建立一個整合網頁爬蟲、資料處理、情緒分析與視覺化的完整專案。
你將爬取財經新聞標題，對其進行簡單的情緒分析，並以圖表呈現結果，
模擬真實資料科學工作流程中「從資料收集到洞察呈現」的完整鏈路。

## 技術要求
- 概念：爬蟲、文字處理、情緒關鍵字比對、資料聚合、視覺化
- 需要的模組：`requests`、`BeautifulSoup`、`pandas`、`matplotlib`、`csv`

## 具體任務

1. **資料收集（爬蟲）**
   - 使用 `requests` 爬取 [Yahoo 奇摩股市新聞](https://tw.stock.yahoo.com/news/) 或任一財經新聞 RSS 來源（例如 `https://news.google.com/rss/search?q=台股&hl=zh-TW&gl=TW&ceid=TW:zh-Hant`）。
   - 以 `BeautifulSoup` 解析出每篇新聞的「標題」與「發布時間」。
   - 至少擷取 20 則新聞。

2. **情緒分析（關鍵字比對）**
   - 定義正面關鍵字清單（例如：漲、創高、突破、買超、利多、亮眼、強勁）。
   - 定義負面關鍵字清單（例如：跌、破底、賣超、利空、衰退、走弱、下修）。
   - 對每則新聞標題掃描，計算正面與負面詞出現次數，決定情緒分類（`正面` / `負面` / `中性`）。

3. **資料儲存**
   - 將結果以 `pandas` DataFrame 整理，欄位包含：`title`、`published`、`sentiment`、`pos_count`、`neg_count`。
   - 匯出為 `news_sentiment.csv`。

4. **視覺化**
   - 繪製圓餅圖：顯示正面、負面、中性新聞的比例。
   - 繪製長條圖：以時間（小時或日期）為 X 軸，顯示正面 vs 負面新聞數量趨勢。
   - 儲存圖表為 `sentiment_chart.png`。

5. **主程式整合**
   - 以 `main()` 函數整合以上所有步驟，確保可單獨執行。
   - 在終端機輸出摘要統計：總篇數、各情緒分類數量、最常出現的正面/負面關鍵字。

## 提示

- RSS 格式的 XML 可用 `BeautifulSoup(response.content, "xml")` 解析，`<item>` 標籤內有 `<title>` 和 `<pubDate>`。
- `datetime.strptime()` 可將字串轉換成日期物件，方便依時間分組。
- `df.groupby(["date", "sentiment"]).size().unstack(fill_value=0)` 可快速生成趨勢長條圖所需的資料結構。
- `matplotlib` 中文字體可加入：`plt.rcParams['font.family'] = 'DejaVu Sans'`（或安裝 `noto-fonts-cjk` 後使用 `'Noto Sans CJK TC'`）。
- 若網站有反爬蟲措施，可在 `requests.get()` 加入 `headers={"User-Agent": "Mozilla/5.0 ..."}`。

## 學習重點（跟爬蟲／ML 的關聯）
