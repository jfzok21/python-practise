# 第 19 週今日 Python 練習題：Hacker News 熱門文章爬取與關鍵字分析

## 題目說明

綜合運用 requests、BeautifulSoup、Pandas 和 Matplotlib，建立一個「科技新聞熱度分析工具」。你將從 Hacker News 官方 API 抓取今日熱門文章，分析標題關鍵字頻率、文章分數分佈，並將結果視覺化輸出，同時儲存成 CSV 供後續使用。

## 技術要求
- 概念：REST API 資料擷取、文字清洗、詞頻統計、資料視覺化
- 需要的模組：`requests`、`pandas`、`matplotlib`、`collections`、`re`

## 具體任務

1. **從 HN API 取得熱門文章 ID**
   使用 Hacker News 官方 API（無需 API key）取得前 30 篇熱門文章：
   ```
   https://hacker-news.firebaseio.com/v0/topstories.json
   ```
   再逐一呼叫以下端點取得每篇文章細節（標題、分數、留言數、作者、時間）：
   ```
   https://hacker-news.firebaseio.com/v0/item/{id}.json
   ```

2. **用 Pandas 整理成 DataFrame**
   欄位包含：`title`、`score`、`comments`（descendants）、`by`（作者）、`time`（轉為 datetime）
   - 過濾掉 `type` 不是 `story` 的項目
   - 分數低於 10 的文章也一併過濾

3. **儲存成 CSV**
   將整理好的 DataFrame 存成 `hn_top_stories.csv`，僅保留上述 5 個欄位。

4. **標題關鍵字詞頻統計**
   - 將所有標題合併後轉為小寫，用正規表達式 `re.findall(r'[a-zA-Z]{4,}', text)` 擷取 4 字母以上的英文單字
   - 排除常見停用詞：`['with', 'from', 'that', 'this', 'your', 'have', 'will', 'what', 'show', 'just', 'more', 'than', 'they', 'been', 'were', 'when', 'their', 'using', 'about', 'into', 'some', 'also', 'like']`
   - 用 `collections.Counter` 取出前 15 名關鍵字

5. **視覺化（並排兩張圖）**
   用 `plt.subplots(1, 2, figsize=(14, 6))` 畫出：
   - **左圖（水平長條圖）**：前 15 名關鍵字及其出現次數，顏色用 `steelblue`，最高的一條改為 `tomato`
   - **右圖（散佈圖）**：X 軸為文章分數（score），Y 軸為留言數（comments），點的大小固定為 60，顏色 `mediumseagreen`，加上標題文字標註（用 `annotate` 標出分數前 5 名的文章標題，截短至 30 字）
   - 整體標題、X/Y 軸標籤均使用英文（避免中文字體問題）
   - 存成 `hn_analysis.png`

## 提示

- `requests.get(url, timeout=5).json()` 取得 JSON；加上 `timeout` 避免卡住
- 可用 `time.sleep(0.05)` 在逐篇抓取時稍作間隔，避免請求過快
- `pd.to_datetime(df['time'], unit='s')` 將 Unix timestamp 轉成 datetime
- `df.sort_values('score', ascending=False).head(5)` 取分數前 5 名
- `ax.barh()` 畫水平長條圖；記得用 `ax.invert_yaxis()` 讓最高的在最上方
- `ax.annotate(text, (x, y), fontsize=7, alpha=0.7)` 加上文字標籤
