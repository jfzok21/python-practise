# 第 19 週今日 Python 練習題：PyPI 套件下載趨勢分析與線性回歸預測

## 題目說明

綜合運用 requests、Pandas、Matplotlib 和 scikit-learn，建立一個「Python 套件健康度儀表板」。你將透過 PyPI Stats API（免費、無需 API key）取得熱門 Python 套件的下載資料，分析各套件的平台分佈與 Python 版本採用率，並用線性回歸預測未來一週的下載趨勢。

## 技術要求
- 概念：REST API 資料擷取、多圖表版面配置、線性回歸預測
- 需要的模組：`requests`、`pandas`、`matplotlib`、`numpy`、`sklearn`

## 具體任務

1. **定義要分析的套件清單**
   選 5 個套件，例如：`['requests', 'numpy', 'pandas', 'flask', 'scikit-learn']`
   用迴圈呼叫以下端點取得「最近下載數」（JSON 格式，無需 API key）：
   ```
   https://pypistats.org/api/packages/{package}/recent
   ```
   擷取 `data` 欄位中 `last_day`、`last_week`、`last_month` 三個數值，建成 DataFrame。

2. **取得各套件的平台（系統）分佈**
   呼叫：
   ```
   https://pypistats.org/api/packages/{package}/system?mirrors=false
   ```
   擷取 `data` 陣列中 `category`（平台名稱）與 `downloads`（下載數），僅保留最新日期那筆（`date` 最大值），建成一個以套件為索引、平台為欄位的 Pivot Table DataFrame。

3. **取得 Python 版本分佈**
   呼叫：
   ```
   https://pypistats.org/api/packages/{package}/python_minor?mirrors=false
   ```
   篩選出 `category` 符合 `3.x` 格式（用正規表達式 `re.match(r'^3\.\d+$', ...)`），取最近一週資料加總，找出每個套件最受歡迎的前 3 名 Python 版本。

4. **線性回歸預測（用 `requests` 套件示範）**
   呼叫：
   ```
   https://pypistats.org/api/packages/requests/overall?mirrors=false
   ```
   回傳的 `data` 陣列包含每日下載數，取最近 30 天的資料：
   - 以「距最早日期的天數」為 X（`numpy.arange`），每日下載數為 y
   - 用 `sklearn.linear_model.LinearRegression` 擬合，預測接下來 7 天的下載量
   - 輸出預測值（整數）及回歸係數（斜率 slope、截距 intercept）

5. **視覺化（2×2 四格圖）**
   用 `plt.subplots(2, 2, figsize=(14, 10))` 畫出：
   - **左上（水平長條圖）**：5 個套件「上週下載數」由多到少排列，顏色 `steelblue`，最高者改 `tomato`
   - **右上（分組長條圖）**：Pivot Table 中各套件在 Linux / Windows / Darwin 三平台的下載數對比
   - **左下（堆疊長條圖）**：每個套件的前 3 名 Python 版本下載數（`bottom` 累加）
   - **右下（折線圖＋預測）**：`requests` 最近 30 天實際下載數（藍色實線）＋未來 7 天預測（橘色虛線），並在圖中標示斜率（Trend: +N/day）
   - 整體大標題、各子圖標題與座標軸標籤一律用英文
   - 存成 `pypi_dashboard.png`，`dpi=150`

## 提示

- `requests.get(url, timeout=10).json()` 取得資料；若回傳錯誤可用 `.get('data', [])` 安全存取
- 建 Pivot Table：`df.pivot_table(index='package', columns='category', values='downloads', aggfunc='sum').fillna(0)`
- 分組長條圖：用迴圈搭配 `x + i * width` 偏移每組的位置，`width = 0.25`
- 堆疊長條圖：先把每個套件的版本資料收集成 dict，再用 `bottom` 累加：
  ```python
  bottom = np.zeros(len(packages))
  for ver in top_versions:
      ax.bar(packages, counts[ver], bottom=bottom, label=ver)
      bottom += counts[ver]
  ```
- `LinearRegression().fit(X.reshape(-1,1), y)`；`.predict()` 傳入包含未來天數的陣列
- `ax.plot(..., linestyle='--', color='orange', label='Forecast')` 畫預測線
