# 第 20 週今日 Python 練習題：個人財務追蹤器

## 題目說明

建立一個命令列（CLI）個人財務追蹤工具，能夠記錄收入與支出、儲存歷史紀錄到 CSV 檔案，並以文字圖表方式呈現每月統計摘要。這個專案整合了前幾週學過的函數、資料結構、字串處理、檔案讀寫等核心技能。

## 技術要求

- 概念：函數、dict、list、CSV 讀寫、datetime、格式化輸出、例外處理
- 需要的模組：`csv`、`datetime`（標準函式庫，無需安裝）

## 具體任務

1. **設計資料結構**：每筆記錄包含 `date`（YYYY-MM-DD）、`type`（`income` 或 `expense`）、`category`（例如「飲食」、「交通」、「薪資」）、`amount`（浮點數）、`note`（備註）。

2. **實作核心函數**：
   - `add_record(records, type_, category, amount, note)` → 新增一筆紀錄並回傳更新後的 list
   - `save_to_csv(records, filepath)` → 將所有紀錄存入 CSV
   - `load_from_csv(filepath)` → 從 CSV 讀取紀錄，若檔案不存在則回傳空 list
   - `monthly_summary(records, year, month)` → 回傳 dict，包含 `total_income`、`total_expense`、`net`、`by_category`

3. **實作文字長條圖**：`print_bar_chart(by_category)` 以 `█` 字元繪製各類別支出比例（最長的類別 = 20 個 `█`）。

4. **主程式選單**：
   ```
   [1] 新增收入
   [2] 新增支出
   [3] 查看本月摘要
   [4] 離開
   ```
   使用 `while True` 迴圈驅動選單，以 `try/except ValueError` 處理非數字輸入。

5. **資料持久化**：每次新增紀錄後立刻呼叫 `save_to_csv`，啟動時呼叫 `load_from_csv` 載入舊資料。

## 範例

```python
# 執行後的互動示例
# =======================
# [1] 新增收入  [2] 新增支出  [3] 查看本月摘要  [4] 離開
# 請選擇： 2
# 類別（飲食/交通/娛樂/其他）： 飲食
# 金額： 350
# 備註（可留空）： 午餐便當
# ✅ 已新增：2026-11-17 | expense | 飲食 | 350.0 | 午餐便當

# 請選擇： 3
# === 2026 年 11 月 摘要 ===
# 總收入：  50000.0
# 總支出：   8420.0
# 淨額  ：  41580.0
#
# 支出類別分布：
# 飲食    ████████████████████  5200.0
# 交通    ████████              2000.0
# 娛樂    ████                  1220.0
```

## 提示

- 用 `datetime.date.today().isoformat()` 取得今天日期字串。
- `csv.DictWriter` / `csv.DictReader` 比 `csv.writer` 更易讀，推薦使用。
- 長條圖比例計算：`bar_len = int(amount / max_amount * 20)`，`'█' * bar_len`。
- 讀取 CSV 時，`amount` 欄位會是字串，記得用 `float()` 轉型。
- 若 `by_category` 為空 dict，`print_bar_chart` 應印出「本月無支出紀錄」。
