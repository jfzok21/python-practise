# 第 20 週今日 Python 練習題：個人股票監控儀表板

## 題目說明

建立一個命令列股票監控工具，讓使用者可以追蹤多支股票的即時（模擬）價格，計算漲跌幅，並將每日快照儲存成 CSV 供後續分析。這個專案整合了前幾週學到的所有核心技能：資料結構、函數、檔案讀寫、字串處理、以及網路請求。

## 技術要求
- 概念：dict、list、函數、CSV 讀寫、字串格式化、例外處理
- 需要的模組：`csv`、`json`、`datetime`、`random`（模擬價格）、`os`

## 具體任務

1. **建立投資組合設定檔**
   - 以 JSON 檔案儲存關注股票清單（代號、名稱、買入價格）
   - 程式啟動時讀入設定，若檔案不存在則建立預設清單

2. **模擬即時報價**
   - 撰寫 `get_price(symbol, base_price)` 函數，以 `random` 模組在基準價 ±5% 範圍內產生當日報價
   - 計算漲跌幅（%）與損益（元）

3. **顯示監控儀表板**
   - 以對齊的表格格式輸出每支股票的：代號、名稱、現價、漲跌幅、損益
   - 漲用 `[+]`，跌用 `[-]`，平盤用 `[=]` 標示

4. **儲存每日快照**
   - 將當次查詢結果附加寫入 `portfolio_history.csv`
   - 欄位：日期、代號、名稱、買入價、現價、漲跌幅%、損益

5. **查詢歷史紀錄**
   - 讀取 CSV，計算每支股票的歷史平均現價與最大損益

## 範例

```python
# 設定檔 portfolio.json
{
  "stocks": [
    {"symbol": "2330", "name": "台積電", "buy_price": 950.0},
    {"symbol": "2317", "name": "鴻海",   "buy_price": 110.0},
    {"symbol": "0050", "name": "元大台灣50", "buy_price": 185.0}
  ]
}

# 執行輸出範例
===========================================
       股票監控儀表板  2026-11-18 14:32
===========================================
代號    名稱          現價      漲跌幅    損益
------  ----------  --------  --------  --------
2330    台積電        968.50   [+] 1.95%  +18.50
2317    鴻海          107.30   [-] 2.45%  -2.70
0050    元大台灣50    188.20   [+] 1.73%  +3.20
===========================================
總損益：+19.00 元
===========================================
```

## 提示

- 用 `f"{value:>8.2f}"` 控制數字欄寬與小數位數，讓表格對齊
- `csv.DictWriter` 比 `csv.writer` 更易讀：欄位名稱直接對應 dict 鍵
- 用 `os.path.exists()` 判斷 CSV 是否已存在，決定是否要寫入標題列
- `try/except` 包住 JSON 讀取，捕捉 `FileNotFoundError` 與 `json.JSONDecodeError`

## 學習重點（跟爬蟲／ML 的關聯）

- **爬蟲延伸**：把 `get_price()` 替換成 `requests.get()` 呼叫真實股價 API（如 Yahoo Finance），即可變成真正的即時監控工具
- **ML 延伸**：歷史 CSV 就是訓練資料，可用 Pandas 讀入後做移動平均、或訓練簡單的線性回歸來預測明日收盤價
- **資料管線意識**：本題的「模擬 → 儲存 → 分析」流程正是資料工程的基本架構
