# 第 20 週今日 Python 練習題：股價資料爬取與分析儀表板

## 題目說明

綜合運用前幾週學到的爬蟲、資料處理、視覺化與機器學習技術，建立一個完整的股票資料分析小專案。你將從公開資料來源抓取股價資訊，使用 Pandas 進行分析，再用 matplotlib 畫出走勢圖，最後嘗試用簡單的線性迴歸預測未來趨勢。

## 技術要求
- 概念：HTTP 請求、JSON 解析、DataFrame 操作、資料視覺化、線性迴歸
- 需要的模組：`requests`、`pandas`、`matplotlib`、`sklearn`、`csv`（標準庫）

## 具體任務

1. **資料取得**：使用 `requests` 呼叫 Yahoo Finance 非官方 API（或從 CSV 讀取備用資料），抓取某支股票（例如 AAPL）近 30 筆收盤價。若 API 無法存取，改用下方範例資料直接建立 DataFrame。
2. **資料整理**：
   - 以 Pandas 建立 DataFrame，欄位包含 `date`、`close`。
   - 將 `date` 欄轉為 `datetime` 型態，並設為索引。
   - 計算 5 日移動平均（`MA5`）與 10 日移動平均（`MA10`）。
3. **視覺化**：
   - 畫出收盤價折線圖，並疊加 MA5、MA10 線。
   - 加上標題、X/Y 軸標籤、圖例。
   - 將圖存成 `stock_chart.png`。
4. **機器學習預測**：
   - 以「第幾天」為 X（整數序號），收盤價為 y，訓練 `LinearRegression`。
   - 預測接下來 5 天的收盤價，並印出結果。
5. **輸出報告**：將 DataFrame（含 MA5、MA10）存成 `stock_report.csv`。

## 範例

```python
# 備用資料（若 API 不可用直接貼入）
import pandas as pd

data = {
    "date": pd.date_range(start="2026-10-01", periods=30, freq="B"),
    "close": [
        170, 172, 169, 174, 176, 175, 178, 180, 177, 182,
        184, 183, 186, 185, 188, 190, 189, 192, 194, 193,
        196, 198, 197, 200, 202, 201, 204, 206, 205, 208
    ]
}
df = pd.DataFrame(data).set_index("date")

# 移動平均
df["MA5"]  = df["close"].rolling(5).mean()
df["MA10"] = df["close"].rolling(10).mean()
print(df.tail(10))

# 預期輸出（部分）：
#             close    MA5    MA10
# 2026-11-10    204  203.0   197.0
# 2026-11-11    206  203.8   198.2
# ...
```

```python
# 線性迴歸預測片段
from sklearn.linear_model import LinearRegression
import numpy as np

X = np.arange(len(df)).reshape(-1, 1)
y = df["close"].values
model = LinearRegression().fit(X, y)

future_X = np.arange(len(df), len(df) + 5).reshape(-1, 1)
predictions = model.predict(future_X)
for i, p in enumerate(predictions, 1):
    print(f"第 {i} 天預測收盤價：{p:.2f}")
```

## 提示
- `pd.date_range(freq="B")` 可以自動跳過週末，模擬交易日。
- `rolling(window).mean()` 會在資料不足 window 筆時產生 `NaN`，畫圖前可用 `dropna()` 或直接讓 matplotlib 跳過。
- 存圖時記得加 `plt.tight_layout()` 防止標籤被截斷。
- LinearRegression 只是趨勢參考，實際股價預測複雜得多，別拿去買股票 😄
