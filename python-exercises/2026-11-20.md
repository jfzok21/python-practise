# 第 20 週今日 Python 練習題：個人股票投資組合分析工具

## 題目說明

建立一個完整的股票投資組合分析工具，能夠爬取股票資料、計算報酬率、並用圖表視覺化你的投資表現。整合前幾週學習的爬蟲、Pandas、NumPy 與 matplotlib 技術，做出一個真實可用的專案。

## 技術要求
- 概念：網頁爬蟲、資料清洗、統計計算、資料視覺化、CSV 檔案讀寫
- 需要的模組：`requests`、`pandas`、`matplotlib`、`numpy`、`csv`、`datetime`

## 具體任務

1. **建立投資組合 CSV**
   建立 `portfolio.csv`，格式如下：
   ```
   ticker,shares,buy_price,buy_date
   AAPL,10,150.00,2024-01-15
   MSFT,5,380.00,2024-02-20
   TSLA,8,200.00,2024-03-10
   ```

2. **爬取即時股價**
   使用 `requests` 從 Yahoo Finance 或其他免費 API（如 `https://query1.finance.yahoo.com/v8/finance/chart/{ticker}`）取得每支股票的最新收盤價。

3. **計算投資績效**
   對每筆持股計算：
   - 目前市值 = 股數 × 目前價格
   - 損益金額 = 目前市值 - 成本（股數 × 買入價格）
   - 損益百分比 = 損益金額 / 成本 × 100

4. **產出績效摘要表格**
   用 `pandas.DataFrame` 整理所有數據，並印出格式化表格，包括：整體總損益、最佳表現股票、最差表現股票。

5. **繪製視覺化圖表**
   - 長條圖：每支股票的損益百分比（正負用不同顏色）
   - 圓餅圖：各股票在組合中的市值佔比

6. **儲存分析報告**
   將分析結果存入 `portfolio_report_[日期].csv`。

## 提示

- Yahoo Finance API 範例：
  ```python
  import requests
  url = f"https://query1.finance.yahoo.com/v8/finance/chart/AAPL"
  headers = {"User-Agent": "Mozilla/5.0"}
  r = requests.get(url, headers=headers)
  data = r.json()
  price = data["chart"]["result"][0]["meta"]["regularMarketPrice"]
  ```
- 若 API 被擋，可先用 `yfinance` 套件（`pip install yfinance`）替代
- 顏色條件：損益為正用 `'green'`，負用 `'red'`
- 格式化數字：`f"{value:+.2f}"` 可自動加上正負號
