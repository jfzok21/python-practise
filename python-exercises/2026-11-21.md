# 第 20 週今日 Python 練習題：天氣資料爬蟲與分析儀表板

## 題目說明

綜合運用前幾週所學的爬蟲、資料處理、視覺化與機器學習技術，建立一個完整的「天氣資料分析小專案」。你將從公開 API 取得天氣數據，整理成 CSV，並繪製趨勢圖，最後用簡單的線性回歸預測明日溫度。

## 技術要求

- 概念：API 請求、JSON 解析、Pandas 資料清理、Matplotlib 視覺化、sklearn 線性回歸
- 需要的模組：`requests`、`pandas`、`matplotlib`、`sklearn`

## 具體任務

1. **取得資料**：呼叫 Open-Meteo 免費天氣 API，取得台北市過去 7 天的每日最高溫與最低溫。
   - API（免費、無需 Key）：
     ```
     https://api.open-meteo.com/v1/forecast?latitude=25.03&longitude=121.56&daily=temperature_2m_max,temperature_2m_min&past_days=7&forecast_days=1&timezone=Asia%2FTaipei
     ```
2. **整理成 DataFrame**：用 Pandas 把日期、最高溫、最低溫整理成一個表格，並儲存為 `weather_data.csv`。
3. **視覺化**：用 Matplotlib 畫出過去 7 天的最高溫與最低溫折線圖（雙線），標示日期在 X 軸，加上標題與圖例。
4. **線性回歸預測**：以「第幾天（0–6）」為特徵，最高溫為目標，訓練一個 `LinearRegression` 模型，預測第 8 天（即明日）的最高溫。
5. **輸出報告**：在終端機印出以下格式的摘要：
   ```
   📊 台北天氣分析報告
   期間：YYYY-MM-DD ～ YYYY-MM-DD
   平均最高溫：XX.X °C
   平均最低溫：XX.X °C
   預測明日最高溫：XX.X °C
   ```

## 提示

- `requests.get(url).json()` 可直接取得 JSON 物件。
- API 回傳的 `daily` 欄位包含 `time`、`temperature_2m_max`、`temperature_2m_min` 三個 list，長度相同，可直接傳給 `pd.DataFrame()`。
- Matplotlib 的 `plt.xticks(rotation=45)` 可讓日期標籤斜排，避免重疊。
- `LinearRegression` 的 `fit(X, y)` 中，`X` 需要是二維陣列：`np.array(range(7)).reshape(-1, 1)`。
- 預測明日時，傳入 `[[7]]` 給 `model.predict()`。
