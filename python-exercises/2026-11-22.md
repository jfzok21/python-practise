# 第 20 週今日 Python 練習題：股票資料爬取與分析儀表板

## 題目說明

建立一個完整的股票資料分析工具，從網路上爬取台灣上市公司的股票資訊，進行資料清理與統計分析，並用圖表視覺化呈現結果，最後將分析報告儲存為 CSV 與圖片檔案。

## 技術要求
- 概念：爬蟲、資料清理、Pandas 統計分析、Matplotlib 視覺化、CSV 輸出
- 需要的模組：`requests`、`BeautifulSoup`、`pandas`、`matplotlib`、`csv`

## 具體任務

1. **資料爬取**：使用 `requests` 和 `BeautifulSoup` 爬取台灣證交所（或模擬資料）至少 10 支股票的當日資訊：
   - 股票代號、股票名稱、成交量、開盤價、最高價、最低價、收盤價、漲跌幅
   
2. **資料清理（Pandas）**：
   - 將爬取的資料轉換為 `DataFrame`
   - 處理缺失值（NaN）：數值欄位填入 0，字串欄位填入 "N/A"
   - 將價格與成交量欄位轉換為正確的數值型態（移除逗號、百分比符號）
   - 新增一欄 `price_range`（最高價 - 最低價）

3. **統計分析**：
   - 計算所有股票的平均收盤價、成交量排行前 5 名
   - 找出漲幅最大與跌幅最大的股票
   - 計算整體市場漲跌比例（漲家數 vs 跌家數）

4. **視覺化（Matplotlib）**：
   - 繪製「成交量前 10 名」長條圖
   - 繪製「漲跌幅分布」直方圖
   - 儲存圖片為 `stock_report_2026-11-22.png`

5. **輸出結果**：
   - 將整理好的 DataFrame 儲存為 `stock_data_2026-11-22.csv`
   - 在終端機印出統計摘要

## 提示

- 若無法爬取真實資料，可用以下方式生成模擬資料：
  ```python
  import random
  import pandas as pd
  
  stocks = [
      ('2330', '台積電'), ('2317', '鴻海'), ('2454', '聯發科'),
      ('2412', '中華電'), ('2308', '台達電'), ('1301', '台塑'),
      ('2882', '國泰金'), ('2881', '富邦金'), ('3008', '大立光'),
      ('2303', '聯電')
  ]
  
  data = []
  for code, name in stocks:
      open_p = round(random.uniform(50, 500), 2)
      close_p = round(open_p * (1 + random.uniform(-0.1, 0.1)), 2)
      high_p = round(max(open_p, close_p) * random.uniform(1.0, 1.05), 2)
      low_p = round(min(open_p, close_p) * random.uniform(0.95, 1.0), 2)
      volume = random.randint(1_000_000, 50_000_000)
      change_pct = round((close_p - open_p) / open_p * 100, 2)
      data.append([code, name, volume, open_p, high_p, low_p, close_p, change_pct])
  
  df = pd.DataFrame(data, columns=['代號','名稱','成交量','開盤','最高','最低','收盤','漲跌幅%'])
  ```

- 使用 `df.nlargest(5, '成交量')` 取排行前 5
- Matplotlib 中文字體設定：
  ```python
  import matplotlib
  matplotlib.rcParams['font.family'] = 'DejaVu Sans'  # 或安裝中文字體
  ```
- `df.to_csv('filename.csv', index=False, encoding='utf-8-sig')` 可讓 Excel 正確顯示中文
