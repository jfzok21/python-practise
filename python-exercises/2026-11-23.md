# 第 20 週今日 Python 練習題：書評情緒分類器

## 題目說明

建立一個完整的文字情緒分析工具，能從 CSV 讀取書評資料、用機器學習模型判斷正負面情緒，並視覺化模型效能與關鍵詞。整合 sklearn、Pandas、matplotlib，打造一個真實可用的 NLP 分類器。

## 技術要求
- 概念：TF-IDF 文字向量化、Naive Bayes 分類、模型評估、混淆矩陣
- 需要的模組：`pandas`、`sklearn`、`matplotlib`、`numpy`、`csv`

## 具體任務

1. **準備訓練資料**
   建立 `reviews.csv`，格式如下（至少 20 筆，正負各半）：
   ```
   review,sentiment
   "This book changed my life, absolutely brilliant!",positive
   "Boring and poorly written, wasted my time.",negative
   "A masterpiece of modern literature.",positive
   "I couldn't finish it, too slow and dull.",negative
   ```

2. **文字前處理**
   - 用 `sklearn.feature_extraction.text.TfidfVectorizer` 將文字轉成數值向量
   - 設定 `stop_words='english'` 過濾無意義詞
   - 切分訓練集 / 測試集（80% / 20%），用 `train_test_split`

3. **訓練分類模型**
   用 `MultinomialNB`（Naive Bayes）訓練情緒分類器：
   ```python
   from sklearn.naive_bayes import MultinomialNB
   model = MultinomialNB()
   model.fit(X_train, y_train)
   ```

4. **評估模型效能**
   計算並印出：
   - 準確率（Accuracy）
   - 分類報告（`classification_report`，包含 precision、recall、f1-score）
   - 混淆矩陣（Confusion Matrix）

5. **視覺化結果**
   繪製兩張圖並排：
   - 左圖：混淆矩陣熱力圖（用 `imshow`）
   - 右圖：正面 / 負面書評各自的 Top 10 重要關鍵詞（水平長條圖）

6. **互動預測**
   讓使用者輸入一段書評，程式即時輸出預測情緒與信心分數：
   ```
   請輸入書評：The story was captivating and emotionally powerful.
   預測結果：正面 ✅（信心：87.3%）
   ```

## 學習重點

這個專案展示了 NLP（自然語言處理）的核心流程：
- **TF-IDF（第 12 週延伸）**：把文字轉成機器能理解的數字
- **sklearn（第 12 週）**：模型訓練、評估一條龍
- **Pandas（第 10 週）**：讀取與整理 CSV 資料
- **matplotlib（第 11 週）**：視覺化模型效能

在業界，情緒分析廣泛應用於客服品質監控、社群輿情分析、商品評論自動分類，是進入資料科學與 NLP 領域的第一個真實專案。

## 進階挑戰（選做）

1. **換用更強的模型**：把 `MultinomialNB` 換成 `LogisticRegression` 或 `SVC`，比較準確率差異，用長條圖並排顯示三種模型的 F1-score。

2. **加入中文支援**：安裝 `jieba` 套件，把書評改成中文，用結巴斷詞後再丟入 TF-IDF，讓分類器能處理中文書評。

3. **爬取真實書評**：用 `requests` + `BeautifulSoup` 從 Goodreads 或 博客來 爬取真實書評（至少 100 筆），用真實資料重新訓練模型，觀察準確率變化。

4. **超參數調優**：用 `GridSearchCV` 自動搜尋最佳 `TfidfVectorizer` 參數（`ngram_range`、`max_features`），找到讓模型效能最高的組合。
