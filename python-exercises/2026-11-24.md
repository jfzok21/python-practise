# 第 21 週今日 Python 練習題：天氣資料爬取與分析儀表板

## 題目說明

實作一個完整的「天氣資料分析專案」，結合爬蟲、資料清理、Pandas 分析與 Matplotlib 視覺化，模擬真實資料工程師的工作流程。你將從公開 API 取得多城市天氣資料，整理成結構化 CSV，再以圖表呈現分析結果。

---

## 技術要求

- **概念**：API 請求、JSON 解析、Pandas DataFrame、Matplotlib 繪圖、資料清理
- **需要的模組**：`requests`、`pandas`、`matplotlib`、`json`、`csv`、`datetime`

---

## 具體任務

1. **取得天氣資料**
   使用 [Open-Meteo](https://open-meteo.com/) 免費天氣 API（無需 API Key），取得以下 5 座城市過去 7 天的每日最高溫、最低溫與降雨量：
   - 台北（25.0330, 121.5654）
   - 東京（35.6895, 139.6917）
   - 曼谷（13.7563, 100.5018）
   - 首爾（37.5665, 126.9780）
   - 新加坡（1.3521, 103.8198）

   API 範例 URL（台北）：
   ```
   https://api.open-meteo.com/v1/forecast?latitude=25.0330&longitude=121.5654&daily=temperature_2m_max,temperature_2m_min,precipitation_sum&past_days=7&forecast_days=0&timezone=Asia%2FTaipei
   ```

2. **清理並整合資料**
   - 將所有城市的資料合併成一個 Pandas DataFrame
   - 欄位：`date`、`city`、`temp_max`、`temp_min`、`precipitation`
   - 計算每天的「溫差」欄位（`temp_range = temp_max - temp_min`）

3. **儲存為 CSV**
   將整理好的 DataFrame 存為 `weather_data.csv`

4. **資料分析**
   用 Pandas 計算並 print 出：
   - 各城市 7 天平均最高溫（排序由高至低）
   - 7 天內哪一天哪座城市降雨量最多
   - 哪座城市日夜溫差最大（平均溫差）

5. **視覺化（3 張圖）**
   用 Matplotlib 繪製：
   - **折線圖**：5 座城市 7 天最高溫度趨勢（每條線代表一個城市，不同顏色）
   - **長條圖**：各城市 7 天累計降雨量比較
   - **熱力圖（heatmap）**：以 `imshow` 呈現城市 × 日期的溫差矩陣
   
   將 3 張圖合成一個 PNG 存檔：`weather_report.png`

## 提示

- Open-Meteo API 回傳 JSON，`response.json()['daily']` 包含各欄位的串列
- 建立 DataFrame 時，可先對每個城市建立小 df，再用 `pd.concat()` 合併
- Matplotlib 多圖可用 `fig, axes = plt.subplots(1, 3, figsize=(18, 5))` 建立子圖
- 熱力圖：先用 `pivot_table` 把 DataFrame 轉成城市 × 日期的矩陣，再傳入 `axes[2].imshow()`
