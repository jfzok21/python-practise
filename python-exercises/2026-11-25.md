# 第 21 週今日 Python 練習題：股票資料自動化分析儀表板

## 題目說明

建立一個自動化的股票資料分析工具，從公開 API 抓取股票歷史資料，使用 Pandas 進行統計分析，並以 Matplotlib 生成視覺化報告，最後將結果儲存為 CSV 和圖表檔案。

---

## 技術要求

- **概念**：API 資料抓取、資料清理、移動平均、訊號分析、視覺化報告
- **需要的模組**：
  - `requests`（HTTP 請求）
  - `pandas`（資料處理）
  - `matplotlib`（繪圖）
  - `datetime`（日期處理）
  - `json`（解析 API 回應）

---

## 具體任務

1. **資料抓取**
   - 使用 Alpha Vantage 免費 API（或模擬資料）取得指定股票（如 AAPL）的過去 60 天收盤價
   - 將原始資料解析並轉為 Pandas DataFrame

2. **資料清理與計算**
   - 確保日期欄位為正確的 datetime 格式，並按日期排序
   - 計算 5 日、20 日移動平均線（MA5、MA20）
   - 計算每日漲跌幅（百分比變動）
   - 標記「黃金交叉」事件：MA5 由下往上穿越 MA20 的日期

3. **統計摘要**
   - 計算期間內最高價、最低價、平均收盤價、總波動率（標準差）
   - 統計上漲天數 vs 下跌天數

4. **視覺化**
   - 繪製收盤價折線圖（含 MA5、MA20）
   - 在圖上標記黃金交叉發生位置（綠色三角形）
   - 另繪一張長條圖顯示每日漲跌幅（上漲為綠色，下跌為紅色）
   - 兩張圖合併為一個 2×1 的 subplot，存成 `stock_report.png`

5. **儲存結果**
   - 將含有移動平均與漲跌幅的完整 DataFrame 存成 `stock_analysis.csv`

---

## 範例

```python
# 預期輸出（統計摘要）
=== AAPL 分析摘要（過去 60 天）===
最高收盤價：$198.45
最低收盤價：$172.30
平均收盤價：$184.67
波動率（標準差）：$7.21
上漲天數：34 / 下跌天數：26
黃金交叉出現日期：['2026-10-12', '2026-11-03']

# 檔案已儲存：
# - stock_analysis.csv
# - stock_report.png
```

```python
# 模擬資料產生器（若無 API 金鑰可使用此段）
import numpy as np
import pandas as pd

np.random.seed(42)
dates = pd.date_range(end='2026-11-25', periods=60, freq='B')
prices = 180 + np.cumsum(np.random.randn(60) * 2)
df = pd.DataFrame({'date': dates, 'close': prices})
```

---

## 提示

- 移動平均計算：`df['MA5'] = df['close'].rolling(window=5).mean()`
- 黃金交叉偵測：先找出 `MA5 > MA20` 的布林值，再用 `.shift(1)` 比較前一天來判斷交叉時間點
- Subplot 語法：`fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(12, 8))`
- 長條圖顏色條件：`colors = ['green' if v > 0 else 'red' for v in df['change_pct']]`
- 儲存圖片：`plt.savefig('stock_report.png', dpi=150, bbox_inches='tight')`
