## 題目說明

綜合運用前 20 週所學技能，建立一個端對端的「房屋資料分析與預測系統」。
你將爬取或讀取房屋資料、進行資料清洗、探索性分析、視覺化，並訓練一個機器學習模型預測房價，最後將結果輸出成 CSV 與圖表報告。

## 技術要求
- 概念：資料爬取、Pandas 資料清洗、NumPy 計算、Matplotlib/Seaborn 視覺化、sklearn 機器學習
- 需要的模組：`requests`, `beautifulsoup4`, `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`

## 具體任務

1. **資料來源**
   - 使用以下公開的房屋資料集 CSV（無需爬蟲也可執行）：
     ```
     https://raw.githubusercontent.com/dsrscientist/dataset1/master/housing.csv
     ```
   - 或用 `requests` + `BeautifulSoup` 爬取一個公開房屋列表頁面（選做）。
   - 若無法連網，可自行生成模擬資料（見範例）。

2. **資料清洗（Pandas）**
   - 讀取 CSV 並用 `df.info()`, `df.describe()` 瞭解資料。
   - 處理缺失值（填補中位數或刪除）。
   - 移除明顯異常值（如房價 < 0 或 > 5,000,000）。

3. **探索性分析（NumPy + Pandas）**
   - 計算各數值欄位的平均值、標準差、相關係數矩陣。
   - 找出與目標欄位（`price` 或 `MEDV`）相關性最高的前 5 個特徵。

4. **資料視覺化（Matplotlib / Seaborn）**
   - 繪製房價分佈直方圖。
   - 繪製前 3 高相關特徵與房價的散佈圖（subplots）。
   - 繪製相關係數熱力圖（heatmap）。
   - 將圖表存成 `house_analysis.png`。

5. **機器學習預測（sklearn）**
   - 以相關性最高的特徵作為輸入，`price`/`MEDV` 作為目標。
   - 分割訓練集 / 測試集（80/20）。
   - 分別訓練 `LinearRegression` 與 `RandomForestRegressor`。
   - 輸出兩個模型的 RMSE 與 R² 分數，比較優劣。

6. **輸出報告**
   - 將清洗後的資料存成 `house_cleaned.csv`。
   - 將模型評估結果存成 `model_report.txt`，格式如下：
     ```
     Linear Regression  → RMSE: 4.52  R²: 0.71
     Random Forest      → RMSE: 3.18  R²: 0.86
     最佳模型：Random Forest
     ```

## 範例

```python
# 若無法連網，用以下程式碼生成模擬資料
import numpy as np
import pandas as pd

np.random.seed(42)
n = 500
df = pd.DataFrame({
    'area':     np.random.randint(20, 200, n),          # 坪數
    'rooms':    np.random.randint(1, 6, n),             # 房間數
    'age':      np.random.randint(0, 50, n),            # 屋齡
    'distance': np.random.uniform(0.5, 30, n),         # 距市中心(km)
    'floor':    np.random.randint(1, 30, n),            # 樓層
    'price':    None                                    # 目標變數（待計算）
})
# 模擬定價邏輯
df['price'] = (
    df['area'] * 15
    + df['rooms'] * 200
    - df['age'] * 10
    - df['distance'] * 50
    + df['floor'] * 5
    + np.random.normal(0, 300, n)
).clip(500, 8000)  # 單位：萬元

df.to_csv('house_data.csv', index=False)
print(df.head())
```

預期輸出（模型評估片段）：
```
Linear Regression  → RMSE: 312.45  R²: 0.78
Random Forest      → RMSE: 198.73  R²: 0.91
最佳模型：Random Forest
```

## 提示
- 用 `df.corr()['price'].abs().sort_values(ascending=False)` 找高相關特徵。
- `from sklearn.metrics import mean_squared_error, r2_score` 計算評估指標。
- `RMSE = mean_squared_error(y_test, y_pred, squared=False)` 或手動 `np.sqrt(MSE)`。
- Seaborn heatmap：`sns.heatmap(df.corr(), annot=True, cmap='coolwarm')`。
- 儲存圖片：`plt.savefig('house_analysis.png', dpi=150, bbox_inches='tight')`。
