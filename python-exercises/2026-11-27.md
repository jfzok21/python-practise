# 第 21 週今日 Python 練習題：股價資料爬取與趨勢分析

## 題目說明

從公開的股價 API 或靜態網頁抓取指定股票近 30 日的收盤價，整理成 DataFrame，計算移動平均線（MA5、MA10），並以 matplotlib 繪製走勢圖，最後將資料存成 CSV 備查。

本題是第 6–11 週技術的綜合應用：requests 爬蟲、BeautifulSoup 解析、Pandas 整理、matplotlib 視覺化，一次練到底。

---

## 技術要求

- 概念：HTTP 請求、JSON 解析、Pandas rolling window、折線圖繪製、CSV 輸出
- 需要的模組：`requests`、`pandas`、`matplotlib`

---

## 具體任務

1. **取得資料**
   使用 `requests` 呼叫 Yahoo Finance 非官方 API（或任何你慣用的股價來源），取得股票代號 `2330.TW`（台積電）近 30 個交易日的收盤價（Close）與日期（Date）。

2. **整理成 DataFrame**
   - 欄位：`date`、`close`
   - `date` 轉成 `datetime` 型態並設為 index
   - `close` 轉成 `float`

3. **計算移動平均**
   - `MA5`：5 日移動平均（`rolling(5).mean()`）
   - `MA10`：10 日移動平均（`rolling(10).mean()`）

4. **繪製走勢圖**
   - 折線圖：收盤價（藍色實線）、MA5（橘色虛線）、MA10（紅色點線）
   - 標題：`2330.TW 收盤價走勢（近 30 日）`
   - 加上圖例（legend）與 x 軸日期標籤（旋轉 45 度避免重疊）
   - 儲存成 `2330_trend.png`

5. **輸出 CSV**
   將 `date`、`close`、`MA5`、`MA10` 存成 `2330_data.csv`

## 提示

- Yahoo Finance 非官方端點範例（不保證長期穩定，可換用 `yfinance` 套件）：
  ```python
  import requests
  url = "https://query1.finance.yahoo.com/v8/finance/chart/2330.TW"
  params = {"range": "2mo", "interval": "1d"}
  resp = requests.get(url, headers={"User-Agent": "Mozilla/5.0"})
  data = resp.json()
  ```
- 若無法連外網，可用 `yfinance` 套件：
  ```python
  import yfinance as yf
  df = yf.download("2330.TW", period="2mo", interval="1d")
  ```
- `rolling` 前 N-1 筆會是 `NaN`，繪圖時 matplotlib 會自動跳過，不需手動處理。
- 日期軸格式化可用 `fig.autofmt_xdate()`。
