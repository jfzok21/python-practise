# 第 21 週今日 Python 練習題：新聞 RSS 聚合器與關鍵字頻率分析

## 題目說明

從多個新聞來源的 RSS/Atom Feed 抓取最新頭條，整合成一份 Pandas DataFrame，
統計高頻關鍵字，並以 matplotlib 橫條圖呈現 Top 20 熱詞。最後將全部標題存成 CSV。

本題串接第 5–11 週核心技術：requests 爬蟲、XML 解析、字串處理、Pandas 彙整、
matplotlib 視覺化，一次完整走過。

---

## 技術要求

- 概念：HTTP 請求、XML/RSS 解析、字串清洗與斷詞、Pandas groupby、橫條圖
- 需要的模組：`requests`、`xml.etree.ElementTree`（標準庫）、`pandas`、`matplotlib`、`collections.Counter`

---

## 具體任務

1. **設定新聞來源**
   建立一份 RSS Feed 清單（至少 2 個來源），例如：
   ```python
   FEEDS = {
       "BBC 科技": "https://feeds.bbci.co.uk/news/technology/rss.xml",
       "Reuters 科技": "https://feeds.reuters.com/reuters/technologyNews",
   }
   ```
   若連不上外網，可改用任何你能存取的 RSS 來源（包括中文媒體的 RSS）。

2. **抓取並解析 RSS**
   - 用 `requests.get()` 取得 XML 內容
   - 用 `xml.etree.ElementTree` 解析，取出每則新聞的：
     - `title`（標題）
     - `pubDate`（發布時間，可選）
     - `source`（來源名稱）

3. **整理成 DataFrame**
   欄位：`source`、`title`、`pub_date`
   - 去除重複標題（`drop_duplicates('title')`）
   - 重設 index

4. **關鍵字頻率分析**
   - 將所有標題合併成一段文字
   - 轉小寫、移除標點符號（用 `str.translate` 或 `re.sub`）
   - 以空格斷詞（英文）或按字元 2-gram（中文標題）切出詞彙
   - 用 `Counter` 統計詞頻，排除停用詞：
     ```python
     STOPWORDS = {"the", "a", "an", "in", "of", "to", "and", "for",
                  "is", "on", "at", "by", "with", "as", "its"}
     ```
   - 取 Top 20 關鍵字

5. **繪製橫條圖**
   - 橫條圖（`barh`），詞頻高的在最上方（`sort_values` 後反轉）
   - 標題：`新聞熱詞 Top 20（{今天日期}）`
   - x 軸標籤：`出現次數`
   - 儲存成 `news_keywords_2026-11-28.png`

6. **輸出 CSV**
   將 DataFrame 存成 `news_headlines_2026-11-28.csv`，印出總筆數與來源分佈。

## 提示

- RSS XML 的命名空間有時需要處理，`findall` 找不到 `item` 時試試：
  ```python
  root = ET.fromstring(resp.content)
  items = root.findall(".//item")        # RSS 2.0
  # 或
  items = root.findall(".//{http://www.w3.org/2005/Atom}entry")  # Atom
  ```
- `requests.get` 加上 `timeout=10` 避免卡住；用 `try/except` 包住每個 Feed，
  單一來源失敗不影響其他來源繼續執行。
- 中文標題斷詞可用 2-gram（每兩個字視為一個詞）：
  ```python
  words = [title[i:i+2] for title in titles for i in range(len(title)-1)]
  ```
- 橫條圖顏色可用 `color='steelblue'`，讓圖表乾淨易讀。
- `fig.tight_layout()` 防止標籤被切掉。
